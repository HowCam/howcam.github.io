# 激素调节的过程

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 实例 1：血糖平衡的调节

**血糖**：血液中的糖，主要是**葡萄糖**。正常人的血糖含量为 **3.9～6.1 mmol/L**。

### 血糖的来源和去向

| 来源 | 去向 |
|------|------|
| 食物中的糖类经消化、吸收进入血液（**主要来源**） | 被组织细胞摄取，**氧化分解**为 $\ce{CO2 + H2O + }$能量 |
| **肝糖原**分解成葡萄糖进入血液（**空腹时的重要来源**） | 在肝和骨骼肌细胞内合成**肝糖原、肌糖原**储存 |
| 脂肪等非糖物质**转化**为葡萄糖进入血液 | 转变为**甘油三酯、某些氨基酸**等非糖物质 |

### 血糖平衡的调节过程

<div class="mermaid">
graph TB
    H[血糖浓度升高] --> B[胰岛 B 细胞]
    B --> I[胰岛素分泌增加]
    I --> G1[促进：血糖进入组织细胞氧化分解]
    I --> G2[促进：合成肝糖原、肌糖原]
    I --> G3[促进：转变为甘油三酯等]
    I --> G4[抑制：肝糖原分解、非糖物质转变]
    G1 --> N[血糖恢复正常]
    G2 --> N
    G3 --> N
    G4 --> N
    L[血糖浓度降低] --> A[胰岛 A 细胞]
    A --> GI[胰高血糖素分泌增加]
    GI --> G5[促进肝糖原分解、非糖物质转变成糖]
    G5 --> N
    N -.反馈调节.-> B
    N -.反馈调节.-> A
</div>

- **胰岛素**：由胰岛 **B 细胞**分泌，是**唯一能够降低血糖浓度**的激素。一方面促进血糖进入组织细胞氧化分解、合成糖原、转变为甘油三酯等；另一方面抑制肝糖原的分解和非糖物质转变成葡萄糖（既增加去路，又减少来源）。
- **胰高血糖素**：由胰岛 **A 细胞**分泌，主要作用于**肝**，促进肝糖原分解成葡萄糖进入血液，促进非糖物质转变成糖，使血糖浓度回升。
- 其他参与调节的激素：糖皮质激素、肾上腺素、甲状腺激素等，通过调节有机物代谢或影响胰岛素的分泌和作用，直接或间接地**升高**血糖。

!!! note "神经调节参与"
    血糖含量降低时，下丘脑某区域兴奋，通过**交感神经**使胰岛 A 细胞分泌胰高血糖素；神经系统还通过控制甲状腺和肾上腺的分泌活动来调节血糖含量。

### 反馈调节

**反馈调节**：在一个系统中，系统本身工作的效果，反过来又作为信息调节该系统的工作。

- 胰岛素的作用结果（血糖降低）会反过来影响胰岛素的分泌；胰高血糖素也是如此；
- 反馈调节是生命系统中非常普遍的调节机制，对机体维持稳态具有重要意义（如生态系统稳定性也受反馈调节）。

### 糖尿病

| 类型 | 病因 | 特点 |
|------|------|------|
| **1 型糖尿病** | 胰岛功能减退、分泌胰岛素**减少** | 通常在青少年时期发病，可用注射胰岛素治疗 |
| **2 型糖尿病** | 与遗传、环境、生活方式密切相关 | 能量摄入过多、运动量过少、肥胖是最常见危险因素；发病年龄降低，不一定能通过注射胰岛素治疗 |

## 实例 2：甲状腺激素分泌的分级调节

当机体感受到寒冷等刺激时，神经冲动传到下丘脑，下丘脑分泌**促甲状腺激素释放激素（TRH）**；TRH 作用于垂体，促使垂体分泌**促甲状腺激素（TSH）**；TSH 随血液循环到达甲状腺，促使甲状腺增加**甲状腺激素**的合成和分泌。甲状腺激素随血液运到全身，几乎作用于体内所有细胞，**提高细胞代谢速率**，使机体产生更多热量。

<div class="mermaid">
graph TB
    S[寒冷等刺激] --> H[下丘脑]
    H -->|TRH| P[垂体]
    P -->|TSH| T[甲状腺]
    T -->|甲状腺激素| C[细胞代谢增强、产热增加]
    T -.反馈抑制（-）.-> H
    T -.反馈抑制（-）.-> P
</div>

!!! note "两种调节兼有"
    在甲状腺激素分泌的过程中，既存在**分级调节**，也存在**反馈调节**（负反馈）。当血液中甲状腺激素含量增加到一定程度时，会抑制下丘脑和垂体分泌相关激素，使甲状腺激素分泌减少而不至于浓度过高。

**分级调节**：下丘脑、垂体和靶腺体之间存在的分层调控。

| 分级调节轴 | 靶腺体 |
|-----------|--------|
| 下丘脑—垂体—**甲状腺**轴 | 甲状腺 |
| 下丘脑—垂体—**肾上腺皮质**轴 | 肾上腺皮质 |
| 下丘脑—垂体—**性腺**轴 | 性腺 |

!!! info "分级调节的意义"
    可以**放大激素的调节效应**，形成多级反馈调节，有利于**精细调控**，从而维持机体的稳态。

## 激素调节的特点

| 特点 | 说明 |
|------|------|
| **通过体液进行运输** | 内分泌腺没有导管，激素弥散到体液中，随血液流到全身；临床上常通过抽取血样检测激素水平 |
| **作用于靶器官、靶细胞** | 激素通过与靶细胞上的**特异性受体**相互识别并特异性结合而发挥作用。甲状腺激素几乎作用于全身细胞，TSH 只作用于甲状腺 |
| **作为信使传递信息** | 激素犹如信使将信息从内分泌细胞传递给靶细胞，引起一系列代谢变化；激素一经起作用后即**失活**，体内需源源不断产生激素 |
| **微量和高效** | 血液中激素浓度很低（一般 $10^{-12}\sim10^{-9}$ mol/L），但作用效果极其显著 |

!!! note "激素间的关系"
    - **协同作用**：胰高血糖素、甲状腺激素、肾上腺素等均可升高血糖，通过作用于不同环节协同升高血糖；生长激素与甲状腺激素在促进生长发育方面也表现为协同。
    - **抗衡（拮抗）作用**：胰岛素降低血糖，与上述升糖激素相抗衡。
    - 激素种类多、量极微，**既不组成细胞结构，又不提供能量，也不起催化作用**，而是使靶细胞原有的生理活动发生变化——激素是**信息分子**。

## 核心概念速记

```
血糖：3.9~6.1 mmol/L；胰岛素唯一降血糖，胰高血糖素升血糖
反馈调节：工作效果反过来调节系统本身
分级调节：下丘脑 → 垂体 → 靶腺（放大效应、精细调控）
激素调节四特点：体液运输、靶器官靶细胞、信使传信息、微量高效
激素 = 信息分子（不供能、不催化、不构成结构）
```
