# 体液调节与神经调节的关系

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 体液调节的概念

**体液调节**：激素等化学物质，通过**体液传送**的方式对生命活动进行调节。**激素调节是体液调节的主要内容**。

除激素外，其他一些化学物质也能作为体液因子起调节作用：

| 体液因子 | 作用 |
|----------|------|
| $\ce{CO2}$ | 调节呼吸运动的**重要体液因子**；体液中 $\ce{CO2}$ 浓度变化刺激相关感受器，通过神经系统调节呼吸运动 |
| 组胺 | 参与过敏反应等 |
| 某些气体分子（$\ce{NO}$、$\ce{CO}$ 等） | 作为信号分子起调节作用 |
| 某些代谢产物 | 对细胞、组织和器官的功能起调节作用 |

!!! info "临床应用"
    临床上给患者输入 $\ce{O2}$ 时，往往采用含 **5% 左右 $\ce{CO2}$** 的混合气体，以达到刺激呼吸中枢的目的。

---

## 体液调节与神经调节的比较

| 比较项目 | 体液调节 | 神经调节 |
|----------|----------|----------|
| 作用途径 | 体液运输 | 反射弧 |
| 反应速度 | 较缓慢 | 迅速 |
| 作用范围 | 较广泛 | 准确、比较局限 |
| 作用时间 | 比较长 | 短暂 |

!!! note "两者关系"
    一些低等动物只有体液调节，没有神经调节；但在人和高等动物体内，体液调节和神经调节都是机体调节生命活动的重要方式，**相辅相成，各具优势**。

---

## 实例 1：体温的调节

体温相对恒定是人体**产热和散热过程保持动态平衡**的结果。

### 产热与散热

| 过程 | 主要器官/方式 |
|------|---------------|
| **产热** | 代谢产热是机体热量的主要来源。安静时主要通过**肝、脑**等器官的活动提供热量；运动时**骨骼肌**成为主要产热器官 |
| **散热** | **皮肤**是最主要的散热器官，通过**辐射、传导、对流、蒸发**（如汗液蒸发）四种方式散热 |

### 寒冷环境中的调节

<div class="mermaid">
graph TB
    A[寒冷环境] --> B[冷觉感受器兴奋]
    B --> C[下丘脑体温调节中枢]
    C --> D[皮肤血管收缩、血流量减少]
    C --> E[汗腺分泌减少 → 蒸发散热减少]
    C --> F[骨骼肌战栗 → 产热增加]
    C --> G[甲状腺激素、肾上腺素释放增加 → 代谢增强、产热增加]
    D --> H[散热减少]
    E --> H
    F --> I[产热增加]
    G --> I
    H --> J[体温维持正常]
    I --> J
</div>

- 皮肤中分布有**冷觉感受器**和**热觉感受器**。
- 这类通过**神经影响激素的分泌，再由激素对机体功能实施调节**的方式，称为**神经—体液调节**。

### 炎热环境中的调节

热觉感受器兴奋 → 传入下丘脑体温调节中枢 → 通过自主神经系统调节和肾上腺等腺体分泌 → 皮肤血管**舒张**、血流量增多，汗液分泌**增多** → 增加散热。

!!! note "调节方式"
    - **生理性调节**（排汗、血管舒缩）是**基本**的调节方式；
    - **行为性调节**（使用空调、增减衣物）是重要**补充**。

!!! warning "调节能力有限"
    人在寒冷环境中停留过久，产热不足以补偿散热，体温会降低；在高温环境中停留过久，热量不能及时散出，体温会升高。体温过低或过高都会影响物质代谢，破坏内环境稳态，严重时危及生命。

## 实例 2：水和无机盐平衡的调节

### 水的摄入与排出

人体每天水的来源：**饮水、食物中所含的水、代谢中产生的水**。

| 摄入的水量 /mL | 排出的水量 /mL |
|----------------|----------------|
| 来自饮水 1200 | 由肾排出（尿液）1500 |
| 来自食物 1000 | 由皮肤排出（汗液）500 |
| 来自代谢 300 | 由肺排出（呼吸）400 |
| — | 由大肠排出（粪便）100 |
| **共计 2500** | **共计 2500** |

（体重 70 kg 成年人、25 ℃、活动量不大、中等饮食程度的情况下）

**肾排尿**是人体排出水的最主要途径，机体通过调节排尿量使水的排出量与摄入量相适应。

### $\ce{Na+}$ 与 $\ce{K+}$

| 离子 | 来源与去路 | 作用 |
|------|-----------|------|
| $\ce{Na+}$ | 主要来源是食盐，几乎全部由**小肠吸收**，主要经**肾随尿排出**，排出量几乎等于摄入量 | $\ce{Na+}$ 浓度对维持**细胞外液渗透压**具有重要作用 |
| $\ce{K+}$ | 蔬菜和水果中富含，合理膳食即可满足需要 | 维持**细胞内液渗透压**起决定性作用；维持心肌舒张、保持心肌正常兴奋 |

### 渗透压调节（水盐平衡调节）

<div class="mermaid">
graph TB
    A[饮水不足、失水过多或食物过咸] --> B[细胞外液渗透压升高]
    B --> C[下丘脑渗透压感受器受刺激]
    C --> D[大脑皮层产生渴觉 → 主动饮水]
    C --> E[下丘脑分泌、垂体释放抗利尿激素增加]
    E --> F[肾小管、集合管重吸收水增加]
    F --> G[尿量减少 → 渗透压恢复正常]
    H[饮水过多或盐分丢失过多] --> I[细胞外液渗透压下降]
    I --> J[抗利尿激素分泌释放减少 → 尿量增加 → 渗透压恢复]
    K[细胞外液量减少、血钠降低] --> L[肾上腺皮质分泌醛固酮增加]
    L --> M[肾小管、集合管重吸收 Na⁺ 增加 → 血钠稳定]
</div>

- **抗利尿激素**：由**下丘脑分泌、垂体释放**，促进肾小管和集合管对水分的重吸收，使尿量减少。
- **渴觉**：在**大脑皮层**产生，通过主动饮水直接调节水的摄入量。
- **醛固酮**：由**肾上腺皮质**分泌，促进肾小管和集合管对 $\ce{Na+}$ 的重吸收，维持血钠含量稳定。
- 水和无机盐的平衡，是在**神经调节和激素调节共同作用**下，通过调节**尿量和尿的成分**实现的。

!!! warning "水盐失衡实例"
    剧烈运动、高温作业或剧烈呕吐、严重腹泻时，丢失大量水和无机盐（主要是钠盐）。若只补水不补盐，细胞外液渗透压下降，出现血压下降、心率加快、四肢发冷甚至昏迷，需及时补充**生理盐水**。

!!! info "最低尿量"
    人体每昼夜有 35～50 g 代谢废物必须随尿液排出，溶解这些废物的最低尿量应在 **500 mL 以上**，所以每天要保证一定量的饮水。

## 神经调节与体液调节的联系

1. **不少内分泌腺直接或间接地受中枢神经系统的调节**，此时体液调节可以看作是神经调节的一个环节。
   例如：肾上腺髓质受交感神经支配，交感神经兴奋时，肾上腺髓质分泌肾上腺素等激素作用于靶细胞。
2. **内分泌腺分泌的激素也可以影响神经系统的发育和功能**。
   例如：幼年时缺乏甲状腺激素会影响脑的发育；成年时甲状腺激素分泌不足会使神经系统兴奋性降低，表现为头晕、反应迟钝、记忆力减退。

!!! note "总结"
    人和高等动物体的各项生命活动常常**同时受神经和体液的调节**。正是由于两种调节方式配合，各器官、系统活动才能协调一致，内环境稳态才得以维持，机体才能适应环境的不断变化。

---

## 核心概念速记

```
体温调节：产热（肝脑/骨骼肌）= 散热（皮肤辐射传导对流蒸发），中枢在下丘脑
水盐调节：下丘脑渗透压感受器 → 抗利尿激素（下丘脑分泌、垂体释放）
醛固酮：肾上腺皮质分泌，保 Na⁺（保水）
联系：神经调控内分泌腺；激素影响神经系统发育和功能
CO₂ 是调节呼吸的重要体液因子
```
