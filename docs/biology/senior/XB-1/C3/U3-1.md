# 激素与内分泌系统

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 腺体与激素

| 类型 | 特点 | 举例 |
|------|------|------|
| **外分泌腺** | 分泌物经由**导管**流出体外或流到消化腔 | 汗腺、唾液腺、胃腺 |
| **内分泌腺** | **没有导管**，分泌物（激素）进入腺体内毛细血管，随血液循环输送到全身 | 垂体、甲状腺、肾上腺、胰岛、性腺等 |

**激素（hormone）**：由内分泌器官（或细胞）分泌的化学物质，对机体的生长发育和生理功能起调节作用。

!!! note "化学本质多样"
    不同激素的化学组成不同，如胰岛素是一种含 51 个氨基酸的蛋白质，而性激素主要是类固醇。

---

## 激素的发现

20 世纪之前，学术界普遍认为人和动物体的一切生理活动都由神经系统调节，探寻其他调节方式意味着挑战权威。

### 促胰液素的发现

| 科学家 | 实验与观点 |
|--------|-----------|
| 沃泰默（法） | 把稀盐酸注入狗的上段小肠肠腔 → 胰腺分泌胰液；切除通向该段小肠的神经，只留下血管，再注入稀盐酸 → 仍能促进胰液分泌。他解释为"十分顽固的反射"（小肠微小神经难以剔除干净） |
| **斯他林和贝利斯**（英） | 大胆假设：这不是反射而是**化学调节**——盐酸作用下小肠黏膜细胞产生一种化学物质，进入血液后随血流到达胰腺，引起胰液分泌。1902 年，将狗小肠黏膜刮下磨碎、加稀盐酸制成提取液，注入同一条狗静脉 → 促进胰液分泌，假设被证实 |
| 巴甫洛夫（俄） | 重复实验后结果相同，感慨："很明显，我们失去了一个发现真理的机会！" |

这种由小肠黏膜分泌的化学物质被称作**促胰液素**。促胰液素的发现不仅使人们认识到一种新的化学物质，更重要的是使人们认识到：机体除了神经调节，还存在由内分泌器官或细胞分泌的化学物质——激素进行调节的方式，即**激素调节（hormonal regulation）**。

!!! tip "科学启示"
    不迷信权威、大胆假设、巧妙设计实验（排除神经干扰、直接提取有效成分），是斯他林和贝利斯成功的关键。

### 研究激素的实例

**实例 1：胰岛素的发现**

- 1869 年，发现胰腺中聚集成岛状的细胞堆，命名为"胰岛"；
- 1889 年，切除胰腺的狗患类似糖尿病的疾病，据此提出胰腺能分泌某种抗糖尿病物质的假说；
- 1916 年，将胰岛产生的可能与糖尿病有关的物质命名为胰岛素；
- 1920—1921 年，**班廷和贝斯特**：结扎狗的胰管使胰腺萎缩（胰岛保持完好），摘除另一只狗的胰腺造成实验性糖尿病，将萎缩胰腺（只剩胰岛）的提取液注入病狗 → 血糖迅速下降并恢复正常；后与生化学家合作抑制胰蛋白酶活性，直接从正常胰腺提取胰岛素，用于治疗糖尿病取得很好效果。

**实例 2：睾丸分泌雄激素的研究**

- 1849 年，摘除公鸡睾丸后雄性性征明显消失（鸡冠萎缩、不再啼鸣、求偶行为消失）；将睾丸重新移植回去，公鸡特征逐步恢复；
- 后来从动物睾丸中提取出**睾酮**，证实它就是睾丸分泌的雄激素。

!!! note "加法原理与减法原理"
    - **减法原理**：人为去除某个影响因素（如摘除胰腺、阉割睾丸、结扎胰管）；
    - **加法原理**：人为施加某个影响因素（如移植睾丸、注射激素提取液、给予睾酮刺激）。

## 内分泌系统的组成和功能

**内分泌系统**由相对独立的**内分泌腺**以及兼有内分泌功能的**细胞**共同构成。有的内分泌细胞聚集在一起成为内分泌腺体（如垂体、甲状腺）；也有的分散在一些器官、组织内（如小肠黏膜上的内分泌细胞）；下丘脑中的某些神经细胞也具有内分泌功能。

| 内分泌腺 | 分泌的主要激素 | 主要作用 |
|----------|----------------|----------|
| **下丘脑** | 促甲状腺激素释放激素（TRH）、促性腺激素释放激素（GnRH）、促肾上腺皮质激素释放激素（CRH）等 | 作用于垂体，调控垂体分泌相应激素 |
| **垂体** | 生长激素、促甲状腺激素（TSH）、促性腺激素、促肾上腺皮质激素等 | 调节生长发育；促激素分别调节相应内分泌腺的分泌活动 |
| **甲状腺** | 甲状腺激素 | 调节体内有机物代谢、促进生长发育、提高神经的兴奋性 |
| **肾上腺**（皮质） | 醛固酮、皮质醇 | 调节水盐代谢和有机物代谢 |
| **肾上腺**（髓质） | 肾上腺素 | 提高机体的应激能力 |
| **胰腺（胰岛）** | 胰岛素（B 细胞）、胰高血糖素（A 细胞） | 在糖代谢中发挥重要调节作用 |
| **卵巢** | 雌激素、孕激素 | 促进女性生殖器官发育、卵细胞生成和女性第二性征出现 |
| **睾丸** | 雄激素（主要是睾酮） | 促进男性生殖器官发育、精子生成和男性第二性征出现 |

**内分泌系统的功能**：维持内环境稳定、调节物质和能量代谢、调控生长发育和生殖等。各种内分泌腺间具有复杂的功能联系，共同调节机体活动。

## 思维训练：验证假说，预测结果

科学家研究性激素在胚胎生殖系统发育中的作用，提出两个假说：

- 假说 1：发育出雄性器官需要来自睾丸提供的激素信号，信号缺失时发育出雌性器官；
- 假说 2：发育出雌性器官需要来自卵巢提供的激素信号，信号缺失时发育出雄性器官。

实验：在家兔胚胎生殖系统分化前，手术摘除即将发育为卵巢或睾丸的组织。结果：

| 性染色体组成 | 未做手术（外生殖器） | 手术后（外生殖器） |
|--------------|---------------------|-------------------|
| XY | 雄性 | **雌性** |
| XX | 雌性 | **雌性** |

结论：实验结果验证了**假说 1**（睾丸提供的激素信号是发育出雄性器官所必需的）。若给予睾酮刺激，则 XX 和 XY 胚胎都将发育出雄性器官。

## 核心概念速记

```
外分泌腺：有导管；内分泌腺：无导管，激素入血
激素调节：内分泌器官（细胞）分泌的化学物质进行的调节
促胰液素：第一种被发现的激素（斯他林、贝利斯，1902）
研究激素方法：减法原理（摘除）+ 加法原理（移植/注射）
内分泌系统 = 内分泌腺 + 兼有内分泌功能的细胞
```
