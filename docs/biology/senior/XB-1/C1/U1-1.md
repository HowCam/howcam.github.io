# 细胞生活的环境

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 体液

**体液**：人体内含有大量以水为基础的液体，统称为体液。成年人体内水量大约是体重的 60%，出生一天的婴儿约为 79%。

| 组成 | 存在部位 | 占比 |
|------|----------|------|
| **细胞内液** | 存在于细胞内 | 约 2/3 |
| **细胞外液** | 存在于细胞外 | 约 1/3 |

细胞外液主要包括**血浆、组织液和淋巴液**等。体液中除含有大量水外，还含有许多离子和化合物。

---

## 体内细胞生活在细胞外液中

单细胞生物（如草履虫）可以直接从水中获取养料和 $\ce{O2}$，并把废物直接排入水中；而组成人体的绝大多数细胞**没有直接与外界环境接触**，它们直接生活的环境是细胞外液。

### 三种细胞外液

| 液体 | 概念 | 直接生活的细胞 |
|------|------|----------------|
| **血浆**（plasma） | 血液中的液体部分，血细胞悬浮其中 | **血细胞** |
| **组织液**（tissue fluid） | 存在于组织细胞间隙的液体，又叫组织间隙液；主要由血浆通过毛细血管壁渗出到细胞间形成，大部分物质可被重新吸收回血浆 | **体内绝大多数细胞**（绝大多数细胞浸浴在组织液中） |
| **淋巴液**（lymph fluid） | 存在于淋巴管中，由一部分组织液经毛细淋巴管壁进入毛细淋巴管而形成，经淋巴结等淋巴器官最终汇入血浆 | **淋巴细胞**等 |

### 内环境

血浆、组织液和淋巴液通过动态的有机联系，共同构成机体内细胞生活的直接环境。为了区别于个体生活的外界环境，人们把这个由**细胞外液**构成的液体环境叫作**内环境（internal environment）**。

    T -->|重吸收| P

!!! note "要点"
    - 血浆与组织液之间是**双向**交换；组织液进入淋巴管是**单向**的；淋巴液最终单向汇入血浆。
    - 全身的细胞外液是一个有机的整体。
    - **内环境 = 细胞外液**，不包括细胞内液，也不包括与外界相通的管腔中的液体（如尿液、消化液、肺泡腔内的气体、汗液等）。

## 细胞外液的成分

以血浆的化学成分为例：

| 成分 | 含量 |
|------|------|
| 水 | 约 **90%** |
| 蛋白质 | 7%～9% |
| 无机盐 | 约 1% |
| 血液运输的其他物质 | 少量（葡萄糖、激素、各种代谢废物等） |

血浆中部分成分的正常参考值：葡萄糖 3.9～6.1 mmol/L，总蛋白 65～85 g/L，钠 137～147 mmol/L，钾 3.5～5.3 mmol/L，钙 2.2～2.65 mmol/L，尿素 2.8～7.2 mmol/L 等。

!!! note "比较"
    组织液、淋巴液的成分和各成分的含量与血浆相近，但**最主要的差别是血浆中含有较多的蛋白质**，而组织液和淋巴液中蛋白质含量很少。

从某种意义上说，细胞外液是一种类似于海水的盐溶液，这在一定程度上反映了**生命起源于海洋**。

## 内环境的理化性质

**渗透压、酸碱度和温度**是细胞外液理化性质的三个主要方面。

### 渗透压

- **渗透压**：指溶液中溶质微粒对水的吸引力。其大小取决于**单位体积溶液中溶质微粒的数目**：溶质微粒越多（溶液浓度越高），渗透压越高。
- 血浆渗透压的大小主要与**无机盐、蛋白质**的含量有关。
- 细胞外液渗透压的 **90% 以上来源于 $\ce{Na+}$ 和 $\ce{Cl-}$**。
- 在 37 ℃ 时，人的血浆渗透压约为 **770 kPa**，相当于细胞内液的渗透压。

### 酸碱度（pH）

- 正常人的血浆近中性，pH 为 **7.35～7.45**。
- 血浆 pH 之所以能保持稳定，与其中含有的 $\ce{HCO3-/H2CO3}$、$\ce{HPO4^{2-}/H2PO4-}$ 等**缓冲物质（缓冲对）**有关。

### 温度

人体细胞外液的温度一般维持在 **37 ℃ 左右**。

!!! warning "细胞的生活需要适宜的理化条件"
    将红细胞放在清水或浓度很低的溶液中，细胞会因吸水过多而破裂；放在浓度较高的溶液中，会因失水过多而死亡；过酸、过碱或温度过高、过低，细胞也不能正常生活。

## 细胞通过内环境与外界环境进行物质交换

1. **细胞 ↔ 内环境**：细胞作为一个开放系统，直接与内环境进行物质交换——不断获取生命活动所需要的物质，同时排出代谢产生的废物。
2. **内环境 ↔ 外界环境**：需要体内各个系统的参与：

| 系统 | 作用 |
|------|------|
| 消化系统 | 将营养物质摄入体内 |
| 呼吸系统 | 吸入 $\ce{O2}$、排出 $\ce{CO2}$ |
| 泌尿系统 | 把代谢废物、水和无机盐排出体外 |
| 循环系统 | 把各种物质运输到机体的相应部位 |

!!! note "相互关系"
    机体各部分正常运行和协调一致，共同保证内环境与外界环境之间物质交换的顺利进行。细胞和内环境之间也是**相互影响、相互作用**的：细胞不仅依赖于内环境，也**参与**了内环境的形成和维持。

## 易错辨析

???+ question "常见判断"
    - 膀胱内的尿液、肺泡腔内的气体、小肠腔内的消化液、汗液、泪液 → **不属于内环境**（与外界相通）。
    - 大脑细胞间隙的液体（组织液） → **属于内环境**。
    - 水疱中的液体主要是组织液；水疱自行消失是因为其中的液体可渗入毛细血管和毛细淋巴管，说明内环境中的物质是不断更新的。
    - 血浆蛋白属于内环境成分，血红蛋白（在红细胞内）不属于内环境成分。
