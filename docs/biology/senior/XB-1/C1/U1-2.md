# 内环境的稳态

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 内环境的动态变化

随着外界环境的变化和体内细胞代谢活动的进行，内环境（如血浆）的各种化学成分和理化性质在**不断发生变化**，但都处于**一定范围内**。

- 不同人的体温会因年龄、性别等的不同而存在微小差异；同一个人的体温在一日内也有变化，但变化幅度一般不超过 **1 ℃**。
- 健康人的血糖、血脂、渗透压等也都是不断变化的，但都处于一定的范围内。
- 血液生化检验中，每种成分的参考值（正常值）都有一个变化范围，若某种成分高于或低于参考值，则预示机体可能处于不健康状态。

---

## 稳态的概念

**稳态（homeostasis）**：正常机体通过调节作用，使各个器官、系统协调活动，共同维持内环境的**相对稳定状态**。

!!! note "理解要点"
    稳态不是恒定不变，而是一种**动态平衡**。例如体温始终接近 37 ℃，内环境的化学成分和理化性质在一定范围内波动。

## 探究·实践：模拟生物体维持 pH 的稳定

**实验原理**：在溶液中加入酸或碱，缓冲对（如 $\ce{HPO4^{2-}/H2PO4-}$）能使溶液 pH 的变化减弱；与自来水相比，生物组织匀浆更类似于缓冲液。

**目的要求**：通过比较**自来水、缓冲液和肝匀浆**在加入酸或碱后 pH 的变化，推测生物体是如何维持 pH 稳定的。

**材料用具**：防护手套、护目镜、50 mL 烧杯、量筒、pH 计或 pH 试纸、0.1 mol/L 的 $\ce{HCl}$、0.1 mol/L 的 $\ce{NaOH}$、pH 为 7 的磷酸盐缓冲液、肝匀浆等。

**方法步骤**：

1. 记录 25 mL 自来水的起始 pH；
2. 一滴一滴加入 0.1 mol/L $\ce{HCl}$，每加 5 滴测一次 pH，直到加入 30 滴；
3. 充分冲洗烧杯后换用自来水，同法逐滴加入 0.1 mol/L $\ce{NaOH}$ 并测 pH；
4. 分别用缓冲液、肝匀浆代替自来水，重复上述步骤；
5. 以酸或碱的滴数为横坐标、pH 为纵坐标绘制曲线。

!!! warning "安全"
    $\ce{HCl}$ 和 $\ce{NaOH}$ 均有腐蚀性，避免接触皮肤和眼睛，不要入口；若酸溅到皮肤上，立即用水冲洗 15 min 并告诉老师。

**结论**：肝匀浆中加入酸或碱后 pH 变化与缓冲液类似，说明生物组织中含有缓冲物质，能维持 pH 相对稳定。

## 对稳态调节机制的认识

| 时期 | 科学家 | 观点 |
|------|--------|------|
| 1857 年 | 贝尔纳（法） | 内环境的稳定是生命能独立和自由存在的首要条件，**主要依赖神经系统的调节** |
| 1926 年 | 坎农（美） | 提出**稳态**概念；稳态是动态平衡，在**神经调节和体液调节**共同作用下，通过各器官、系统分工合作实现 |
| 随着分子生物学发展 | — | **免疫系统**也能发现并清除异物、病原微生物等引起内环境波动的因素 |

!!! note "目前普遍观点"
    **神经—体液—免疫调节网络**是机体维持稳态的主要调节机制。

**稳态的基础**：人体各器官、系统协调一致地正常运行。若某种器官功能出现障碍，会引起稳态失调。例如肾功能衰竭时，水和无机盐等代谢紊乱，可出现全身水肿、尿素氮升高、呕吐等症状（**尿毒症**），严重时导致死亡。

**调节能力有限度**：当外界环境变化过于剧烈，或人体自身的调节功能出现障碍时，内环境稳态就会遭到破坏。

| 稳态失调实例 | 原因 |
|--------------|------|
| 中暑 | 高温引起体温调节功能紊乱，高热、皮肤干燥、恶心、呕吐等，体温超过 40 ℃ 病死率高 |
| 高原反应 | 高原空气稀薄、氧分压低，出现头痛、乏力、心跳加快、血压升高等 |
| 严重腹泻后只喝水不补盐 | 丢失大量无机盐，细胞外液渗透压下降 |
| 尿毒症 | 肾功能衰竭，代谢废物无法排出 |

## 内环境稳态的重要意义

**内环境稳态是机体进行正常生命活动的必要条件。**

1. 细胞代谢需要依靠氧化分解葡萄糖来提供能量，只有**血糖浓度和血液中的含氧量**保持在正常范围内，才能为这一反应提供充足的反应物。
2. 细胞代谢的进行离不开**酶**，酶的活性受温度、pH 等因素的影响，只有温度、pH 等在适宜范围内，酶才能正常发挥催化作用。

## 稳态概念的发展

稳态已成为生命科学的一大基本概念，在生命系统的各个层次上普遍存在：

| 层次 | 实例 |
|------|------|
| 分子水平 | 基因表达的稳态、激素分泌的稳态、酶活性的稳态；原癌基因与抑癌基因表达的稳态被破坏，正常细胞可能变成癌细胞 |
| 细胞水平 | 细胞分裂和分化的稳态 |
| 器官水平 | 心脏活动的稳态（血压、心率）、消化腺分泌消化液的稳态 |
| 个体水平 | 内环境稳态 |
| 群体水平 | 种群数量的稳态、生态系统的结构和功能的稳态 |

## 核心概念速记

```
体液 = 细胞内液（2/3）+ 细胞外液（1/3）
内环境 = 细胞外液 = 血浆 + 组织液 + 淋巴液等
稳态 = 内环境的化学成分和理化性质处于动态平衡（相对稳定）
调节机制：神经—体液—免疫调节网络
意义：机体进行正常生命活动的必要条件
```
