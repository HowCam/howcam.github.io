# 其他植物激素

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 其他植物激素的发现

| 激素 | 发现过程 |
|------|----------|
| **赤霉素（GA）** | 1926 年发现水稻感染赤霉菌后植株疯长（**恶苗病**，比正常植株高 50% 以上且结实率大大降低）；将赤霉菌培养基滤液喷施到水稻幼苗上，未感染的幼苗也出现恶苗病症状；1935 年从滤液分离出致病的物质，称为赤霉素；20 世纪 50 年代发现被子植物体内也存在赤霉素 |
| **细胞分裂素** | 后来发现，主要在根尖合成 |
| **脱落酸** | 后来发现 |
| **乙烯** | 20 世纪 60 年代，气相层析技术证明成熟果实释放的乙烯促进了其他果实成熟（"木瓜催熟柿子"中的"气"） |
| **油菜素内酯** | 植物体内的天然调节物质，已被正式认定为**第六类植物激素** |

!!! info "植物激素的含量"
    植物激素含量极少：菜豆未成熟种子中赤霉素含量不到种子质量的亿分之一；1 kg 向日葵新鲜叶片中只含有几微克细胞分裂素。

## 五类植物激素的合成部位与作用

| 激素 | 合成部位 | 主要作用 |
|------|----------|----------|
| **生长素** | 芽、幼嫩的叶、发育中的种子 | 促进细胞伸长生长、诱导细胞分化；促进侧根和不定根发生，影响花、叶、果实发育 |
| **赤霉素** | 幼芽、幼根和未成熟的种子 | **促进细胞伸长**，从而引起植株增高；促进细胞分裂与分化；促进**种子萌发、开花和果实发育** |
| **细胞分裂素** | 主要是**根尖** | **促进细胞分裂**；促进芽的分化、侧枝发育、叶绿素合成 |
| **脱落酸** | **根冠、萎蔫的叶片**等 | **抑制细胞分裂**；促进气孔关闭；促进叶和果实的**衰老和脱落**；维持种子休眠 |
| **乙烯** | 植物体**各个部位** | **促进果实成熟**；促进开花；促进叶、花、果实脱落 |
| **油菜素内酯**（第六类） | — | 促进茎、叶细胞的扩展和分裂，促进花粉管生长、种子萌发等 |

!!! note "调控方式"
    植物激素对植物生长发育的调控，是通过调控**细胞分裂、细胞伸长、细胞分化和细胞死亡**等方式实现的。

## 植物激素间的相互作用

在植物各器官中同时存在多种植物激素，决定器官生长、发育的往往不是某种激素的**绝对含量**，而是不同激素的**相对含量**。

### 1. 相对含量决定发育方向

例如：黄瓜茎端的**脱落酸与赤霉素的比值较高**，有利于分化形成**雌花**；比值较低则有利于分化形成**雄花**。

### 2. 协同作用

- 生长素主要促进**细胞核的分裂**，细胞分裂素主要促进**细胞质的分裂**，二者协调促进细胞分裂的完成；
- 赤霉素与生长素都能促进细胞伸长，表现为协同。

### 3. 抗衡（拮抗）作用

- 调节种子萌发：**赤霉素促进萌发，脱落酸抑制萌发**，二者作用效果相反；
- 赤霉素、生长素促进生长，脱落酸抑制生长。

### 4. 代谢上的相互作用

当**生长素浓度升高到一定值**时，就会促进**乙烯的合成**；乙烯含量升高，反过来会**抑制生长素的作用**。

### 5. 顺序性

在植物生长发育过程中，不同种激素的调节还往往表现出一定的**顺序性**。例如猕猴桃果实的发育过程中，细胞分裂素、生长素、赤霉素、脱落酸等激素的含量会像**接力**一样按次序出现高峰，调节果实的发育和成熟。

!!! note "总结"
    植物的生长、发育，是由多种激素相互作用形成的**调节网络**调控的。

## 生活实例分析

???+ question "一个烂苹果会糟蹋一筐好苹果"
    成熟苹果释放大量**乙烯**，乙烯可促进其他果实成熟，并诱导周围水果自身产生乙烯，加速成熟（进而腐烂）。所以一个烂苹果会加速整筐苹果成熟腐烂。

???+ question "小麦、玉米在即将成熟时遇干热后又遇大雨，种子易在穗上发芽"
    脱落酸能维持种子休眠、抑制萌发；**脱落酸在高温条件下容易降解**，持续干热使种子中脱落酸含量下降，再遇大雨提供水分，种子便解除休眠在穗上发芽。

## 核心概念速记

```
赤霉素：幼芽幼根未成熟种子 → 促伸长、促萌发开花果实发育
细胞分裂素：根尖 → 促细胞分裂、芽分化
脱落酸：根冠萎蔫叶片 → 抑制分裂、促衰老脱落、维持休眠
乙烯：各部位 → 促果实成熟、促脱落
第六类激素：油菜素内酯
器官发育取决于激素相对含量（比例），多种激素形成调节网络
```
