# 环境因素参与调节植物的生命活动

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 概述

高等植物的生长发育受环境因素调节，**光、温度、重力**对植物生长发育的调节作用尤为重要。

---

## 光对植物生长发育的调节

光不仅是植物进行光合作用的**能量来源**，还是一种**信号**，影响、调控植物生长、发育的全过程。

| 生命现象 | 实例 |
|----------|------|
| 种子萌发 | 烟草、莴苣的种子需在有光条件下才能萌发；洋葱、番茄的种子萌发受光抑制 |
| 形态建成 | 豆芽在黑暗中培育，茎（下胚轴）比光下长很多；见光后发生形态变化长成豆苗 |
| 开花 | 菠菜只有白天长度超过 13 小时才开花；菊、水稻要在白天短于一定时长才开花（也有不少植物与昼夜长短无关，如黄瓜、棉花、向日葵） |

### 光敏色素

植物具有能接收光信号的分子，**光敏色素**是其中的一种。

- **化学本质**：一类蛋白质（**色素—蛋白复合体**），分布在植物各个部位，在**分生组织**细胞内比较丰富；
- **吸收光谱**：主要吸收**红光和远红光**；植物体内还有感受**蓝光**的受体，环境中的红光、蓝光对植物生长发育非常关键；
- **作用机制**：

!!! note "适应意义"
    种子萌发、植株生长、开花、衰老都受到光的调控，使植物的生命活动与外界环境（光照条件、季节变化）相协调，体现了植物对环境的适应。

## 温度和重力等环境因素的调节

### 温度

- 植物的所有生理活动都是在一定的温度范围内进行；
- 温度通过影响**种子萌发、植株生长、开花结果和叶的衰老、脱落**等生命活动，参与调节植物的生长发育；
- 植物分布的**地域性**很大程度上由温度决定。

| 实例 | 说明 |
|------|------|
| **年轮** | 春夏季细胞分裂快、细胞体积大，形成颜色较浅的带；秋冬季细胞分裂慢、细胞体积较小，形成颜色较深的带 |
| **春化作用** | 冬小麦、冬大麦、蕙兰等在生长期需要经历一段时期的**低温**之后才能开花；经历低温诱导促使植物开花的作用称为春化作用 |

### 重力

重力是调节植物生长发育和形态建成的**重要环境因素**：根向地生长、茎背地生长就是在重力调节下形成的。

**"淀粉—平衡石假说"**（被普遍承认的解释）：

- 植物对重力的感受是通过体内一类富含"**淀粉体**"的细胞，即**平衡石细胞**来实现的；
- 当根的放置方向改变时，平衡石细胞中的淀粉体沿**重力方向沉降**，引起植物体内一系列信号分子的改变；
- 通过影响**生长素的运输**，导致生长素沿着重力刺激的方向**不对称分布**，从而造成重力对植物生长的影响（根近地侧生长素浓度高，抑制生长，根向下弯曲；茎近地侧生长素浓度高，促进生长，茎向上弯曲）。

!!! question "意义"
    根向地生长有利于吸收水分和无机盐，茎背地生长有利于接受光照进行光合作用，都是对环境的适应。

## 植物生长发育的整体调控

高等植物的正常生长发育需要各个器官、组织、细胞之间的协调和配合。植物生长发育的调控，是由**基因表达调控、激素调节和环境因素调节共同完成**的。

<div class="mermaid">
graph TB
    G[基因表达调控] --> P[植物生长发育]
    H[激素调节] --> P
    E[环境因素调节：光、温度、重力] --> P
    G -->|决定| H
    E -->|影响| H
    H -->|作为信息分子影响| G
</div>

| 层次 | 调控机制 |
|------|----------|
| **基因水平** | 植物细胞储存全套基因，但某个细胞的基因如何表达会根据需要作调整；生长、发育、繁殖、休眠都处在基因**适时选择性表达**的调控之下 |
| **细胞/器官间** | 细胞与细胞、器官与器官之间的协调，需要通过**激素传递信息**；激素作为信息分子影响细胞的基因表达，从而起调节作用 |
| **个体水平** | 激素的产生和分布是基因表达调控的结果，也受到环境因素的影响；植物响应环境变化，调控基因表达以及激素产生、分布，最终表现在器官和个体水平上的变化 |

## 科学·技术·社会：调控花期创造美好生活

人工控制花期可使植物提前或延后开花，满足节日需求和生产需要。主要途径有四种：

1. **温度处理**：利用温度调控促进或抑制花芽发育；
2. **光照处理**：控制光照时间长短（如夜间补光促使火龙果提前开花）；
3. **生长调节剂处理**：施用植物生长调节剂；
4. **栽培措施处理**：调节种植期，采用适当的修剪、摘心、水肥控制等。

例如，菊花本在秋天开放，如今四季可见；2008 年北京奥运会期间，园林技术人员通过调控使月季在夏季连续盛开。

## 核心概念速记

```
光：能量来源 + 信号；光敏色素（色素-蛋白复合体）吸收红光/远红光 → 基因表达
温度：影响萌发、生长、开花、衰老；年轮、春化作用
重力：淀粉—平衡石假说 → 生长素不对称分布 → 根向地、茎背地
整体调控 = 基因表达调控 + 激素调节 + 环境因素调节（相互作用、协调配合）
```
