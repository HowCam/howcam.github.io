# 植物生长调节剂的应用

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 植物生长调节剂

**植物生长调节剂**：由**人工合成**的，对植物的生长、发育有调节作用的化学物质。

**优点**：原料广泛、容易合成、效果稳定，在农林园艺生产上得到广泛应用。

!!! note "与植物激素的区别"
    植物激素是植物体内产生的；植物生长调节剂是人工合成的，但具有与植物激素相似的生理效应。

### 类型

| 类型 | 特点 | 举例 |
|------|------|------|
| 分子结构和生理效应与植物激素**类似** | 结构相似、效应相似 | **吲哚丁酸（IBA）** |
| 分子结构与植物激素差别较大，但具有**类似的生理效应** | 结构不同、效应相似 | **α-萘乙酸（NAA）、矮壮素、2,4-D、乙烯利、青鲜素、膨大剂** |

!!! warning "管理"
    在我国，植物生长调节剂属于**农药管理范围**，只有取得农药登记并获得生产许可的产品才能生产、经营和使用。

## 应用实例

| 实例 | 使用的调节剂 | 效果 |
|------|--------------|------|
| 啤酒生产 | **赤霉素**处理大麦 | 使大麦种子无须发芽就能产生 α-淀粉酶 |
| 葡萄种植 | 赤霉素、细胞分裂素类物质 | 提高结果率和单果质量，提高无核化程度；施用不合理会造成果实空心 |
| 西瓜、草莓、葡萄 | 一定浓度的**膨大剂（膨大素）** | 长势加快、个头变大、提前上市；但口感差、汁水少、甜味不足、不耐储存 |
| 马铃薯、大蒜、洋葱 | **青鲜素**（抑制发芽） | 延长储藏期；可能有副作用，会损害人体健康 |
| 水果催熟 | **乙烯利** | 释放乙烯催熟水果 |
| 扦插繁殖 | 生长素类调节剂（NAA、2,4-D 等） | 促进插条生根 |
| 调控花期 | 多种调节剂 | 使植物提前或延后开花 |

!!! note "理性评估"
    植株自身能合成激素，但人工合成的调节剂具有**效果稳定、原料广泛、容易合成**等优点，可满足特定生产需求。是否施用、如何施用，需要理性评估；施用不当不仅达不到预期目的，反而造成损失。

## 植物生长调节剂的施用

### 需考虑的因素

1. 根据实际情况选择**恰当的**植物生长调节剂；
2. 综合考虑施用**目的、效果和毒性**，以及调节剂残留、价格和施用是否方便等；
3. 对某种调节剂，施用**浓度、时间、部位**以及施用时植物的**生理状态和气候条件**等都会影响效果。

!!! info "法规要求"
    我国对植物生长调节剂的生产、销售和使用有明确规定：必须经国家指定单位检验并进行正规田间试验，充分证明其效益、**无毒无害**方可批准登记；禁止夸大功能；禁止在肥料中添加植物生长调节剂。

!!! note "正确认识"
    植物生长调节剂**不是营养物质，也不是万灵药**，只有配合浇水、施肥等措施，适时施用才能发挥效果。过量使用可能对人体健康和环境带来不利影响。

## 探究·实践：探索植物生长调节剂的应用

### 一、探索生长素类调节剂促进插条生根的最适浓度

**提出问题**：所选定的生长素类调节剂促进某种植物插条生根的最适浓度是多少？

**材料用具**：一年生枝条、蒸馏水、花盆、细沙；生长素类调节剂（NAA、2,4-D、吲哚丙酸、IBA 中选一种）等。

**处理插条的方法**：

| 方法 | 操作 | 适用 |
|------|------|------|
| **浸泡法** | 插条基部浸泡在溶液中，深约 3 cm，处理几小时至一天 | 溶液**浓度较小**，最好在遮阴、空气湿度较高处进行 |
| **沾蘸法** | 插条基部在浓度较高的药液中沾蘸约 5 s，深约 1.5 cm | 溶液**浓度较高** |

**设计要点**：

1. 设置合理的**浓度梯度**：可参考植物体内天然生长素含量或查找资料；所知不多时先设计梯度较大的**预实验**摸索，再设计更合理的浓度梯度；
2. 注意控制**无关变量**：处理时间长短一致、植物材料条件尽可能相同；
3. 确定**因变量的检测指标**：如根的数目、根的长度等。

**分析结果**：以调节剂浓度为横坐标、根的数目为纵坐标绘制曲线图，确定最适浓度范围。

!!! info "预实验"
    在正式实验前先做预实验，可以为进一步实验**摸索条件**，也可以检验实验设计的**科学性和可行性**。预实验也必须像正式实验一样认真进行才有意义。

### 二、尝试利用乙烯利催熟水果

- **原理**：乙烯利工业品为液体，pH < 3.5 时较稳定；随溶液 pH 升高，分解释放**乙烯**。乙烯对水果有催熟作用，还能进一步**诱导水果自身产生乙烯**，加速成熟。
- **注意事项**：乙烯利对皮肤、黏膜有刺激性，需做好防护并在通风良好处操作；遇明火可燃烧，需注意防火。

## 核心概念速记

```
植物生长调节剂 = 人工合成的、有调节作用的化学物质（原料广、易合成、效果稳定）
两类：结构效应类似（IBA）/ 结构不同效应类似（NAA、乙烯利、矮壮素）
施用考虑：浓度、时间、部位、植物生理状态、气候条件
探索最适浓度：预实验 → 浓度梯度 → 控制无关变量 → 因变量（生根数）
不是营养物质，也不是万灵药，需配合水肥
```
