# 特异性免疫

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 免疫系统对病原体的识别

人体所有细胞膜表面都有多种不同的蛋白质，其中包括作为**分子标签**起作用的一组蛋白质，能被自身免疫细胞识别。病毒、细菌等病原体也带有各自的身份标签，侵入人体后可被免疫细胞通过细胞表面的**受体**辨认出来。

当病原体突破前两道防线，第三道防线的"作战部队"（主要是**淋巴细胞**）就会紧急动员起来，产生特异性免疫。为研究方便，人为地将其"作战"方式分为**体液免疫**和**细胞免疫**两种。

---

## 体液免疫

**体液免疫**：B 细胞激活后可以产生抗体，由于抗体存在于体液中，这种主要靠**抗体**"作战"的方式称为体液免疫。

### 基本过程

1. 一些病原体可以和 **B 细胞接触**，这为激活 B 细胞提供了**第一个信号**；
2. 一些病原体被树突状细胞、B 细胞等**抗原呈递细胞（APC）**摄取；
3. APC 将抗原处理后呈递在细胞表面，然后传递给**辅助性 T 细胞**；
4. 辅助性 T 细胞表面的特定分子发生变化并与 B 细胞结合，这是激活 B 细胞的**第二个信号**；辅助性 T 细胞开始分裂、分化，并分泌**细胞因子**；
5. B 细胞受到**两个信号**刺激后开始分裂、分化，大部分分化为**浆细胞**，小部分分化为**记忆 B 细胞**；细胞因子能促进该过程；
6. 浆细胞产生和分泌大量**抗体**，抗体随体液在全身循环并与病原体结合，抑制病原体的增殖或对人体细胞的黏附。

!!! note "要点"
    - B 细胞活化需要**两个信号**，还需要**细胞因子**的作用。
    - 在多数情况下，抗体与病原体结合后会形成**沉淀**等，进而被其他免疫细胞吞噬消化。
    - **记忆细胞**可在抗原消失后存活几年甚至几十年；再次接触相同抗原时，能迅速增殖分化，快速产生大量抗体（二次免疫反应更快、更强）。
    - 通常一个 B 细胞只针对一种特异病原体，只产生一种特异性抗体；人体内 B 细胞种类在 $10^9$ 以上。

## 细胞免疫

**细胞免疫**：当病原体进入细胞内部，就要靠 **T 细胞直接接触靶细胞**来"作战"，这种方式称为细胞免疫。

### 基本过程

1. 被病原体（如病毒）感染的宿主细胞（**靶细胞**）膜表面的某些分子发生变化，**细胞毒性 T 细胞**识别变化的信号；
2. 细胞毒性 T 细胞**分裂并分化**，形成新的细胞毒性 T 细胞和**记忆 T 细胞**；细胞因子能加速这一过程（辅助性 T 细胞的活化及分泌细胞因子过程与体液免疫类似）；
3. 新形成的细胞毒性 T 细胞在体液中循环，识别并接触、裂解被**同样病原体**感染的靶细胞；
4. 靶细胞裂解、死亡后，病原体暴露出来，抗体可以与之结合，或被其他细胞吞噬掉。

!!! note "辅助性 T 细胞的关键作用"
    B 细胞和细胞毒性 T 细胞的活化都离不开辅助性 T 细胞的辅助，可见**辅助性 T 细胞在体液免疫和细胞免疫中都起着关键的作用**。

## 体液免疫与细胞免疫的协调配合

| 比较 | 体液免疫 | 细胞免疫 |
|------|----------|----------|
| 作战方式 | 主要靠**抗体** | 主要靠**细胞毒性 T 细胞**直接接触靶细胞 |
| 作战对象 | **细胞外液中的病原体** | **侵入细胞内的病原体**（靶细胞） |
| 主要细胞 | B 细胞、浆细胞、记忆 B 细胞、辅助性 T 细胞 | 细胞毒性 T 细胞、记忆 T 细胞、辅助性 T 细胞 |
| 联系 | 抗体消灭细胞外病原体；细胞免疫使靶细胞裂解，病原体暴露后抗体才能发挥作用 | 裂解靶细胞，使病原体失去藏身之所 |

**二次免疫**：相同抗原再次入侵时，记忆 B 细胞和记忆 T 细胞会迅速增殖分化，快速、高效地产生免疫反应。

## 神经—体液—免疫调节网络

越来越多的证据表明，神经系统、内分泌系统与免疫系统之间存在相互调节，通过**信息分子**构成一个复杂网络：

| 系统 | 信息分子 |
|------|----------|
| 神经系统 | 神经递质（如乙酰胆碱） |
| 内分泌系统 | 激素（如 TRH、甲状腺激素、糖皮质激素） |
| 免疫系统 | 细胞因子（如白细胞介素、干扰素、肿瘤坏死因子） |

!!! note "作用特点"
    神经调节、体液调节和免疫调节的实现都离不开信号分子，这些信号分子的作用方式都是**直接与受体接触**。受体一般是蛋白质分子，不同受体结构各异，因此信号分子与受体的结合具有**特异性**。三个系统各自以特有的方式在维持内环境稳态中发挥作用，**任何一方都不能取代另外两方**。

## 科学·技术·社会

- **流感**：流感病毒分为甲、乙、丙三型，表面有血凝素（HA）和神经氨酸酶（NA），极易突变（如 H1N1、H3N2、H5N1、H7N9）；接种疫苗是普遍采用的预防措施，但不能应对新发突变。
- **癌症的免疫疗法**：在体外改造病人自身 T 细胞使其识别特定癌细胞并大量增殖后回输；使用 **PD-1 或 PD-L1 抗体**阻断肿瘤细胞逃避免疫系统的信号通路，使 T 细胞有效对付癌细胞。

## 核心概念速记

```
体液免疫：B 细胞（双信号 + 细胞因子）→ 浆细胞 → 抗体
细胞免疫：细胞毒性 T 细胞 → 裂解靶细胞 → 病原体暴露
辅助性 T 细胞：两种免疫的关键"辅助"
记忆细胞：二次免疫快速、高效
三大系统通过信息分子 + 特异性受体构成调节网络
```
