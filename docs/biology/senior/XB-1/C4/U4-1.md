# 免疫系统的组成和功能

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 免疫系统的组成

免疫系统是人体的"安全保卫部"，主要包括**免疫器官、免疫细胞和免疫活性物质**。

    I[免疫系统] --> O[免疫器官]
    I --> C[免疫细胞]
    I --> M[免疫活性物质]
    O --> O1[骨髓、胸腺：免疫细胞生成、成熟场所]
    O --> O2[脾、淋巴结、扁桃体：免疫细胞集中分布场所]
    C --> C1[淋巴细胞：B 细胞（骨髓成熟）、T 细胞（胸腺成熟）]
    C --> C2[树突状细胞、巨噬细胞等]
    M --> M1[抗体、细胞因子、溶菌酶等]
</div>

### 免疫器官

免疫器官主要由**淋巴组织**构成，并借助血液循环和淋巴循环相互联系。

| 免疫器官 | 功能 |
|----------|------|
| **骨髓** | 位于骨髓腔或骨松质内，是各种免疫细胞的**发生地**，是 **B 细胞分化、发育、成熟的场所**，是机体重要的免疫器官 |
| **胸腺** | 位于胸骨后面，是 **T 细胞分化、发育、成熟的场所**；随年龄增长，青春期达到高峰，以后逐渐退化 |
| **脾** | 位于胃的左侧，内含大量淋巴细胞，参与制造新的血细胞与清除衰老的血细胞 |
| **淋巴结** | 沿淋巴管遍布全身（颈部、腋窝、腹股沟等），是淋巴细胞集中的地方，能阻止和消灭侵入体内的微生物 |
| **扁桃体** | 咽腭部，左右各一，内部有很多免疫细胞，具有防御功能 |

!!! note "战场比喻"
    骨髓和胸腺就像部队的**大本营和训练基地**；脾、淋巴结和扁桃体是免疫细胞集中分布的场所，也是它们"作战"的**战场**。

### 免疫细胞

免疫细胞是执行免疫功能的细胞，来自骨髓的**造血干细胞**，包括各种类型的白细胞：

| 细胞 | 特点与功能 |
|------|-----------|
| **B 淋巴细胞（B 细胞）** | 在骨髓中成熟；在免疫反应中起重要作用 |
| **T 淋巴细胞（T 细胞）** | 迁移到胸腺成熟；分为**辅助性 T 细胞**和**细胞毒性 T 细胞**等 |
| **树突状细胞** | 分布于皮肤、消化道、呼吸道等上皮组织及淋巴器官，成熟时具有分支，具有强大的**吞噬、呈递抗原**功能 |
| **巨噬细胞** | 几乎分布于机体各种组织，具有**吞噬消化、抗原处理和呈递**功能 |

**抗原（antigen）**：能引发免疫反应的物质（病原体表面特定的蛋白质等），大多数抗原是蛋白质，可游离，也可存在于细菌、病毒等病原微生物以及细胞上。

**抗原呈递细胞（APC）**：B 细胞、树突状细胞和巨噬细胞都能摄取和加工处理抗原，并将抗原信息暴露在细胞表面，以便呈递给其他免疫细胞。

### 免疫活性物质

**免疫活性物质**：由免疫细胞或其他细胞产生的、并发挥免疫作用的物质。

| 物质 | 作用 |
|------|------|
| **抗体（antibody）** | 机体产生的专门应对抗原的蛋白质，能与相应抗原发生**特异性结合**（一种抗体只能与特定抗原结合），可随血液和淋巴循环到达全身 |
| **细胞因子** | 如白细胞介素、干扰素、肿瘤坏死因子等，由淋巴细胞等分泌 |
| **溶菌酶** | 体液中的杀菌物质 |

!!! info "抗体应用"
    新型冠状病毒感染康复者的血清中含有针对该病毒的抗体，提取血清输给临床病人，其中的抗体可与病毒结合使病毒失活，有助于病人康复。

## 免疫系统的基本功能

人体有三道防线抵御病原体攻击：

| 防线 | 组成 | 特点 |
|------|------|------|
| 第一道防线 | **皮肤、黏膜** | 人人生来就有，不针对特定病原体，对多种病原体都有防御作用 |
| 第二道防线 | 体液中的**杀菌物质**（如溶菌酶）和**吞噬细胞**（如巨噬细胞、树突状细胞） | 同上 |
| 第三道防线 | 机体在个体发育过程中与病原体接触后获得 | 针对特定抗原起作用，具有**特异性** |

前两道防线属于**非特异性免疫**，第三道防线属于**特异性免疫**。三道防线是统一的整体，共同实现免疫系统的三大基本功能：

| 功能 | 含义 | 异常时的表现 |
|------|------|--------------|
| **免疫防御** | 机体排除外来抗原性异物的一种免疫防护作用，是免疫系统**最基本**的功能 | 反应过强、过弱或缺失 → 组织损伤或易被病原体感染 |
| **免疫自稳** | 机体清除衰老或损伤的细胞，进行自身调节，维持内环境稳态 | 对自身抗原发生免疫反应 → **自身免疫病** |
| **免疫监视** | 机体识别和清除突变的细胞，防止肿瘤发生 | 功能低下或失调 → 肿瘤发生或持续病毒感染 |

## 生物科技进展：免疫系统的新发现

2015 年，科学家在小鼠脑组织中发现免疫细胞并呈管状分布，确定了**脑中淋巴管**的存在；2017 年公布了人脑淋巴管磁共振成像图。这一发现丰富了人类对**神经—体液—免疫调节网络**维持内环境稳态的认识。

## 核心概念速记

```
免疫系统 = 免疫器官 + 免疫细胞 + 免疫活性物质
T 细胞在胸腺成熟，B 细胞在骨髓成熟
APC（B 细胞、树突状细胞、巨噬细胞）：摄取、加工、呈递抗原
三道防线：皮肤黏膜 / 杀菌物质+吞噬细胞 / 特异性免疫
三大功能：免疫防御、免疫自稳、免疫监视
```
