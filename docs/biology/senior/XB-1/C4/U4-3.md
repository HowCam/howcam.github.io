# 免疫失调

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 过敏反应

**过敏反应**：已免疫的机体，在**再次接触相同的抗原**时，有时会发生引发组织损伤或功能紊乱的免疫反应。

- **过敏原**：引起过敏反应的抗原物质，如鱼、虾、牛奶、蛋类、花粉、花生、室内尘土、磺胺、奎宁、宠物皮屑、棉絮等。
- 全世界 20%～40% 的人被过敏问题困扰。

### 发生机理

<div class="mermaid">
graph LR
    A[过敏原首次进入] --> B[B 细胞活化产生抗体]
    B --> C[抗体吸附在肥大细胞等表面]
    D[相同过敏原再次进入] --> C
    C --> E[肥大细胞释放组胺等物质]
    E --> F[毛细血管扩张、通透性增强、平滑肌收缩、腺体分泌增多]
    F --> G[皮肤红肿、发疹、流涕、打喷嚏、哮喘、呼吸困难]
</div>

!!! note "特点"
    - 过敏反应有快慢之分：可能在接触过敏原后数分钟内出现，也可能 24 h 后才有症状；
    - 许多过敏反应有明显的**遗传倾向**和**个体差异**。

!!! tip "预防"
    找出过敏原并且**尽量避免再次接触**该过敏原，是预防过敏反应发生的主要措施；自己不能找出时可由医生通过医学方法检测；出现症状应及时就医。

## 自身免疫病

**自身免疫病**：在某些特殊情况下，免疫系统也会对自身成分发生反应，如果自身免疫反应对组织和器官造成损伤并出现了症状，就称为自身免疫病。

| 疾病 | 成因/症状 |
|------|-----------|
| **风湿性心脏病** | 某种链球菌表面抗原与心脏瓣膜上某物质结构十分相似，免疫系统攻击病菌的同时也攻击心脏瓣膜 |
| **类风湿关节炎** | 常见自身免疫病，累及关节 |
| **系统性红斑狼疮** | 累及多个器官，病程缓解与发作交替；主要症状有发热、关节痛、红斑、大量脱发、白细胞减少等；多见于年轻女性，我国发病率约 0.75‰；与遗传、免疫失调、内分泌异常及环境等多因素有关 |

!!! info "治疗前景"
    对病情严重的自身免疫病患者进行**自体造血干细胞移植**是一种很有前景的治疗方法。

## 免疫缺陷病

**免疫缺陷病**：由机体免疫功能不足或缺乏而引起的疾病。

| 类型 | 成因 | 实例 |
|------|------|------|
| **先天性免疫缺陷病** | 遗传而生来就有免疫缺陷 | 重症联合免疫缺陷病：与淋巴细胞发育有关的基因突变或缺陷引起，患者多为新生儿和婴幼儿，体液免疫和细胞免疫均有严重缺陷，任何病原体感染都可能致命 |
| **获得性免疫缺陷病** | 由疾病和其他因素引起 | 艾滋病（AIDS）；**大多数免疫缺陷病属于此类** |

### HIV 与艾滋病

**艾滋病（AIDS）**：由**人类免疫缺陷病毒（HIV）**引起。HIV 主要侵入并破坏人体的**辅助性 T 细胞**，逐渐使免疫系统瘫痪、功能瓦解，最终使人无法抵抗其他病毒、病菌的入侵，或发生恶性肿瘤而死亡。

| 项目 | 内容 |
|------|------|
| 病毒类型 | **逆转录病毒**，核酸为两条相同的 RNA 链，含逆转录酶 |
| 主要侵染细胞 | **辅助性 T 细胞** |
| 潜伏期 | 通常 2～10 年甚至更长；期间 HIV 迅速增殖，机体产生抗 HIV 抗体（**HIV 检测的重要依据**） |
| 病程发展 | 辅助性 T 细胞数量持续下降 → 免疫系统功能减退 → 淋巴结肿大、发热、体重下降 → 死于严重感染或恶性肿瘤 |
| 传播途径 | **性接触传播、血液传播、母婴传播** |

!!! note "一般接触不传播"
    与 HIV 感染者的一般接触（如握手、拥抱）**不会**感染 HIV；对待艾滋病病人应少一份歧视，多一份关爱。

**预防艾滋病的做法**：

1. 采取安全的性行为，如使用避孕套；
2. 避免注射时经血液传播，不吸毒；
3. 发生易感行为后主动检测并积极治疗；
4. 不与他人共用牙刷和剃须刀；
5. 不用未经消毒的器械文眉、穿耳等。

我国对 HIV 感染者或艾滋病患者实行"**发现就治疗，而且免费**"并遵循自愿原则；健康中国行动目标是到 2030 年艾滋病全人群感染率控制在 0.2% 以下。

!!! warning "细胞因子风暴"
    某些新冠患者体内出现"细胞因子风暴"，是免疫系统过度反应、大量分泌细胞因子导致的组织损伤。

## 核心概念速记

```
过敏反应：已免疫机体再次接触相同过敏原 → 抗体吸附肥大细胞 → 组胺释放
自身免疫病：免疫系统攻击自身物质（风湿性心脏病、类风湿关节炎、红斑狼疮）
免疫缺陷病：先天性（重症联合免疫缺陷）/ 获得性（艾滋病）
HIV：逆转录病毒，侵染辅助性 T 细胞，传播途径为性、血液、母婴
一般接触（握手、拥抱）不传播 HIV
```
