## 疫苗

**疫苗（vaccine）**：通常是用**灭活的或减毒的病原体**制成的生物制品。接种疫苗后，人体内可产生相应的**抗体**，从而对特定传染病具有抵抗力。

**原理**：利用免疫系统的**特异性**和**记忆性**——给机体输入外源抗原，免疫系统产生特异性反应，且免疫力能维持较长时间。

| 项目 | 实例 |
|------|------|
| 我国最早用免疫方法预防传染病 | 人痘接种预防天花 |
| 巴斯德 | 研制疫苗，开创科学免疫接种的新时期 |
| 消灭的传染病 | 天花（天花疫苗根除） |
| 常见疫苗 | 卡介苗、脊髓灰质炎疫苗（"糖丸"）、麻疹疫苗 |
| 第一个预防癌症的疫苗 | 2006 年 HPV 疫苗获批上市，可预防由 HPV 引起的几种子宫颈癌 |
| 新型基因工程疫苗 | 2018 年 5 月，我国首个 DNA 疫苗获得新兽药证书（预防某亚型禽流感） |

!!! question "接种疫苗后为何可能有轻微反应？"
    疫苗作为抗原进入机体，会引起一定的免疫反应（如轻微发热），这是免疫系统被激活、产生抗体和记忆细胞的正常表现。

!!! note "流感疫苗为何不终生有效？"
    流感病毒极易发生变异，疫苗只能针对特定抗原起作用；当病毒表面抗原发生改变后，原有抗体和记忆细胞不能识别新病毒，因此流感疫苗需每年接种。而麻疹病毒抗原稳定，接种一次可获终生免疫。

## 器官移植

**器官移植（organ transplantation）**：医学上把用正常的器官置换丧失功能的器官，以重建其生理功能的技术。

### 免疫排斥与 HLA

- 每个人的细胞表面都带有一组与别人不同的蛋白质——**组织相容性抗原**，也叫**人类白细胞抗原（HLA）**，是标明细胞身份的标签物质；
- 正常情况下，白细胞认识自身的 HLA，不会攻击自身细胞；移植他人的器官或组织时，白细胞识别出 HLA 不同而发起**攻击**，这就是器官移植容易失败的原因；
- **器官移植的成败主要取决于供者与受者的 HLA 是否一致或相近**。除同卵双胞胎外，几乎找不到两个 HLA 完全一致的人；研究表明，只要供者与受者的**主要 HLA 有一半以上相同**，就可以进行器官移植。

### 面临的问题与对策

| 问题 | 对策 |
|------|------|
| 免疫排斥 | 使用**免疫抑制剂**大大提高成活率；但会使淋巴细胞减少，患者容易患感染性疾病 |
| 供体器官短缺 | 利用**自体干细胞**培养相应的组织、器官；倡导自愿捐献器官 |
| 分配公平 | 2013 年中国人体器官分配与共享计算机系统启用，以病情紧急度和供受者匹配程度等客观医学指标由计算机自动分配，最大程度排除人为干预 |

!!! note "免疫抑制剂的其他应用"
    治疗类风湿关节炎、系统性红斑狼疮等自身免疫病常使用免疫抑制剂。

## 免疫学的其他应用

| 应用领域 | 说明 |
|----------|------|
| **免疫预防** | 接种疫苗预防传染病 |
| **免疫诊断** | 利用抗原和抗体反应的**高度特异性**，检测病原体和肿瘤标志物等 |
| **免疫治疗** | 与手术、化疗、放疗并列的重要治疗方法：对免疫功能低下者使用**免疫增强疗法**，对某些疾病（如自身免疫病）使用**免疫抑制疗法** |

## 与生物学有关的职业：疫苗制品工

疫苗制品工是从事细菌性疫苗、病毒性疫苗、类毒素等生产的人员，主要工作包括：

1. 制备特殊原始辅料，配制培养基；
2. 对培养基、设备等进行消毒灭菌，去除杂质；
3. 用发酵罐、生物反应器、摇床等培养微生物或细胞，收集病毒液，灭活或杀菌；
4. 用离心、过滤、纯化等设备分离，提取有效成分；
5. 配制稀释液、保护剂、吸附剂，除菌过滤或冷冻干燥、标记、分装、包装。

流感疫苗的主要"工厂"是**鸡胚**（1937 年用鸡胚培养流感病毒获得成功）。疫苗制品关系千万人的健康，每个环节都需要认真、谨慎与强烈的社会责任感。

## 核心概念速记

```
疫苗 = 灭活或减毒的病原体制成的生物制品（利用特异性 + 记忆性）
器官移植成败关键：供受者 HLA 是否一致或相近（主要 HLA 一半以上相同）
免疫排斥 → 免疫抑制剂；供体短缺 → 干细胞培养器官、自愿捐献
免疫学应用：免疫预防、免疫诊断、免疫治疗
```
