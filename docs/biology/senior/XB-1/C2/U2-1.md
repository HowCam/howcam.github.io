# 神经调节的结构基础

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

## 神经系统的基本结构

人的神经系统包括**中枢神经系统**和**外周神经系统**两部分。

    N[神经系统] --> CNS[中枢神经系统]
    N --> PNS[外周神经系统]
    CNS --> B[脑]
    CNS --> S[脊髓]
    B --> BR[大脑：最高级中枢]
    B --> XN[小脑：协调运动、维持平衡]
    B --> GN[脑干：呼吸、心血管等生命中枢]
    B --> XQ[下丘脑：体温、水平衡、生物节律]
    PNS --> J[脑神经 12 对]
    PNS --> JG[脊神经 31 对]
    J --> SN[传入神经 / 传出神经]
    JG --> SN
    SN --> ZY[躯体运动神经]
    SN --> ZN[内脏运动神经（自主神经系统）]
    ZN --> G[交感神经]
    ZN --> F[副交感神经]

### 中枢神经系统

**中枢神经系统**包括脑（大脑、脑干和小脑等，位于颅腔内）和脊髓（位于椎管内）。在中枢神经系统内，大量神经细胞聚集在一起，形成许多不同的**神经中枢**，分别负责调控某一特定的生理功能。

| 结构 | 位置 | 主要功能 |
|------|------|----------|
| **大脑** | 颅腔内，包括左右两个大脑半球 | 表面是**大脑皮层**，是调节机体活动的**最高级中枢** |
| **小脑** | 大脑的后下方 | 协调运动，维持身体平衡 |
| **脑干** | 连接脊髓和脑其他部分 | 有许多维持生命的必要中枢，如调节呼吸、心脏功能的基本活动中枢 |
| **下丘脑** | 脑的重要组成部分 | 有**体温调节中枢、水平衡调节中枢**等，还与生物节律等的控制有关 |
| **脊髓** | 椎管内 | 是脑与躯干、内脏之间的联系通路，是调节运动的**低级中枢**（如膝跳反射中枢） |

### 外周神经系统

外周神经系统分布在全身各处，包括与脑相连的**脑神经（12 对）**和与脊髓相连的**脊神经（31 对）**：

- 脑神经主要分布在头面部，负责管理头面部的感觉和运动；
- 脊神经主要分布在躯干、四肢，负责管理躯干、四肢的感觉和运动；
- 脑神经和脊神经中都有支配内脏器官的神经。

外周神经系统都含有：

| 类型 | 功能 |
|------|------|
| **传入神经**（感觉神经） | 将接收到的信息传递到中枢神经系统 |
| **传出神经**（运动神经） | 将中枢的指令信息传输到相应器官，使机体对刺激作出反应 |

传出神经又分为：

- **躯体运动神经**：支配躯体运动，明显受意识支配；
- **内脏运动神经**：支配内脏器官，不受意识支配。

## 自主神经系统

**自主神经系统**：支配内脏、血管和腺体的传出神经，它们的活动**不受意识支配**。

由**交感神经**和**副交感神经**两部分组成，二者的作用通常是**相反的**。

| 器官 | 交感神经兴奋（兴奋状态占优势） | 副交感神经兴奋（安静状态占优势） |
|------|------------------------------|----------------------------------|
| 眼 | 使瞳孔扩张 | 使瞳孔收缩 |
| 肺（支气管） | 使支气管扩张 | 使支气管收缩 |
| 心脏 | 使心跳加快 | 使心跳减慢 |
| 胃肠 | 抑制胃肠蠕动 | 促进胃肠蠕动 |
| 血管 | 使血管收缩 | — |

!!! note "油门与刹车"
    交感神经和副交感神经对同一器官的作用犹如汽车的**油门和刹车**，可以使机体对外界刺激作出更精确的反应，使机体更好地适应环境的变化。

!!! question "思考"
    如果呼吸或心跳必须在意识支配下完成，将会出现什么结果？——睡眠时呼吸、心跳会停止，无法维持生命活动。

## 组成神经系统的细胞

组成神经系统的细胞主要包括**神经元**和**神经胶质细胞**两大类。

### 神经元

**神经元（neuron）**是神经系统结构与功能的**基本单位**，由胞体、树突和轴突等部分构成。

| 结构 | 特点与功能 |
|------|-----------|
| **胞体** | 神经元的膨大部分，里面含有细胞核 |
| **树突** | 胞体向外伸出的树枝状突起，通常短而粗，用来**接收信息**并传导到胞体 |
| **轴突** | 长而较细的突起，将信息从胞体**传向**其他神经元、肌肉或腺体 |
| **髓鞘** | 轴突外表大都套有一层髓鞘；轴突呈纤维状，与髓鞘构成**神经纤维** |
| **神经** | 许多神经纤维集结成束，外面包有一层包膜，构成一条神经 |
| **神经末梢** | 树突和轴突末端的细小分支，分布在全身各处 |

!!! info "轴突可以很长"
    支配人足部肌肉的轴突长度可以超过 1 m；长颈鹿体内从头部延伸到骨盆的轴突大约有 3 m 长。

### 神经胶质细胞

- 广泛分布于神经元之间，数量为神经元数量的 **10～50 倍**；
- 是对神经元起**辅助作用**的细胞，具有**支持、保护、营养和修复**神经元等多种功能；
- 在外周神经系统中，神经胶质细胞参与构成神经纤维表面的髓鞘；
- 神经元与神经胶质细胞一起，共同完成神经系统的调节功能。

## 生物科技进展：脑细胞真的是死一个少一个吗

- 传统观点：高等动物的神经发生只存在于胚胎期或出生后的发育早期，成年后脑细胞死一个少一个。
- 1977 年起，科学家陆续在成年大鼠、金丝雀、人类等多种动物成体脑中发现**神经发生**（细胞增殖、分化、迁移和存活）。
- 影响因素：受多种激素和生长因子、环境与多种社会因素调节；随年龄增加神经发生量下降；复杂环境、跑动可增加海马中新生神经元数量；应激（剧烈温度变化、缺氧、创伤、精神紧张等）可抑制神经发生。
- 意义：丰富的学习和生活体验可促进脑中神经元产生，可能为修复疾病或创伤受损的大脑提供途径。

## 核心概念速记

```
神经系统 = 中枢神经系统（脑 + 脊髓）+ 外周神经系统（脑神经 12 对 + 脊神经 31 对）
自主神经系统 = 交感神经 + 副交感神经（作用通常相反，不受意识支配）
神经元 = 胞体 + 树突 + 轴突（结构与功能的基本单位）
神经纤维 = 轴突（或长树突）+ 髓鞘；神经 = 神经纤维束 + 包膜
```
