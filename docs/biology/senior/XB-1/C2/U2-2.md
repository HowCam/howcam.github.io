# 神经调节的基本方式

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 反射与反射弧

**反射（reflex）**：在**中枢神经系统**的参与下，机体对内外刺激所产生的**规律性应答反应**。反射是神经调节的**基本方式**。常见反射有缩手反射、眨眼反射、膝跳反射等。

**反射弧（reflex arc）**：完成反射的**结构基础**。

<div class="mermaid">
graph LR
    A[感受器] --> B[传入神经]
    B --> C[神经中枢]
    C --> D[传出神经]
    D --> E[效应器]
    S[刺激] --> A
</div>

| 环节 | 功能 |
|------|------|
| **感受器** | 接受一定的刺激后产生**兴奋** |
| **传入神经** | 将兴奋向神经中枢传导 |
| **神经中枢** | 对传入的信息进行分析和综合，产生兴奋 |
| **传出神经** | 将神经中枢的兴奋传到效应器 |
| **效应器** | 传出神经末梢和它所支配的**肌肉或腺体**等，对刺激作出应答 |

**兴奋（excitation）**：动物体或人体内的某些细胞或组织（如神经组织）感受外界刺激后，由相对静止状态变为显著活跃状态的过程。

!!! warning "反射完成的必要条件"
    反射活动需要经过**完整的反射弧**来实现。反射弧中任何环节在结构、功能上受损，反射就不能完成。

!!! note "感觉的形成"
    兴奋除了在反射弧中传导，还会在脑与脊髓等中枢神经系统中传导。例如缩手反射中，兴奋还会从脊髓的低级中枢传导到**大脑皮层**，从而产生感觉（所以先缩手、后感到疼痛，具有保护意义）。

## 非条件反射与条件反射

| 比较项目 | 非条件反射 | 条件反射 |
|----------|-----------|----------|
| 形成时间 | **生来就有**（出生后无须训练） | 出生后在生活过程中通过**学习和训练**形成 |
| 数量 | 有限 | 几乎是无限的 |
| 神经中枢 | 大脑皮层以下的中枢（如脊髓）即可完成 | 必须有**大脑皮层**参与 |
| 稳定性 | 一般是永久的、不消退 | 可建立，也可**消退** |
| 举例 | 缩手反射、膝跳反射、眨眼反射、婴儿吮吸 | 狗听到铃声分泌唾液、谈虎色变 |
| 意义 | 完成基本的、先天性的防御和生理活动 | 扩展机体对复杂环境的适应范围 |

### 条件反射的建立（以狗的唾液分泌为例）

1. 给狗喂食 → 分泌唾液（**非条件反射**，食物是**非条件刺激**）；
2. 只给铃声 → 不分泌唾液（铃声是**无关刺激**）；
3. 每次喂食前先响铃，随后立即喂食，重复多次；
4. 一段时间后，铃声单独出现也能引起唾液分泌 → 铃声转化为**条件刺激**，条件反射建立。

!!! note "条件反射建立的基础"
    条件反射是在**非条件反射**的基础上，通过学习和训练而建立的；建立之后要维持下去，还需要**非条件刺激的强化**。

### 条件反射的消退

如果反复应用条件刺激（铃声）而不给予非条件刺激（食物），条件反射就会逐渐减弱，以至最终完全不出现。

!!! info "消退的实质"
    条件反射的消退**不是**条件反射的简单丧失，而是中枢把原先引起兴奋性效应的信号转变为产生**抑制性效应**的信号。因此，消退是一个**新的学习过程**，需要大脑皮层的参与。

### 条件反射的意义

条件反射使机体能够识别刺激物的性质，**预先**作出不同的反应，具有更强的**预见性、灵活性和适应性**，大大提高了动物应对复杂环境变化的能力。

## 易错辨析

???+ question "常见判断"
    - 只有具有**神经系统**的动物才有反射；植物和单细胞生物没有反射，只有应激性。
    - 反射弧中感受器与效应器通过传入、传出神经相连，但效应器是"传出神经末梢 + 肌肉或腺体"，不只是一个器官。
    - 传入神经受损 → 无感觉、无反应；传出神经受损 → 有感觉、无反应（如"能感觉针刺但不能运动"）。
    - 脊蛙（去除脑、保留脊髓）能完成屈腿反射，但不能形成感觉，也不能完成条件反射。
