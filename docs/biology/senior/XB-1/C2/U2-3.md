# 神经冲动的产生和传导

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 兴奋在神经纤维上的传导

在蛙的坐骨神经上放置两个微电极并连接到电表：静息时电表没有测出电位变化；刺激神经左端，靠近刺激端的电极处（a 处）先变为负电位、接着恢复正电位，随后另一电极处（b 处）变为负电位、再恢复为正电位。

这说明：在神经系统中，兴奋是以**电信号**的形式沿着神经纤维传导的，这种电信号也叫**神经冲动（neural impulse）**。

### 静息电位与动作电位

| 状态 | 离子基础 | 膜电位 |
|------|----------|--------|
| **静息电位**（未受刺激） | 膜对 $\ce{K+}$ 通透性强，$\ce{K+}$ 外流 | **内负外正** |
| **动作电位**（受刺激） | 膜对 $\ce{Na+}$ 通透性增加，$\ce{Na+}$ 内流 | **内正外负** |

- 静息时，神经细胞外的 $\ce{Na+}$ 浓度比膜内高，$\ce{K+}$ 浓度比膜内低。
- 兴奋部位（内正外负）与邻近未兴奋部位（内负外正）之间存在电位差，发生电荷移动，形成**局部电流**。
- 局部电流又刺激相近的未兴奋部位发生同样的电位变化，如此进行下去，将兴奋向前传导，后方又恢复为静息电位。

!!! note "传导特点"
    - 在**离体神经纤维**上，兴奋可**双向传导**；
    - 在反射弧中，由于突触的存在，兴奋整体是**单向传导**的。
    - 兴奋传导的方向与膜内局部电流方向一致，与膜外局部电流方向相反。

## 兴奋在神经元之间的传递

相邻的两个神经元一般并不直接接触。神经元的轴突末梢经过多次分枝，每个小枝末端膨大呈杯状或球状，叫作**突触小体**；突触小体与其他神经元的胞体或树突等相接近，共同形成**突触（synapse）**。

### 突触的结构

| 结构 | 说明 |
|------|------|
| **突触前膜** | 轴突末梢（突触小体）的膜，内有突触小泡 |
| **突触间隙** | 前膜与后膜之间的间隙 |
| **突触后膜** | 与突触前膜相对应的另一个神经元的胞体膜或树突膜 |

### 传递过程

1. 神经冲动传到轴突末梢 → 突触小泡向突触前膜移动并融合，释放**神经递质**；
2. 神经递质经扩散通过突触间隙；
3. 神经递质与突触后膜上的相关**受体**结合，形成递质—受体复合物；
4. 改变突触后膜对离子的通透性，引发突触后膜**电位变化**；
5. 神经递质与受体分开，并迅速被**降解或回收**进细胞，以免持续发挥作用。

**常见的神经递质**：乙酰胆碱、氨基酸类（谷氨酸、甘氨酸）、5-羟色胺、多巴胺、去甲肾上腺素、肾上腺素等。

### 传递特点

!!! note "单向传递"
    神经递质只存在于突触小泡中，只能由**突触前膜释放**，然后作用于**突触后膜**，因此神经元之间兴奋的传递只能是**单方向**的（从一个神经元的轴突传到下一个神经元的胞体或树突）。

!!! note "突触延搁"
    突触处的兴奋传递需要经过"电信号 → 化学信号 → 电信号"的转换，因此传递速度比在神经纤维上**慢**。

神经元与肌肉细胞或某些腺体细胞之间也是通过突触联系的：神经元释放的神经递质可作用于肌肉细胞或腺细胞，引起肌肉收缩或腺体分泌。

## 滥用兴奋剂、吸食毒品的危害

某些化学物质的作用位点往往是**突触**：

- 有些能促进神经递质的合成和释放；
- 有些会干扰神经递质与受体的结合；
- 有些会影响分解神经递质的酶的活性。

**兴奋剂**：原指能提高中枢神经系统机能活动的一类药物，如今是运动禁用药物的统称，具有增强兴奋程度、提高运动速度等作用。运动比赛禁止使用兴奋剂，以维护比赛的公平、保护参赛者的身心健康。

**毒品**：《中华人民共和国刑法》规定，毒品是指鸦片、海洛因、甲基苯丙胺（冰毒）、吗啡、大麻、可卡因以及国家规定管制的其他能够使人形成瘾癖的麻醉药品和精神药品。有些兴奋剂就是毒品。

### 可卡因致瘾机制

- 正常情况下，多巴胺发挥作用后会被突触前膜上的**转运蛋白**从突触间隙回收；
- 吸食可卡因后，转运蛋白失去回收多巴胺的功能，多巴胺留在突触间隙**持续发挥作用**，导致突触后膜上的多巴胺**受体减少**；
- 药效失去后，由于受体已减少，机体正常神经活动受影响，服药者必须继续服用可卡因维持神经元活动，形成**恶性循环**，毒瘾难戒；
- 此外，可卡因干扰交感神经作用，导致心脏功能异常，抑制免疫系统功能；长期吸食可产生触幻觉、嗅幻觉、皮下虫行蚁走感，易引发暴力或攻击行为。

!!! warning "法律责任"
    2008 年《中华人民共和国禁毒法》施行：禁毒是全社会的共同责任，实行"预防为主，综合治理，禁种、禁制、禁贩、禁吸并举"的方针。珍爱生命，远离毒品。

## 实验与思维训练

**蛙心灌流实验**：A 心脏有某副交感神经支配，B 没有。刺激该神经，A 心跳减慢；取 A 心脏营养液注入 B 心脏营养液，B 心跳也减慢。结论：该神经释放一种化学物质使心跳变慢。

??? question "推断假说与预期"
    假说：神经元与心肌细胞之间传递的信号是**化学信号**。预期：若将刺激神经后的营养液转移到另一心脏，后者心跳也会减慢。

## 核心概念速记

```
静息电位：K⁺外流 → 内负外正；动作电位：Na⁺内流 → 内正外负
神经纤维上：局部电流传导（离体双向）
突触：前膜 → 间隙 → 后膜；神经递质单向传递，速度较慢
兴奋剂/毒品多通过突触起作用（如可卡因干扰多巴胺回收）
```
