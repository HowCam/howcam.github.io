# 神经系统的分级调节

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 神经系统对躯体运动的分级调节

躯体的运动（如膝跳反射、缩手反射）不仅受到**脊髓**的控制，也受到**大脑皮层**的调节。

### 大脑皮层与躯体运动

- 大脑的表面覆盖着主要由神经元胞体及其树突构成的薄层结构——**大脑皮层**。
- 大脑有丰富的沟回，使有限体积的颅腔内具有更大的表面积；成年人大脑皮层总面积可达 **2200 cm²**。
- 大脑通过**脑干**与脊髓相连，大脑发出的指令可以通过脑干传到脊髓。

**第一运动区（中央前回）的特点**：

1. 刺激中央前回顶部 → 引起**下肢**运动；刺激下部 → 引起**头部器官**运动；刺激其他部位 → 引起相应器官运动。
2. 躯体各部分的运动机能在第一运动区内都有代表区，且代表区的位置与躯体各部分的关系是**倒置**的。
3. 皮层代表区范围的大小与躯体中相应部位的**大小无关**，而与躯体运动的**精细程度**有关（如手、面部所占区域大）。

### 分级调节

<div class="mermaid">
graph TB
    A[大脑皮层（最高级中枢）] --> B[脑干等（连接低级与高级中枢）]
    B --> C[脊髓（低级中枢）]
    C --> D[肌肉收缩等运动]
    A -.发出指令并不断调整.-> C
</div>

躯体的运动受大脑皮层、脑干、脊髓等的**共同调控**：脊髓是机体运动的**低级中枢**，大脑皮层是**最高级中枢**，脑干等连接低级中枢和高级中枢。脑中的高级中枢发出指令对低级中枢进行不断调整，使机体的运动变得有条不紊与精准。

!!! question "脑卒中实例"
    老人脑部血管阻塞使大脑某区损伤，脊髓、脊神经和四肢都正常却不能运动，说明**大脑（高级中枢）对脊髓（低级中枢）的调控**是运动完成的必要条件。

## 神经系统对内脏活动的分级调节

神经系统对内脏活动的调节与对躯体运动的调节相似，也是通过**反射**进行的。中枢神经系统的不同部位都存在调节内脏活动的中枢。

### 各中枢的层级与功能

| 中枢 | 级别 | 主要功能 |
|------|------|----------|
| **脊髓** | 低级中枢 | 完成简单的内脏反射：排尿、排便、血管舒缩等；调节是初级的，排尿不完全、不能受意识控制 |
| **脑干** | 基本中枢 | 调节呼吸运动、心血管活动等；受损可致呼吸或心跳停止 |
| **下丘脑** | 较高级中枢 | 调节体温、水平衡、摄食等，使内脏活动与其他生理活动相联系 |
| **大脑皮层** | 最高级中枢 | 对各级中枢活动起调整作用，使自主神经系统**并不完全"自主"** |

### 排尿反射的分级调节

- 控制排尿的**低级中枢在脊髓**；膀胱储尿达到一定程度时引起尿意。
- 脊髓对膀胱扩大和缩小的控制由**自主神经系统**支配：**交感神经兴奋不会导致膀胱缩小；副交感神经兴奋会使膀胱缩小**。
- 人之所以能有意识地控制排尿（"憋尿"），是因为**大脑皮层对脊髓进行调控**。
- 婴儿因大脑发育尚未完善，不能有意识地控制排尿，常尿床；成人因外伤等出现尿床，可能是大脑皮层与脊髓的联系受损。

    在躯体运动及排尿反射的分级调节过程中，还存在**反馈调节**（详见第 3 章第 2 节）。

## 易错辨析

???+ question "常见判断"
    - 脊髓横断（胸部）后：膝跳反射**存在**（反射弧完整），但针刺足部**无感觉**（兴奋不能上行传到大脑皮层），且**不能有意识控制排尿**。
    - 自主神经系统"自主"是指其活动一般不受意识支配，但仍受大脑皮层等高级中枢调控。
    - 大脑皮层运动代表区是倒置的（头部在下、下肢在上），但**头部器官的代表区是正立的**这一细节可不必深究；关键在于代表区大小与精细程度相关。
