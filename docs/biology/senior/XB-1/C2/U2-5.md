# 人脑的高级功能

> 来源：人教版高中生物选择性必修一《稳态与调节》（2019 新课标）

---

## 概述

人的大脑皮层有 140 多亿个神经元，组成了许多神经中枢，是整个神经系统中最高级的部位。它除了感知外部世界以及控制机体的反射活动，还具有**语言、学习和记忆、情绪**等方面的高级功能，使人类能够主动适应环境，创造灿烂的人类文明。

!!! info "阿尔茨海默病"
    老年人常见疾病，主要表现为逐渐丧失记忆和语言功能、计算和推理等思维能力受损（如迷路）、情绪不稳定，由大脑内某些特定区域的神经元大量死亡造成。

---

## 语言功能

**语言功能是人脑特有的高级功能**，包括与语言、文字相关的全部智能活动，涉及人类的**听、说、读、写**。

人类的语言活动与大脑皮层某些特定区域相关，这些特定区域叫**言语区**：

| 言语区 | 位置特点 | 受损后的症状 |
|--------|----------|--------------|
| **S 区** | 接近躯体运动中枢 | 能听懂、能书写，但**不能讲话**（运动性失语症） |
| **H 区** | 接近听觉中枢 | 能讲话、听觉正常，但**不能听懂话** |
| **W 区** | 接近躯体运动中枢 | **不能写字** |
| **V 区** | 接近视觉中枢 | **不能看懂文字** |

!!! note "左右脑分工"
    - 大多数人主导语言功能的区域在**大脑左半球**，**逻辑思维**主要由左半球负责；
    - 大多数人的大脑**右半球**主要负责**形象思维**，如音乐、绘画、空间识别等。

!!! warning "注意"
    听、说、读、写分别由不同区域控制，但这些区域**相互联系**，并非相互独立。

## 学习与记忆

**学习**：神经系统不断地接受刺激，获得新的行为、习惯和积累经验的过程。条件反射的建立也就是动物学习的过程。

**记忆**：学习和记忆不是由单一脑区控制的，而是由**多个脑区和神经通路**参与。

### 记忆的四个阶段

| 阶段 | 持续时间 | 特点 |
|------|----------|------|
| **感觉性记忆** | < 1 秒 | 转瞬即逝，信息大部分迅速消退，不构成真正的记忆 |
| **第一级记忆** | 数秒～数分钟 | 相当于短时记忆，如临时记住验证码；加以**注意**可由感觉性记忆转入 |
| **第二级记忆** | 数分钟～数年 | 相当于长时记忆；第一级记忆中的信息经**反复运用、强化**转入；可因前后信息干扰而遗忘 |
| **第三级记忆** | 可能永久 | 长年累月运用而不易遗忘，成为永久记忆，如对自己姓名的记忆 |

**神经基础**：

- 学习和记忆涉及脑内**神经递质**的作用以及某些种类**蛋白质**的合成；
- **短时记忆**可能与神经元之间即时的信息交流有关，尤其是与大脑皮层下一个形状像海马的脑区（**海马区**）有关；
- **长时记忆**可能与突触形态及功能的改变以及**新突触的建立**有关。

!!! tip "学习启示"
    老师强调动用多种器官（耳听、眼看、动手、动口），就是通过多通道刺激和反复强化，促进信息由短时记忆向长时记忆转化。

## 情绪

情绪是人对环境所作出的反应，是大脑的高级功能之一，有积极和消极两种相反的表现。

| 概念 | 说明 |
|------|------|
| **抑郁** | 遇到精神压力、生活挫折、疾病、死亡等情况时产生的消极情绪；通常短期存在，可通过自我调适、他人支持、心理咨询好转 |
| **抑郁症** | 抑郁持续两周以上得不到缓解，可能影响工作、学习和生活，严重时产生自残或自杀行为，必须接受专业治疗 |

**应对方法**：

1. 积极建立和维系良好的**人际关系**；
2. 适量**运动**；
3. 学会**调节压力**；
4. 当情绪波动超出自己能调节的程度时，应向**专业人士**咨询。

!!! info "抗抑郁药"
    抗抑郁药一般通过作用于**突触**来影响神经系统功能。例如有的药物可选择性抑制突触前膜对 5-羟色胺的回收，使突触间隙中 5-羟色胺浓度维持在一定水平。

## 科学·技术·社会：脑机接口

- **原理**：采集大脑神经元电信号（植入微电极阵列或在头皮收集脑电波），经计算机编码、解码，转换成控制外部设备（如电动假肢）的命令。
- **植入式**：信号精度高、速度快，但需开颅植入微电极，有手术风险。
- **非植入式**：手术风险低，但采集到的电信号微弱、模糊，精度和速度较低。
- **我国成果**：2014 年"神工一号"全肢体中风康复脑控人工神经机器人系统；2016 年"神工"系统随"天宫二号"开展在轨脑机交互实验。我国在脑电波分析和解读技术、脑机接口系统实用性开发上处于国际领先水平。

```
人脑高级功能：语言、学习、记忆、情绪
言语区：S（说）、H（听）、W（写）、V（读）
记忆四阶段：感觉性 → 第一级 → 第二级 → 第三级
短时记忆：海马区、即时信息交流；长时记忆：突触改变与新突触建立
抑郁超过两周 → 抑郁症，需专业治疗
```
