# 植物细胞工程

> 来源：人教版高中生物选择性必修三（2019新课标）

---

## 植物细胞工程的基本技术

### 理论基础——细胞全能性

**细胞全能性**：细胞经分裂和分化后，仍具有产生完整生物体的潜能。

!!! note "历史沿革"
    - 1902年哈伯兰特提出细胞全能性理论但未成功
    - 1958年斯图尔德证明胡萝卜体细胞可分化为胚

??? question "为什么不是所有细胞都表现全能性？"
    → 基因选择性表达（芽原基→芽，叶原基→叶）

### 植物组织培养

**植物组织培养（plant tissue culture）**：将离体的植物器官、组织或细胞，培养在人工培养基上，诱导其形成完整植株的技术。

| 术语 | 定义 |
|------|------|
| **外植体** | 离体培养的植物器官、组织或细胞 |
| **脱分化** | 高度分化细胞失去特有结构和功能，形成**愈伤组织**（薄壁组织团块）|
| **再分化** | 愈伤组织重新分化成芽、根等器官 |

#### 关键激素

| 激素 | 作用 |
|------|------|
| **生长素** | 促进生长、分裂、分化 |
| **细胞分裂素** | 促进分裂、**芽的分化** |

!!! note "激素比例"
    - 比值**高**（生长素为主）→ 促进**生根**
    - 比值**低**（细胞分裂素为主）→ 促进**生芽**

## "菊花的组织培养"实验

### 方法步骤

```
外植体消毒：70%酒精30s → 无菌水洗2-3次 → 5%次氯酸钠30min → 无菌水洗2-3次
    ↓
切割成0.5～1cm小段，用无菌滤纸吸去表面水分
    ↓
接种到诱导愈伤组织培养基（18～22℃，一般不需光照）
    ↓
愈伤组织形成（约15～20d）
    ↓
转接诱导生芽培养基（有光照）→ 长出芽
    ↓
转接诱导生根培养基 → 生根
    ↓
炼苗（打开封口膜适应自然环境）
    ↓
移栽：洗去根部培养基 → 蛭石/珍珠岩 → 逐步移栽入土
```

### 注意事项

- 培养基和器械全部灭菌
- 接种在酒精灯火焰旁
- 外植体不要倒插
- 定期观察记录

## 植物体细胞杂交技术

### 背景

番茄和马铃薯——希望培育"地上结番茄、地下长马铃薯"的"超级作物"，但杂种植株**未能**实现，原因是基因表达调控问题。

### 关键概念

**原生质体**：用**纤维素酶和果胶酶**去除细胞壁后获得的裸露细胞。

**植物体细胞杂交（plant somatic hybridization）**：将不同来源的植物体细胞融合成杂种细胞，培育成新植物体的技术。

### 融合方法

| 方法 | 说明 |
|------|------|
| 物理法 | 电融合法、离心法 |
| 化学法 | **PEG融合法**、高Ca²⁺—高pH融合法 |

### 流程示意

```
A植物细胞 → 去壁 → A原生质体
B植物细胞 → 去壁 → B原生质体
        ↓ 原生质体融合（PEG/电融合）
        ↓ 杂种细胞（再生细胞壁）
        ↓ 愈伤组织
        ↓ 杂种植株
```

!!! info "已成功案例"
    - 白菜—甘蓝
    - 普通小麦—长穗偃麦草
    - 多种柑橘属间杂种植株（我国）

## 植物细胞工程的应用

### 1. 快速繁殖（微型繁殖技术）

- 高效快速繁殖优良品种
- 保持**遗传特性**
- 应用：观赏植物、经济林木、无性繁殖作物、**濒危植物**

??? note "实例"
    - 荷兰兰花产业（60年代起步）
    - 我国铁皮石斛试管苗规模化生产

### 2. 作物脱毒

| 项目 | 内容 |
|------|------|
| 问题 | 无性繁殖作物（马铃薯、草莓、香蕉）病毒逐年积累→减产降质 |
| 方法 | 切取**茎尖**（病毒极少或无）→ 组织培养 → **脱毒苗** |
| 效果 | 脱毒马铃薯比未脱毒**增产50%以上** |

### 3. 单倍体育种

```
花药/花粉培养 → 单倍体植株 → 诱导染色体加倍 → 纯合二倍体植株
```

- 优点：**年限短**（当年完成）；隐性性状容易显现
- 我国：1974年世界首例"**单育1号烟草**"；后育成水稻、玉米、油菜、甘蓝、甜椒等新品种

### 4. 突变体的利用

- 组织培养中细胞受培养条件/诱变因素影响产生突变
- 筛选有用突变→培育新品种
- 实例：抗花叶病毒甘蔗、抗盐碱烟草

### 5. 细胞产物的工厂化生产

- **次生代谢物**：非植物基本生命活动所必需，是药物、香料、色素等重要来源
- **细胞培养**：在离体条件下培养单个植物细胞或细胞团使其增殖

| 实例 | 说明 |
|------|------|
| 紫草宁 | 世界首例药用植物细胞工程产品（20世纪80年代）|
| 紫杉醇 | 治乳腺癌；传统方法破坏濒危红豆杉；现筛选高产细胞我国领先 |
| 人参皂苷 | 我国实现人参细胞培养生产活性成分 |

## 核心概念速记

```
细胞全能性 = 分化细胞仍保留全套遗传物质
脱分化 = 分化细胞 → 愈伤组织（未分化）
再分化 = 愈伤组织 → 芽/根

植物组织培养 = 离体器官/组织/细胞 → 完整植株
原生质体 = 去壁后的裸露细胞
体细胞杂交 = 原生质体融合 → 杂种植株
```
