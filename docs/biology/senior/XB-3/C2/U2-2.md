# 动物细胞工程

> 来源：人教版高中生物选择性必修三（2019新课标）

---

## 动物细胞培养

**动物细胞培养（animal cell culture）**：从动物体取出组织，分散成单个细胞，在适宜培养条件下生长和增殖的技术。

### 培养条件

| 条件 | 要求 |
|------|------|
| 营养 | 合成培养基 + 血清；糖类、氨基酸、无机盐、维生素 |
| 无菌无毒 | 定期更换培养液清除代谢物 |
| 温度 | 哺乳动物细胞：**（36.5±0.5）℃** |
| pH | **7.2～7.4** |
| 气体 | O₂（必需）+ CO₂（维持pH）；95%空气 + 5% CO₂ |
| 渗透压 | 适宜 |

### 培养过程

```
取动物组织 → 分散成单个细胞（机械法/胰蛋白酶/胶原蛋白酶）
    ↓
制成细胞悬液 → 放入培养瓶/培养皿
    ↓
原代培养（细胞贴壁；发生**接触抑制**）
    ↓
分瓶：胰蛋白酶处理 → 分散成单个细胞 → 离心收集 → 分瓶
    ↓
传代培养
```

### 两类生长方式

| 类型 | 特点 | 代表 |
|------|------|------|
| 悬浮培养 | 细胞漂浮在培养液中 | 血细胞 |
| 贴壁培养 | 需贴附基质表面；发生**接触抑制** | 大多数细胞 |

## 干细胞培养及其应用

**干细胞（stem cell）**：在一定条件下可以分化成其他类型细胞的细胞。

### 胚胎干细胞（ES细胞）

| 项目 | 内容 |
|------|------|
| 来源 | **早期胚胎** |
| 分化能力 | **全能性**：可分化为任何类型细胞，形成完整个体 |
| 研究 | 1981年首次分离小鼠ES细胞；已分离兔、牛、猴、人ES细胞 |
| 局限 | 需从胚胎获取，涉及**伦理问题** |

### 成体干细胞

| 项目 | 内容 |
|------|------|
| 来源 | 成体组织或器官内 |
| 分化能力 | **组织特异性**：只能分化成特定细胞/组织 |
| 实例 | 骨髓**造血干细胞**、神经**神经干细胞**、睾丸**精原干细胞** |

!!! info "造血干细胞"
    治疗白血病、恶性肿瘤放化疗后的造血/免疫功能障碍。

### 诱导多能干细胞（iPS细胞）

| 项目 | 内容 |
|------|------|
| 发现 | 2006年，山中伸弥（日本）|
| 原理 | 体外诱导成纤维细胞（加特定因子）→ 类似胚胎干细胞的细胞 |
| 优点 | 无须破坏胚胎（无伦理争议）；可来源于病人自身体细胞（无免疫排斥）|
| 应用 | 阿尔茨海默病、心血管疾病、镰状细胞贫血等治疗 |

## 动物细胞融合技术与单克隆抗体

### 动物细胞融合技术

**原理**：使两个或多个动物细胞结合形成一个细胞，具有原来多个细胞的遗传信息。

**诱导方法**：PEG融合法、电融合法、**灭活病毒诱导法**

!!! note "灭活病毒机制"
    病毒表面糖蛋白与细胞膜糖蛋白作用，使细胞膜打开融合。

### 单克隆抗体

**传统方法问题**：产量低、纯度低、特异性差。

#### 杂交瘤技术原理

```
特定抗原免疫小鼠 → 脾细胞（含多种B淋巴细胞，各分泌不同抗体）
    ↓
与骨髓瘤细胞（无限增殖）融合 → 杂交瘤细胞
    ↓
选择培养基筛选（未融合/同种融合细胞死亡，只有杂交瘤存活）
    ↓
克隆化培养 + 抗体检测 → 筛选出分泌特定抗体的杂交瘤细胞
    ↓
体外大规模培养 or 注射小鼠腹腔增殖
    ↓
单克隆抗体
```

#### 实验流程详解

##### 第一步：免疫小鼠

- 用**特定抗原**（如蛋白质、细胞表面分子）多次注入小鼠体内
- 使B淋巴细胞增殖分化，产生针对该抗原的多种抗体

##### 第二步：获取脾细胞

- 小鼠脾脏中含大量B淋巴细胞
- 每个B淋巴细胞分泌的抗体**特异性不同**
- 脾细胞提供**抗体分泌能力**

##### 第三步：骨髓瘤细胞特点

| 特性 | 说明 |
|------|------|
| 无限增殖 | 可在培养液中长期传代 |
| 不能分泌抗体 | 保留细胞融合能力 |
| 代谢缺陷 | 缺乏HGPRT（嘌呤合成关键酶）|

!!! tip "骨髓瘤细胞选择"
    选择缺乏HGPRT的骨髓瘤细胞是为了后续用HAT培养基筛选杂交瘤细胞。

##### 第四步：细胞融合

- 脾细胞 + 骨髓瘤细胞混合
- 常用**PEG（聚乙二醇）**诱导融合
- 融合方式：脾细胞↔脾细胞、骨髓瘤↔骨髓瘤、脾细胞↔骨髓瘤

##### 第五步：HAT培养基筛选

**HAT培养基**成分：次黄嘌呤(H)、氨甲蝶呤(A)、胸腺嘧啶核苷(T)

| 细胞类型 | HGPRT | 存活情况 |
|---------|-------|----------|
| 未融合骨髓瘤细胞 | 缺陷 | **死亡** |
| 未融合脾细胞 | 正常 | **死亡** |
| **杂交瘤细胞** | 正常（来自脾细胞） | **存活** |

**筛选原理**：氨甲蝶呤阻断DNA合成主途径，杂交瘤从脾细胞获得HGPRT，通过应急途径合成DNA存活。

##### 第六步：克隆化培养

- 将杂交瘤细胞稀释至**单细胞**水平
- 培养于96孔板
- 确保抗体来自**单个细胞**（单克隆）

##### 第七步：抗体检测

- 采用**ELISA**或免疫荧光法检测
- 筛选出**阳性克隆**（分泌特定抗体）

##### 第八步：扩大培养

| 方式 | 特点 |
|------|------|
| 体外大规模培养 | 悬浮培养，纯度高 |
| 小鼠腹腔注射 | 腹水中含高浓度抗体 |

#### 单克隆抗体的优点

| 对比项 | 传统血清抗体 | 单克隆抗体 |
|--------|--------------|-------------|
| 产生细胞 | 多克隆 | **单克隆** |
| 成分 | 多种抗体混合物 | **单一特异性** |
| 特异性 | 交叉反应多 | **强** |

??? question "常见考点"
    1. **为什么选择骨髓瘤细胞？** 能无限增殖+可与脾细胞融合
    2. **HAT筛选原理（高频考点）？** A阻断DNA合成 → 只有具HGPRT的杂交瘤能存活
    3. **单克隆抗体的"单克隆"指什么？** 来自**单个杂交瘤细胞**的子代
    4. **杂交瘤细胞为什么能同时具备两种能力？** 从脾细胞获得抗体分泌能力，从骨髓瘤细胞获得无限增殖能力

#### 应用

- **诊断试剂**：早孕诊断、疾病鉴定（定位肿瘤/心血管畸形）
- **ADC（抗体—药物偶联物）**：单克隆抗体+细胞毒素，精准杀伤肿瘤
- **新药测试**

## 动物体细胞核移植技术和克隆动物

### 体细胞核移植技术

**核移植（nuclear transplantation）**：将一个细胞的细胞核移入去核卵母细胞中，使重新组合的细胞发育成新胚胎，进而发育成动物个体的技术。

| 类型 | 难度 | 说明 |
|------|------|------|
| 胚胎细胞核移植 | 较低 | 分化程度低 |
| **体细胞核移植** | 较高 | 分化程度高，表现全能性困难 |

!!! note "克隆猴难点"
    非人灵长类体细胞核移植非常困难。
    - 供体核不能完全恢复分化前功能状态→胚胎发育率低
    - 操作技术尚不完善

### 流程（以克隆奶牛为例）

```
从屠宰场收集卵巢 → 采集卵母细胞 → 体外培养至MⅡ期
    ↓
从供体高产奶牛取体细胞，培养
    ↓
显微操作法去核（也可用梯度离心/紫外线短照/化学处理）
    ↓
将供体体细胞注入去核卵母细胞
    ↓
电融合法 → 重构胚（具有发育成完整个体的能力）
    ↓
激活：电刺激/Ca²⁺载体/乙醇/蛋白酶合成抑制剂
    ↓
胚胎移植到代孕母牛体内
    ↓
生出与供体遗传物质基本相同的犊牛
```

### 应用前景

| 领域 | 应用 |
|------|------|
| 畜牧 | 加速遗传改良、促进优良畜群繁育 |
| 医药 | 转基因克隆动物作为**生物反应器**生产药物 |
| 器官移植 | 异种移植；患者自身细胞→避免免疫排斥 |
| 基础研究 | 胚胎发育/衰老研究 |
| 濒危物种 | 增加存活数量 |

### 存在的问题

- 成功率低；理论基础滞后
- 克隆动物健康问题：体形过大、异常肥胖、发育困难、脏器缺陷、免疫失调
- 多莉早衰问题（存活7年，普通绵羊12岁）

### "三亲婴儿"

```
母亲卵母细胞（有线粒体遗传病基因）→ 去核
卵母细胞捐献者 → 去核（留健康细胞质）
父亲精子
    ↓
体外受精 + 核移植
    ↓
生出"三亲婴儿"（拥有父亲+母亲+捐献者部分基因）
```

**优点**：避免母亲线粒体遗传病基因传递（遗传物质主要在细胞核，线粒体基因来自健康捐献者）

## 核心概念速记

```
动物细胞培养 = 离体细胞培养（分散 + 适宜条件）
接触抑制 = 贴壁细胞长满后停止分裂
干细胞 = 可分化成其他类型细胞的细胞
ES细胞 = 胚胎干细胞（全能性）
iPS细胞 = 诱导多能干细胞（体细胞诱导，无伦理争议）

细胞融合 = 两个/多个细胞 → 一个杂交细胞
杂交瘤细胞 = B淋巴细胞（抗体）+ 骨髓瘤细胞（无限增殖）
单克隆抗体 = 单个杂交瘤细胞产生的高度特异性抗体

核移植 = 核 + 去核卵母细胞 → 重构胚 → 新个体
克隆动物 = 体细胞核移植产生的个体
重构胚 = 人工重新构建的胚胎
```
