# 第1章 遗传因子的发现

## 1.1 孟德尔的豌豆杂交实验（一）

### 一、融合遗传与相对性状

1. **融合遗传**：两个亲本杂交后，双亲的遗传物质会在子代体内发生混合，使子代表现出介于双亲之间的性状。此观点可以被一对相对性状杂交实验否定。

2. **豌豆用作遗传实验材料的优点**：

    - 豌豆花是两性花，自然状态下是纯种（自花传粉、闭花受粉 → 自交）
    - 豌豆植株有易于区分的、可以稳定遗传给后代的相对性状
    - 豌豆生长周期短，便于在较短时间内观察遗传结果
    - 豌豆子粒多，便于获得足够的统计数据进行分析

3. **相对性状**：同种生物同一性状的不同表现类型。

### 二、人工杂交实验

4. **杂交实验操作步骤**：去雄 → 套袋 → 传粉 → 套袋

5. **去雄选择未成熟花**：成熟花已经完成自交，无法实现人工授粉。

6. **两次套袋的时间**：
   
    - 去雄后
   
    - 人工传粉后
   
    目的：防止外来花粉干扰。

7. **去雄的目的**：防止自花传粉。所以单性花不用去雄，未成熟之前直接套袋即可。

8. **自花传粉**：两性花未开放时，自己的花粉落到自己的柱头上，完成的传粉的过程。

9. **异花传粉**：两朵花之间传粉的过程。

### 三、一对相对性状的杂交实验

10. **实验过程**：不同性状的纯种亲代杂交（高茎 × 矮茎）后的子一代（$F_1$）全是高茎。子一代自交后产生的子二代有高有矮，高：矮 $\approx 3:1$

11. **显性性状**：$F_1$ 中表现出来的性状。孟德尔把子一代表现出来的性状，叫做**显性性状**。

12. **隐性性状**：$F_1$ 中未表现出的性状。

13. **子一代（$F_1$）自交结果**：有高有矮，高：矮 $\approx 3:1$

14. **性状分离**：杂种后代中同时出现显性性状和隐性性状的现象。

### 四、分离现象的解释

15. **假说—演绎法**：

    ???+ note "假说—演绎法的步骤"
        1. 提出问题
        2. 提出假说
        3. 演绎推理
        4. 实验验证
        5. 得出结论

    若实验结果与演绎推理的结果一致，则说明假说成立。

16. **孟德尔的提出的假说内容**：

    1. 生物的性状是由遗传因子决定的。
    2. 在体细胞中，遗传因子是成对存在的。
    3. 生物体在形成配子时，成对的遗传因子彼此分离，分别进入不同的配子中。配子中只含有每对遗传因子中的一个。
    4. 受精时，雌雄配子的结合是随机的。

### 五、基本概念辨析

17. **自交**：遗传因子组成相同的生物体之间互相交配。（不一定是同一生物体。植物体中一般指自花受粉和异花同株传粉。）

18. **杂交**：遗传因子组成不同的生物体间相互交配的过程。

19. **测交**：杂种与隐性纯合个体相交。

20. **正反交**：是一对相对概念，具体正反可以自主定义。

21. **自由交配**：也叫随机交配，种群中雌雄个体相互交配的机会均等。在题目中适用"配子法"来分析。

22. **基因型**：基因组成类型。**表现型**：性状类型。

!!! warning "注意"
    雌雄配子数目不相等。雄配子数量一般远远多于雌配子。

### 六、性状分离比的条件

23. 出现 $3:1$ 性状分离比的条件：

    1. 子一代个体形成的各个种类的雌配子或雄配子数目相等且存活能力相同。
    2. 雌雄配子结合机会均等。
    3. 子二代不同基因型的个体存活率相等。
    4. 基因为完全显性。
    5. 子代样本数量足够多。

### 七、性状分离模拟实验

24. 性状分离模拟实验

    ???+ note "模拟实验要点"
        1. 两个小桶分别代表雌雄生物的生殖器官（睾丸、卵巢）
        2. 小桶内的小球代表雌雄配子
        3. 小球颜色代表配子的基因型
        4. 小球大小相同保证抽取时没有形状上的区别
        5. 各小桶内的两种彩球数目需要相等
        6. 两个小桶的彩球数目可以/应当不相等
        7. 抽取彩球的动作代表遗传因子彼此分离
        8. 将两个彩球放在一起代表配子的结合
        9. 一组实验完成后需要放回原小桶，保证小桶内的两种彩球比例是 $1:1$
        10. 分析数据时，结果不满足 $3:1$ 的原因：抽取次数太少

### 八、测交实验验证

25. 对分离现象解释的验证（测交实验）：

    1. **设计原因**：验证假说能否预测另一种实验的结果。
    2. **方法**：测交法。
    3. **测交时使用隐性纯合子与 $F_1$ 杂交的原因**：后代性状类型和比例可以直接反映遗传因子组成。

    !!! tip "测交实验应用"
        - 测定杂合子配子种类和比例
        - 测定杂合子遗传因子组成
        - 预测杂合子形成配子时遗传因子的行为

### 九、分离定律

26. **分离定律**：

    - 在生物的体细胞中，控制同一性状的遗传因子成对存在，不相融合。
    - 在形成配子时，成对的遗传因子彼此分离，分离后的遗传因子分别进入不同的配子中，随配子遗传给后代。

27. **分离的时间**：有性生殖的生物形成配子时。

???+ success "经典例题"

    用纯种高茎豌豆与纯种矮茎豌豆杂交，$F_1$ 全部为高茎。$F_1$ 自交得 $F_2$，其中高茎约有 3000 株，矮茎约有 1000 株。则 $F_2$ 中纯合高茎约占多少？

    **解析**：
    
    - $F_2$ 中高茎 : 矮茎 ≈ 3 : 1
    - 高茎中纯合子（DD）占 $\dfrac{1}{3}$，杂合子（Dd）占 $\dfrac{2}{3}$
    - 矮茎全为纯合子（dd）
    - $F_2$ 中纯合高茎 = $3000 \times \dfrac{1}{3} = 1000$ 株
    
    **答案**：纯合高茎约占 1000 株，比例为 $\dfrac{1}{4}$。
