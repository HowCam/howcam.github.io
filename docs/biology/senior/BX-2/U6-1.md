# 第6章 生物的进化

## 6.1 生物有共同祖先的证据

### 一、达尔文的生物进化论

- 1859 年，达尔文在《物种起源》一书中明确提出，地球上的当今生物都是由共同祖先进化来的，人和猿有共同的祖先。
- 达尔文的生物进化论主要由两大学说组成：

| 学说 | 主要内容 |
|------|----------|
| 共同由来学说 | 地球上所有的生物都是由原始的共同祖先进化来的 |
| 自然选择学说 | 揭示生物进化的机制，解释适应的形成和物种形成的原因 |

### 二、地层中陈列的证据——化石

**化石**：通过自然作用保存在地层中的古代生物的遗体、遗物或生活痕迹等。

- 利用化石可以确定地球上曾经生活过的生物的种类及其形态、结构、行为等特征。
    - 从动物的牙齿化石推测它们的饮食情况；
    - 从动物的骨骼化石推测其体型大小和运动方式；
    - 从植物化石推测它们的形态、结构和分类地位。
- **化石是研究生物进化最直接、最重要的证据。**

**化石在地层中的分布**

- 大部分化石发现于沉积岩的地层中。如果把地层比作一本书，化石则是书中的文字，记录着地球和生物进化的历史。
- 在越古老的地层中，成为化石的生物越简单、越低等，水生生物的化石也越多；在越晚近的地层中，成为化石的生物越复杂、越高等，陆生生物的化石也越多。
- 大量化石证据揭示出生物由**简单到复杂、由低等到高等、由水生到陆生**的进化顺序。

**重要化石实例**

| 化石 | 支持的观点 |
|------|------------|
| 赫氏近鸟龙化石 | 身体骨架与恐龙非常接近，骨架周围有清晰的羽毛印痕，为鸟类起源于恐龙的假说提供了有力证据 |
| 少女露西的骨骼化石 | 上肢骨与黑猩猩相似，适于攀缘；下肢骨与现代人类接近，适于直立行走，支持人猿共祖说 |

!!! note "测定化石年代——理想的“地质时钟”"

    放射性同位素衰变的速率不受环境因素影响。测定化石中所含 $\ce{^{238}U}$ 和 $\ce{^{206}Pb}$ 的比例，可以知道化石大约是什么时候形成的；测定 $\ce{^{14}C}$ 和 $\ce{^{12}C}$ 的比例，也可以推知生物所生存的年代。$\ce{^{238}U}$ 的半衰期是 45 亿年，$\ce{^{14}C}$ 的半衰期是 5 730 年。

### 三、当今生物体上进化的印迹——其他方面的证据

**比较解剖学证据**

- 比较解剖学是研究比较脊椎动物的器官、系统的形态和结构，为这些生物是否有共同祖先寻找证据的学科。
- 蝙蝠的翼、鲸的鳍、猫的前肢和人的上肢，虽然外形和功能迥异，但骨骼组成一致，都有肱骨、桡骨、尺骨、腕骨、掌骨和指骨，且排列顺序一致。
- 这种结构模式的一致性说明它们是由共同祖先进化而来的。

**胚胎学证据**

- 胚胎学是研究动植物胚胎的形成和发育过程的学科。
- 人的胚胎在发育早期会出现鳃裂和尾，这与鱼的胚胎在发育早期出现鳃裂和尾非常相似，只是随着发育的进行，人的鳃裂和尾消失了，而成年的鱼仍然保留了鳃和尾。
- 脊椎动物在胚胎发育早期都有彼此相似的阶段，这支持了人和其他脊椎动物有共同祖先的观点。

**细胞和分子水平的证据**

- 从细胞水平看，当今生物都有能进行代谢、生长和增殖的细胞，细胞有共同的物质基础和结构基础，如都有细胞膜、细胞质、核糖体和 DNA。
- 从分子水平看，不同生物的 DNA 和蛋白质等生物大分子具有共同点，提示当今生物有着共同的原始祖先；其差异的大小则揭示了当今生物种类亲缘关系的远近，以及它们在进化史上出现的顺序。

| 比较对象 | 数据 |
|----------|------|
| 人与猩猩的同源 DNA 差异 | $2.4\%$ |
| 人与长臂猿的同源 DNA 差异 | $5.3\%$ |
| 人与黑猩猩基因组的差异 | $3\%$ |
| 人与黑猩猩细胞色素 c 的氨基酸差异 | 0 个 |
| 人与猕猴细胞色素 c 的氨基酸差异 | 1 个 |
| 人与酵母菌细胞色素 c 的氨基酸差异 | 44 个 |

- 细胞色素 c 是细胞中普遍含有的一种蛋白质，约有 104 个氨基酸，其氨基酸序列每 2 000 万年才发生 $1\%$ 的改变。亲缘关系越近的生物，细胞色素 c 的氨基酸序列差异越小。

### 四、各类证据的关系

| 证据 | 地位与作用 |
|------|------------|
| 化石证据 | 研究生物进化最直接、最重要的证据 |
| 比较解剖学证据 | 通过同源器官的形态结构比较，为共同祖先提供佐证 |
| 胚胎学证据 | 通过胚胎发育早期的相似性，为共同祖先提供佐证 |
| 细胞和分子水平证据 | 通过细胞结构和大分子的共同点，揭示亲缘关系远近 |

### 五、化石与地层

**化石**

- 化石是指通过自然作用保存在地层中的古代生物的遗体、遗物或生活痕迹等。
- 利用化石可以确定地球上曾经生活过的生物的种类及其形态、结构、行为等特征。
- 例如，从动物的牙齿化石推测它们的饮食情况，从骨骼化石推测其体型大小和运动方式，从植物化石推测其形态、结构和分类地位。
- 化石是研究生物进化**最直接、最重要**的证据。

**地层与化石的分布**

- 大部分化石发现于沉积岩的地层中。沉积岩是成层堆积的松散沉积物固结而成的岩石。
- 在正常情况下，地层的形成顺序是**下老上新**：越靠下的地层形成越早，越靠上的地层形成越晚。
- 因此，越古老的地层中发现的生物化石越简单、越低等；越晚形成的地层中发现的生物化石越复杂、越高等。

| 地质年代 | 首次出现的生物类群 |
|----------|--------------------|
| 约 35 亿年前 | 古细菌等单细胞原核生物 |
| 约 21 亿年前 | 单细胞真核生物 |
| 约 7 亿年前 | 多细胞生物 |
| 约 5 亿年前 | 鱼类、昆虫、两栖类等 |
| 约 2.45 亿年前 | 爬行类 |
| 约 1.44 亿年前 | 鸟类、哺乳类 |

- 大量化石证据证实：生物是由原始的共同祖先经过漫长的地质年代逐渐进化而来的，进化的总体趋势是**由简单到复杂、由低等到高等、由水生到陆生**。

!!! note "放射性同位素测年"

    - 放射性同位素以恒定的速率衰变，一定时间内衰变一半所需的时间叫作**半衰期**。
    - $\ce{^{238}U}$ 的半衰期为 45 亿年，衰变后形成 $\ce{^{206}Pb}$；测定化石中 $\ce{^{238}U}$ 与 $\ce{^{206}Pb}$ 的比例，可以推算化石的形成年代。
    - $\ce{^{14}C}$ 的半衰期为 5 730 年，可用于测定 7 万年以内化石的年代。

### 六、比较解剖学与胚胎学证据

**同源器官**

- 起源相同、结构和部位相似，但形态和功能不同的器官，叫作**同源器官**。
- 例如，人的上肢、猫的前肢、鲸的鳍和蝙蝠的翼，虽然外形和功能差别很大，但内部骨骼结构模式一致，都有肱骨、桡骨、尺骨、腕骨、掌骨和指骨。
- 同源器官的存在说明这些生物有共同的原始祖先。

**同功器官**

- 功能相同但起源不同的器官，叫作**同功器官**。
- 例如，鸟的翼和昆虫的翅都能用于飞行，但它们的起源和结构不同。

| 概念 | 含义 | 实例 |
|------|------|------|
| 同源器官 | 起源相同、结构相似、功能不同 | 人的上肢、猫的前肢、鲸的鳍、蝙蝠的翼 |
| 同功器官 | 功能相同、起源不同 | 鸟的翼、昆虫的翅 |
| 痕迹器官 | 退化、功能不明显的器官 | 人的阑尾、尾骨 |

**胚胎学证据**

- 脊椎动物在胚胎发育早期都有彼此相似的阶段。
- 人的胚胎在发育早期会出现鳃裂和尾，这与鱼的胚胎在发育早期出现鳃裂和尾非常相似，只是随着发育的进行，人的鳃裂和尾消失了。
- 这说明人和其他脊椎动物有共同的祖先。

### 七、分子水平的证据与分子钟

**分子水平的共同特征**

- 当今生物的细胞都有共同的结构基础，如细胞膜、细胞质、核糖体等。
- 所有生物共用一套遗传密码，都以 ATP 直接供能，DNA 和蛋白质等生物大分子具有共同点。
- 不同生物的 DNA 和蛋白质等生物大分子的差异大小，揭示了生物种类亲缘关系的远近。

**细胞色素 c 的差异**

| 生物 | 与人的细胞色素 c 氨基酸差异数 |
|------|------------------------------|
| 黑猩猩 | 0 |
| 猕猴 | 1 |
| 狗 | 11 |
| 金枪鱼 | 21 |
| 果蝇 | 27 |
| 天蚕蛾 | 31 |
| 链孢霉 | 43 |
| 酵母菌 | 44 |

- 细胞色素 c 约有 104 个氨基酸，其氨基酸序列每 2 000 万年才发生 $1\%$ 的改变。
- 与人的差异越小，说明亲缘关系越近；差异越大，说明亲缘关系越远。

**分子钟**

- 生物大分子的进化速率相对恒定，因此可以用分子差异的大小来推算物种分化的时间，这种方法称为**分子钟**。
- 例如，人与黑猩猩基因组的差异只有 $3\%$，说明二者的亲缘关系很近。

!!! tip "各类证据的关系"

    - 化石证据是直接的证据，揭示了生物进化的顺序；
    - 比较解剖学、胚胎学证据从形态结构上支持共同由来学说；
    - 细胞和分子水平的证据从物质基础上支持共同由来学说；
    - 各类证据互为补充、相互印证，共同支持生物有共同祖先的观点。

!!! note "本节小结"

    化石为研究生物进化提供了直接的证据，比较解剖学和胚胎学以及细胞和分子水平的研究，都给生物进化论提供了有力的支持。这些证据互为补充、相互印证，有力地支持了达尔文的共同由来学说，进而为解释适应和物种的形成提供了坚实的基础。
