# 第5章 基因突变及其他变异

## 5.1 基因突变和基因重组

### 一、基因突变的实例——镰状细胞贫血

- 正常人的红细胞呈中央微凹的圆饼状；镰状细胞贫血患者的红细胞呈弯曲的镰刀状，容易破裂，使人患溶血性贫血，严重时会导致死亡。
- 对患者血红蛋白分子的分析发现，组成血红蛋白分子的肽链上发生了**氨基酸的替换**：谷氨酸被缬氨酸取代。
- 根本原因是编码血红蛋白的基因中发生了**碱基对的替换**：DNA 上的 GAG 变为 GTG，转录出的 mRNA 上密码子由 GAG 变为 GUG。

!!! note "基因突变影响性状的途径"

    基因中碱基序列改变 → mRNA 碱基序列改变 → 蛋白质中氨基酸序列改变 → 蛋白质功能改变 → 性状改变。

- 该突变若发生在配子中，可遵循遗传规律传递给后代，因此镰状细胞贫血是可遗传的。
- 若基因中发生碱基的**增添或缺失**，同样会改变氨基酸序列，进而可能引起性状改变；当增添或缺失的碱基不是 3 的倍数时，突变位点之后的氨基酸序列往往会发生较大改变。

### 二、基因突变的概念

**基因突变**：DNA 分子中发生碱基的替换、增添或缺失，而引起的基因碱基序列的改变。

| 项目 | 说明 |
|------|------|
| 变异水平 | 分子水平，光学显微镜下无法观察 |
| 发生时期 | 主要发生在 DNA 复制时，即有丝分裂间期、减数第一次分裂前的间期 |
| 发生部位 | 可发生在生物个体发育的任何时期，可发生在不同 DNA 分子上，也可发生在同一 DNA 分子的不同部位 |
| 遗传情况 | 发生在配子中，遵循遗传规律传递给后代；发生在体细胞中，一般不能遗传 |

!!! tip "体细胞突变的特殊情况"

    有些植物的体细胞发生了基因突变，可以通过无性生殖遗传给后代。

### 三、基因突变的原因

| 类型 | 举例 | 作用机理 |
|------|------|----------|
| 物理因素 | 紫外线、X 射线及其他辐射 | 损伤细胞内的 DNA |
| 化学因素 | 亚硝酸盐、碱基类似物 | 改变核酸的碱基 |
| 生物因素 | 某些病毒 | 病毒的遗传物质影响宿主细胞的 DNA |
| 自发突变 | DNA 复制偶尔发生错误 | 没有外来因素影响时也可发生 |

### 四、基因突变的特点

1. **普遍性**：自然界中诱发基因突变的因素很多，基因突变也会自发产生，因此基因突变在生物界普遍存在。
2. **随机性**：可发生在生物个体发育的任何时期；可发生在细胞内不同的 DNA 分子上，以及同一 DNA 分子的不同部位。
3. **不定向性**：一个基因可以发生不同的突变，产生一个以上的等位基因。
4. **低频性**：自然状态下基因突变的频率很低。例如，果蝇每个配子中红眼基因突变为白眼基因的频率约为 $4\times10^{-5}$。
5. **多害少利性**：基因突变可能破坏生物体与现有环境的协调关系，因而对生物体有害；也有少数有利突变（如抗病性、耐旱性、抗药性突变）和中性突变。

!!! note "突变的有害与有利不是绝对的"

    突变的有害或有利往往取决于生物的生存环境，同一突变在不同环境中可能表现出不同的利害关系。

### 五、基因突变的结果与意义

- **结果**：产生新的基因（新的等位基因），不改变染色体上基因的数目和排列顺序。
- **意义**：
    - 基因突变是产生新基因的途径；
    - 基因突变是生物变异的**根本来源**；
    - 基因突变为生物的进化提供了丰富的**原材料**。

### 六、诱变育种

- **原理**：基因突变。
- **方法**：利用物理因素（如紫外线、X 射线等）或化学因素（如亚硝酸盐等）处理生物，提高突变率，再选择人类需要的变异类型。
- **实例**：用辐射方法处理大豆，选育出含油量高的大豆品种；航天育种（利用太空特殊环境诱导基因突变）。
- **优点**：可以提高突变率，在较短时间内获得更多的优良变异类型，大幅度改良某些性状。
- **缺点**：突变具有不定向性，有利变异少，需要大量处理实验材料，盲目性较大。

### 七、细胞的癌变

**致癌相关基因**

| 基因 | 正常功能 | 突变后的后果 |
|------|----------|--------------|
| 原癌基因 | 表达的蛋白质是细胞正常的生长和增殖所必需的 | 突变或过量表达使蛋白质活性过强，可能引起细胞癌变 |
| 抑癌基因 | 表达的蛋白质能抑制细胞的生长和增殖，或促进细胞凋亡 | 突变使蛋白质活性减弱或失去活性，也可能引起细胞癌变 |

- 健康人的细胞中本来就存在原癌基因和抑癌基因。
- 细胞癌变往往是**多个基因突变累积**的结果。以结肠癌为例：抑癌基因Ⅰ、Ⅱ、Ⅲ先后突变，原癌基因再发生突变，正常结肠上皮细胞逐步转变为癌细胞并发生转移。

**癌细胞的主要特征**

- 能够无限增殖；
- 形态结构发生显著变化；
- 细胞膜上的糖蛋白等物质减少，细胞之间的黏着性显著降低，容易在体内分散和转移。

!!! warning "致癌因子"

    致癌因子是导致癌症的重要因素。日常生活中应远离致癌因子，选择健康的生活方式。

### 八、基因重组

**概念**：在生物体进行有性生殖的过程中，控制不同性状的基因的重新组合。

**类型**

| 类型 | 发生时期 | 机制 | 结果 |
|------|----------|------|------|
| 非同源染色体上非等位基因的自由组合 | 减数第一次分裂后期 | 非同源染色体自由组合，非等位基因随之自由组合 | 产生不同基因型的配子 |
| 同源染色体上非姐妹染色单体的交叉互换 | 减数第一次分裂前期（四分体时期） | 同源染色体上的等位基因随非姐妹染色单体的互换而交换 | 产生新的基因组合 |
| 基因工程（重组 DNA 技术） | 体外 | 不同生物的基因重新组合 | 定向改造生物性状 |

- **结果**：产生新的基因型，但不产生新基因。
- **意义**：使产生的配子种类多样化，进而产生基因组合多样化的子代，其中一些子代可能含有适应某种变化的、生存所必需的基因组合，有利于物种在无法预测变化的环境中生存。基因重组也是生物变异的来源之一，对生物的进化具有重要意义。

### 九、基因突变与基因重组的比较

| 比较项目 | 基因突变 | 基因重组 |
|----------|----------|----------|
| 变异本质 | 基因碱基序列发生改变 | 控制不同性状的基因重新组合 |
| 发生时期 | 主要发生在 DNA 复制时 | 减数第一次分裂前期和后期 |
| 是否产生新基因 | 产生新基因（等位基因） | 不产生新基因，只产生新的基因型 |
| 是否改变基因数目和排列顺序 | 不改变 | 不改变 |
| 光学显微镜下是否可见 | 不可见 | 不可见 |
| 变异地位 | 生物变异的根本来源 | 生物变异的重要来源 |
| 共同意义 | 均为可遗传变异的来源，为生物进化提供原材料 | 同左 |

### 十、基因突变的类型（拓展）

**按碱基序列改变的方式分类**

| 类型 | 改变方式 | 对蛋白质的影响 | 举例 |
|------|----------|----------------|------|
| 碱基替换（错义突变） | 一个碱基对被另一个碱基对替换，导致密码子改变 | 氨基酸种类改变，可能影响蛋白质功能 | 镰状细胞贫血 |
| 碱基替换（无义突变） | 密码子变成终止密码子 | 肽链提前终止，蛋白质变短 | 某些遗传病 |
| 碱基替换（同义突变） | 密码子改变，但决定同一种氨基酸 | 蛋白质不变，性状不变 | 密码子简并性 |
| 碱基增添或缺失 | 增加或减少一个或几个碱基对 | 阅读框改变（移码突变），影响通常较大 | 某些遗传病 |

- 碱基替换只改变个别密码子，影响相对较小；碱基增添或缺失往往改变阅读框，导致其后所有密码子改变，影响通常较大。
- 但由于密码子的简并性，同义突变不会改变蛋白质的氨基酸序列，属于中性突变。

**按对性状的影响分类**

| 类型 | 含义 |
|------|------|
| 显性突变 | 突变基因在杂合状态下即可表现 |
| 隐性突变 | 突变基因需纯合时才表现 |
| 有利突变 | 提高生物对环境的适应能力 |
| 有害突变 | 破坏生物与现有环境的协调关系 |
| 中性突变 | 既不有利也不有害 |

!!! note "基因突变的多害少利性"

    基因突变可能破坏生物体与现有环境的协调关系，因此大多对生物体有害；但也有少数突变有利，如植物的抗病性突变、耐旱性突变，微生物的抗药性突变；还有些突变是中性的。

### 十一、基因突变与生物进化

- 基因突变是产生新基因的途径，是生物变异的根本来源，为生物的进化提供了丰富的原材料。
- 基因突变具有随机性和不定向性，而自然选择是定向的，决定生物进化的方向。
- 在自然状态下，基因突变的频率很低，但由于种群个体数量多，种群中产生的突变个体总数仍然较多。

**杂合子优势**

- 镰状细胞贫血主要流行于非洲的疟疾高发地区。
- 具有一个镰状细胞贫血突变基因的个体（杂合子）在氧含量正常的情况下并不表现出贫血症状，因为该个体能同时合成正常和异常的血红蛋白，并对疟疾具有较强的抵抗力。
- 因此，在疟疾高发地区，杂合子个体具有生存优势，突变基因在人群中的比例较高。
- 这说明基因突变的有利或有害不是绝对的，而是取决于生物所处的环境。

### 十二、航天育种与育种方式的比较

**航天育种**

- 将种子或生物材料搭载航天器送入太空，利用空间环境中的宇宙辐射、微重力、高真空等因素综合作用，诱发基因突变。
- 返回地面后，再经过选择、培育，获得优良新品种。
- 航天育种是诱变育种的一种，其原理仍然是基因突变。

| 育种方式 | 原理 | 主要优点 | 主要缺点 |
|----------|------|----------|----------|
| 诱变育种 | 基因突变 | 提高突变率，加快育种进程 | 盲目性大，有利变异少 |
| 杂交育种 | 基因重组 | 将不同亲本的优良性状组合在一起 | 育种周期长 |
| 单倍体育种 | 染色体变异 + 基因重组 | 明显缩短育种年限 | 技术复杂 |
| 多倍体育种 | 染色体变异 | 培育出茎秆粗壮、营养物质含量高的品种 | 结实率低，发育迟缓 |

!!! tip "诱变育种的实例"

    - 用辐射方法处理大豆，选育出含油量高的大豆品种；
    - 用诱变方法培育青霉素高产菌株；
    - 通过航天育种培育出太空椒、太空水稻等新品种。

!!! note "本节小结"

    可遗传变异包括基因突变、基因重组和染色体变异。其中基因突变能产生新基因，是变异的根本来源；基因重组能产生新的基因型，是形成生物多样性的重要原因之一。二者都在分子水平上发生，光学显微镜下无法观察到。
