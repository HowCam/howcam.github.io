# 第5章 基因突变及其他变异

## 5.2 染色体变异

### 一、染色体变异的概念

**染色体变异**：生物体的体细胞或生殖细胞内染色体数目或结构的变化。

- 染色体变异可在光学显微镜下观察到，这是它与基因突变、基因重组的重要区别。
- 染色体变异包括**染色体数目的变异**和**染色体结构的变异**两大类。

### 二、染色体数目的变异

染色体数目的变异可以分为两类：

1. 细胞内**个别染色体**的增加或减少。
2. 细胞内染色体数目以**一套完整的非同源染色体**为基数成倍地增加或成套地减少。

**染色体组**：细胞中一套非同源染色体。同一个染色体组内的染色体形态和功能各不相同，携带着控制一种生物生长发育、遗传和变异的全套遗传信息。

- 例如，野生马铃薯体细胞中有两个染色体组，每个染色体组包括 12 条形态和功能不同的非同源染色体。

!!! tip "染色体组数目的判断"

    - 根据染色体形态判断：细胞内形态相同的染色体有几条，就含有几个染色体组。
    - 根据基因型判断：控制同一性状的基因（同种字母）有几个，就含有几个染色体组。
    - 根据染色体数目和形态数推算：染色体组数 $=$ 染色体数 $\div$ 染色体形态数。

### 三、二倍体、多倍体和单倍体

| 概念 | 定义 | 发育起点 | 实例 |
|------|------|----------|------|
| 二倍体 | 体细胞中含有两个染色体组的个体 | 受精卵 | 几乎全部动物和过半数的高等植物 |
| 多倍体 | 体细胞中含有三个或三个以上染色体组的个体 | 受精卵 | 三倍体无子西瓜、四倍体葡萄、普通小麦 |
| 单倍体 | 体细胞中染色体数目与本物种配子染色体数目相同的个体 | 配子 | 蜜蜂的雄蜂、玉米的单倍体植株 |

!!! warning "单倍体的判断"

    单倍体不一定只含一个染色体组。由配子直接发育而来的个体，无论体细胞中含有几个染色体组，都称为单倍体；由受精卵发育而来的个体，体细胞中含有几个染色体组，就是几倍体。

### 四、多倍体

**形成原因**

- 减数分裂出现错误，形成含有两个染色体组的配子，与含有一个染色体组的配子结合，发育成三倍体；两个含两个染色体组的配子结合，发育成四倍体。
- 二倍体在胚或幼苗时期受某种因素影响，体细胞进行有丝分裂时染色体只复制而未分离，形成四倍体。

**特点**

- 与二倍体植株相比，多倍体植株常常茎秆粗壮，叶片、果实和种子都比较大，糖类和蛋白质等营养物质的含量都有所增加。
- 四倍体葡萄的果实比二倍体的大得多；四倍体番茄的维生素 C 含量比二倍体的几乎增加了一倍。

**三倍体不育的原因**

- 三倍体的原始生殖细胞中有三套非同源染色体，减数分裂时出现**联会紊乱**，不能形成可育的配子。
- 香蕉、三倍体无子西瓜的果实中没有种子，原因就在于此。

**人工诱导多倍体**

| 方法 | 处理对象 | 原理 |
|------|----------|------|
| 秋水仙素处理 | 萌发的种子或幼苗 | 抑制纺锤体的形成，使染色体不能移向细胞两极，从而引起细胞内染色体数目加倍 |
| 低温处理 | 萌发的种子或幼苗、分生组织 | 抑制纺锤体的形成，影响染色体被拉向两极，细胞不能分裂成两个子细胞 |

- 染色体数目加倍的细胞继续进行有丝分裂，就可能发育成多倍体植株。
- 应用：培育含糖量高的甜菜、三倍体无子西瓜等。

!!! warning "秋水仙素"

    秋水仙素（$\ce{C22H25O6N}$）是从百合科植物秋水仙的种子和球茎中提取的一种植物碱，有剧毒，使用时应当特别注意。

### 五、单倍体

- 单倍体植株与正常植株相比，长得弱小，而且高度不育。
- 自然条件下，玉米、高粱、水稻、番茄等二倍体植物偶尔也会出现单倍体植株。

**单倍体育种**

1. 采用**花药（或花粉）离体培养**的方法获得单倍体植株；
2. 用秋水仙素等人工诱导染色体数目加倍，恢复到正常植株的染色体数目。

| 项目 | 说明 |
|------|------|
| 原理 | 染色体数目变异 |
| 优点 | 明显缩短育种年限 |
| 原因 | 经染色体加倍得到的植株，每对染色体上成对的基因都是纯合的，自交后代不会发生性状分离 |

### 六、染色体结构的变异

染色体结构的改变，会使排列在染色体上的基因数目或排列顺序发生改变，导致性状的变异。大多数染色体结构变异对生物体是不利的，有的甚至会导致生物体死亡。

| 类型 | 含义 | 实例 |
|------|------|------|
| 缺失 | 染色体中某一片段缺失 | 果蝇缺刻翅；猫叫综合征（人 5 号染色体部分缺失） |
| 重复 | 染色体中增加某一片段 | 果蝇棒状眼 |
| 倒位 | 染色体中某一片段位置颠倒 | 果蝇卷翅 |
| 易位 | 染色体的某一片段移接到另一条非同源染色体上 | 果蝇花斑眼 |

!!! note "猫叫综合征"

    猫叫综合征是人的 5 号染色体部分缺失引起的遗传病。患儿哭声轻、音调高，很像猫叫，生长发育迟缓，并存在严重的智力障碍。

### 七、染色体结构变异与基因突变的比较

| 比较项目 | 染色体结构变异 | 基因突变 |
|----------|----------------|----------|
| 变异水平 | 细胞水平（染色体水平） | 分子水平 |
| 光学显微镜下是否可见 | 可见 | 不可见 |
| 基因数目是否改变 | 改变 | 不改变 |
| 基因排列顺序是否改变 | 改变 | 不改变 |
| 是否产生新基因 | 一般不产生 | 产生新基因 |
| 对生物体的影响 | 大多不利，甚至致死 | 多害少利 |

### 八、染色体组的判断方法

**染色体组的概念**

- 细胞中的一组非同源染色体，在形态和功能上各不相同，携带着控制一种生物生长发育、遗传和变异的全部信息，这样的一组染色体叫作一个**染色体组**。
- 例如，野生马铃薯体细胞中有两个染色体组，每个染色体组包括 12 条形态和功能不同的非同源染色体。

**判断方法**

| 方法 | 依据 |
|------|------|
| 看形态 | 细胞内同种形态的染色体有几条，就含有几个染色体组 |
| 看基因 | 控制同一性状的基因有几个，就含有几个染色体组 |
| 看数目 | 染色体组数 $=\dfrac{\text{染色体总数}}{\text{每个染色体组的染色体数}}$ |

**二倍体、多倍体与单倍体的判断**

| 类型 | 发育起点 | 体细胞染色体组数 | 实例 |
|------|----------|------------------|------|
| 二倍体 | 受精卵 | 2 个 | 人、果蝇、野生马铃薯 |
| 多倍体 | 受精卵 | 3 个或 3 个以上 | 三倍体无子西瓜、四倍体葡萄 |
| 单倍体 | 配子 | 与本物种配子染色体数相同 | 雄蜂、单倍体玉米 |

!!! warning "单倍体不一定只含一个染色体组"

    - 单倍体是指由配子直接发育而来的个体，其体细胞染色体数目与本物种配子染色体数目相同。
    - 例如，四倍体的配子含有两个染色体组，由该配子发育成的个体仍是单倍体，但含有两个染色体组。
    - 因此，判断单倍体关键是看**发育起点**，而不是看染色体组数。

### 九、单倍体育种与多倍体育种的比较

| 比较项目 | 单倍体育种 | 多倍体育种 |
|----------|------------|------------|
| 原理 | 染色体变异 | 染色体变异 |
| 方法 | 花药（或花粉）离体培养获得单倍体植株，再用秋水仙素处理使染色体数目加倍 | 用秋水仙素处理萌发的种子或幼苗 |
| 优点 | 明显缩短育种年限；得到的植株每对染色体上的基因都是纯合的，自交后代不发生性状分离 | 茎秆粗壮，叶片、果实和种子较大，糖类和蛋白质等营养物质含量增加 |
| 缺点 | 技术复杂，需要组织培养条件 | 结实率低，发育迟缓 |
| 实例 | 单倍体小麦、水稻育种 | 三倍体无子西瓜、四倍体葡萄 |

- 单倍体植株长得弱小，而且高度不育，因此需要人工诱导染色体数目加倍，恢复为正常植株后才能正常生殖。
- 单倍体育种得到的植株是纯合子，自交后代不会发生性状分离，因此能明显缩短育种年限。

### 十、三倍体无子西瓜的培育流程

1. 用秋水仙素处理二倍体西瓜的萌发种子或幼苗，使染色体数目加倍，得到四倍体植株（$4n$）。
2. 以四倍体植株作母本，二倍体植株作父本进行杂交，得到三倍体种子（$3n$）。
3. 将三倍体种子种下，长成三倍体植株。
4. 三倍体植株开花时，用二倍体西瓜的花粉刺激其子房，促进子房发育成果实。
5. 由于三倍体植株在减数分裂时同源染色体联会紊乱，不能形成正常的配子，因此果实中没有种子。

| 步骤 | 操作 | 结果 |
|------|------|------|
| 诱导四倍体 | 秋水仙素处理二倍体幼苗 | 染色体数目加倍，得到四倍体 |
| 杂交 | 四倍体（♀）× 二倍体（♂） | 得到三倍体种子 |
| 种植 | 三倍体种子萌发 | 长成三倍体植株 |
| 刺激子房 | 二倍体花粉涂抹三倍体雌蕊柱头 | 子房发育为无子果实 |

!!! note "无子西瓜为什么无子"

    三倍体植株的原始生殖细胞中有三套非同源染色体，减数分裂时同源染色体联会紊乱，不能形成可育的配子，因此不能形成种子。果实由子房发育而来，虽然没有种子，但果肉仍可正常发育。

!!! tip "无子西瓜的制种"

    三倍体无子西瓜不能通过种子繁殖后代，因此每年都需要用四倍体和二倍体杂交来制种。这也是无子西瓜种子价格较高的原因。

### 十一、低温诱导植物细胞染色体数目变化的实验

**实验原理**

- 用低温处理植物的分生组织细胞，能够抑制纺锤体的形成，影响细胞有丝分裂中染色体被拉向两极，导致细胞不能分裂成两个子细胞，于是植物细胞的染色体数目发生变化。
- 秋水仙素与低温诱导染色体数目加倍的原理相似，都是抑制纺锤体的形成。

**材料用具**

- 蒜或洋葱（均为二倍体，体细胞中染色体数目为 16）；
- 冰箱、显微镜、载玻片、盖玻片、卡诺氏液、甲紫溶液、盐酸、酒精等。

**方法步骤**

1. 将蒜（或洋葱）在冰箱冷藏室（$4^\circ\text{C}$）放置一周，取出后在室温（约 $25^\circ\text{C}$）培养，待长出约 1 cm 长的不定根。
2. 将整个装置放入冰箱冷藏室，诱导培养 $48\sim72\text{ h}$。
3. 剪取诱导处理的根尖 $0.5\sim1\text{ cm}$，放入卡诺氏液中浸泡 $0.5\sim1\text{ h}$ 固定细胞形态，然后用体积分数为 $95\%$ 的酒精冲洗 2 次。
4. 制作装片：解离 → 漂洗 → 染色 → 制片，操作方法与观察植物细胞有丝分裂的实验相同。
5. 先用低倍镜寻找染色体形态较好的分裂象，确认某个细胞发生染色体数目变化后，再用高倍镜观察。

| 步骤 | 目的 |
|------|------|
| 低温诱导 | 抑制纺锤体形成，使染色体数目加倍 |
| 卡诺氏液固定 | 固定细胞形态 |
| 解离 | 使组织中的细胞相互分离开来 |
| 漂洗 | 洗去解离液，便于染色 |
| 染色 | 使染色体着色，便于观察 |
| 制片 | 压片使细胞分散，便于观察 |

!!! warning "实验注意事项"

    - 解离后细胞已经死亡，因此观察到的细胞是固定在某一个分裂时期的静态图像。
    - 视野中既有正常的二倍体细胞，也有染色体数目发生改变的细胞，需要仔细寻找。
    - 低温诱导时间要适宜，时间过短效果不明显，时间过长可能影响细胞活性。

!!! note "本节小结"

    染色体变异包括数目变异和结构变异。数目变异既可表现为个别染色体的增减，也可表现为以染色体组为基数成倍或成套的增减；结构变异包括缺失、重复、倒位和易位四种类型。染色体变异可在光学显微镜下观察到，这一点与基因突变、基因重组不同。
