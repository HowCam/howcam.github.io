# 第3章 基因的本质

## 3.2 DNA的结构

### 一、DNA 双螺旋结构模型的构建

**构建过程**

| 时间 | 科学家 | 贡献 |
|------|--------|------|
| 1951 年 | 沃森、克里克 | 开始合作研究 DNA 结构，尝试搭建多种双螺旋和三螺旋模型，但都被否定 |
| — | 威尔金斯、富兰克林 | 应用 X 射线衍射技术获得高质量的 DNA 衍射图谱，沃森和克里克据此推算出 DNA 呈螺旋结构 |
| 1952 年 | 查哥夫 | 提供重要信息：DNA 中腺嘌呤（A）的量总是等于胸腺嘧啶（T）的量，鸟嘌呤（G）的量总是等于胞嘧啶（C）的量 |
| 1953 年 | 沃森、克里克 | 构建将碱基安排在双链螺旋内部、脱氧核糖—磷酸骨架安排在螺旋外部的模型，A 与 T 配对、G 与 C 配对，两条链方向相反 |

- 1953 年，沃森和克里克撰写的论文《核酸的分子结构——脱氧核糖核酸的一个结构模型》在英国《自然》杂志上刊载。
- 1962 年，沃森、克里克和威尔金斯三人因这一研究成果共同获得诺贝尔生理学或医学奖。

!!! note "模型成功的关键"

    A—T 碱基对与 G—C 碱基对具有相同的形状和直径，这样组成的 DNA 分子具有恒定的直径，能够解释 A、T、G、C 的数量关系。模型与基于 X 射线衍射照片推算出的结构相符。

### 二、DNA 双螺旋结构的主要特点

1. DNA 是由**两条单链**组成的，这两条链按**反向平行**方式盘旋成双螺旋结构。
2. DNA 中的**脱氧核糖和磷酸交替连接**，排列在外侧，构成**基本骨架**；**碱基排列在内侧**。
3. 两条链上的碱基通过**氢键**连接成碱基对，并且碱基配对具有一定的规律：A 一定与 T 配对，G 一定与 C 配对。碱基之间的这种一一对应的关系，叫作**碱基互补配对原则**。

### 三、DNA 结构的细节

**脱氧核苷酸的连接**

- 每个脱氧核苷酸由一分子磷酸、一分子脱氧核糖和一分子含氮碱基组成。
- 脱氧核糖上与碱基相连的碳叫作 $1'-\text{C}$，与磷酸基团相连的碳叫作 $5'-\text{C}$。
- 相邻两个脱氧核苷酸之间，通过前一个脱氧核苷酸的 $3'-\text{C}$ 上的羟基与后一个脱氧核苷酸的磷酸基团形成磷酸二酯键而连接。

**5' 端与 3' 端**

- DNA 的一条单链具有两个末端：一端有一个游离的磷酸基团，称作 **5' 端**；另一端有一个羟基（$\ce{-OH}$），称作 **3' 端**。
- DNA 的两条单链走向相反：从双链的一端起始，一条单链是从 5' 端到 3' 端的，另一条单链则是从 3' 端到 5' 端的。

**碱基配对**

- A 与 T 之间形成 **2 个氢键**，G 与 C 之间形成 **3 个氢键**。
- 因此，G 与 C 的含量越高的 DNA 分子，结构越稳定。

| 碱基对 | 氢键数 | 嘌呤—嘧啶 |
|--------|--------|-----------|
| A—T | 2 | 腺嘌呤—胸腺嘧啶 |
| G—C | 3 | 鸟嘌呤—胞嘧啶 |

### 四、DNA 双链中的碱基数量关系

设 DNA 双链中 A、T、G、C 的数量分别为 $A$、$T$、$G$、$C$。

- 根据碱基互补配对原则：$A=T$，$G=C$。
- 嘌呤总数等于嘧啶总数：$A+G=T+C$。
- 因此：$\dfrac{A+G}{T+C}=1$，$\dfrac{A+C}{T+G}=1$。
- $\dfrac{A+T}{G+C}$ 的值在双链中与在每条单链中相等，但没有固定值，可反映 DNA 的特异性。

!!! tip "单链与双链的数量关系"

    - 在双链 DNA 中，$A=T$、$G=C$ 始终成立。
    - 在单链 DNA 中，$A$ 不一定等于 $T$，$G$ 不一定等于 $C$。
    - 若一条链中 $\dfrac{A+T}{G+C}=a$，则其互补链及整个双链中该比值也为 $a$。
    - 若一条链中 $\dfrac{A+G}{T+C}=b$，则其互补链中该比值为 $\dfrac{1}{b}$。

### 五、DNA 结构的特性

| 特性 | 原因 |
|------|------|
| 稳定性 | 脱氧核糖和磷酸交替连接构成基本骨架；碱基对通过氢键连接；碱基互补配对原则保证结构规则 |
| 多样性 | 组成 DNA 的碱基只有 4 种，但碱基对的排列顺序千变万化 |
| 特异性 | 每种 DNA 分子都有特定的碱基排列顺序 |

- DNA 的多样性和特异性是生物体多样性和特异性的物质基础。

### 六、制作 DNA 双螺旋结构模型

**模型设计要点**

1. 明确用何种材料分别代表磷酸、脱氧核糖和碱基，并正确连接三种物质。
2. 明确每个脱氧核苷酸之间的连接部位，正确连接脱氧核苷酸。
3. 体现 DNA 两条链的反向平行关系。
4. 体现两条链碱基之间的互补配对关系。

!!! note "模型制作中的数量关系"

    - 每个脱氧核苷酸中，磷酸和脱氧核糖交替连接构成骨架，碱基连接在脱氧核糖上。
    - 两条链上的 A 与 T 配对、G 与 C 配对，因此模型中 A 的数量等于 T 的数量，G 的数量等于 C 的数量。

### 七、DNA 指纹技术

- 两个随机个体具有相同 DNA 序列的可能性微乎其微，因此 DNA 可以像指纹一样用来识别身份。
- 应用时，首先用合适的酶将待检测的样品 DNA 切成片段，再用电泳的方法将这些片段按大小分开，最后形成 DNA 指纹图。
- 每个人的 DNA 指纹图是独一无二的，可以根据指纹图的吻合程度确认身份。
- 应用：刑侦鉴定、亲子鉴定、死者遗骸的鉴定等。

### 八、碱基比例的计算规律（拓展）

**基本关系**

- 在双链 DNA 中：$A=T$，$G=C$，$A+G=T+C$。
- 因此：$\dfrac{A+G}{T+C}=1$，$\dfrac{A+C}{T+G}=1$。
- 嘌呤总数等于嘧啶总数：$A+G=T+C$。

**单链与双链的关系**

| 比值 | 一条链 | 互补链 | 整个双链 |
|------|--------|--------|----------|
| $\dfrac{A+T}{G+C}$ | $a$ | $a$ | $a$ |
| $\dfrac{A+G}{T+C}$ | $b$ | $\dfrac{1}{b}$ | $1$ |
| $\dfrac{A+G}{A+T+G+C}$ | $c$ | 不一定等于 $c$ | 一般不等于 $c$ |

- 若一条链中 $A+T$ 占该链碱基总数的 $x\%$，则整个双链中 $A+T$ 也占 $x\%$。
- 若一条链中 $A$ 占该链的 $x\%$，则互补链中 $T$ 占该链的 $x\%$，但整个双链中 $T$ 占 $x\%$ 不一定成立。

**示例**

- 某双链 DNA 分子中，$A$ 占碱基总数的 $28\%$，则：
    - $T=28\%$，$A+T=56\%$；
    - $G=C=\dfrac{1-56\%}{2}=22\%$。
- 若一条链中 $A:G:T:C=1:2:3:4$，则：
    - 该链中 $A+T$ 占 $\dfrac{1+3}{1+2+3+4}=40\%$；
    - 整个双链中 $A+T$ 也占 $40\%$；
    - 互补链中 $A:G:T:C=3:4:1:2$。

**氢键数与磷酸二酯键数**

| 项目 | 计算 |
|------|------|
| 氢键数 | $2\times(A-T\text{ 对数})+3\times(G-C\text{ 对数})$ |
| 双链 DNA 中磷酸二酯键数 | $2(n-1)$（$n$ 为碱基对数） |
| 单链中磷酸二酯键数 | $n-1$（$n$ 为核苷酸数） |

!!! tip "计算的关键"

    - 先确定已知量是占**双链**还是占**单链**的比例；
    - 利用 $A=T$、$G=C$ 以及互补链的碱基关系进行换算；
    - 氢键数取决于 $G-C$ 碱基对的数量，$G-C$ 越多，DNA 越稳定。

### 九、DNA 的变性与复性

**变性**

- 在某些理化因素（如高温、强碱）的作用下，DNA 双链的氢键断裂，解开成两条单链，这种现象叫作 **DNA 变性**。
- 变性只破坏氢键，不破坏磷酸二酯键，因此 DNA 的一级结构（核苷酸序列）不变。

**复性**

- 变性 DNA 在适当条件下（如缓慢冷却），两条单链又可以重新配对，恢复双螺旋结构，这种现象叫作 **DNA 复性**。
- 复性时，互补的碱基序列重新形成氢键，因此复性具有特异性。

**解链温度（$T_m$）**

- DNA 变性一半时的温度称为解链温度（$T_m$）。
- $G-C$ 碱基对越多，氢键越多，$T_m$ 越高，DNA 越稳定。

!!! note "变性与复性的应用"

    - **PCR 技术**：通过高温变性使 DNA 双链解开，低温复性使引物与模板结合，再在中温下延伸。
    - **分子杂交**：用标记的 DNA 单链与待测 DNA 进行杂交，根据是否形成双链判断序列的互补关系，可用于基因检测。

### 十、DNA 结构发现的科学方法

| 方法 | 作用 |
|------|------|
| X 射线晶体衍射 | 获得 DNA 的衍射图谱，推算 DNA 呈螺旋结构及螺旋的直径、间距 |
| 模型建构 | 根据已有事实和数据，搭建 DNA 双螺旋结构模型 |
| 数学分析 | 分析碱基数量关系，发现 $A=T$、$G=C$ 的规律 |

- 沃森和克里克的成功，建立在威尔金斯和富兰克林提供的 X 射线衍射图谱、查哥夫发现的碱基数量关系，以及他们对模型不断修正的基础之上。
- 这体现了科学研究中**多学科交叉**、**合作交流**和**证据推理**的重要性。

### 十一、本节小结

DNA 由两条反向平行的单链盘旋成双螺旋结构，脱氧核糖和磷酸交替连接构成基本骨架，碱基排列在内侧并通过氢键形成碱基对，遵循碱基互补配对原则。DNA 的碱基排列顺序千变万化，构成了 DNA 的多样性和特异性。
