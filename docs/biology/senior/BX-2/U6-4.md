# 第6章 生物的进化

## 6.4 协同进化与生物多样性的形成

### 一、协同进化

**协同进化**：不同物种之间、生物与无机环境之间在相互影响中不断进化和发展。

**实例**

| 实例 | 协同进化的表现 |
|------|----------------|
| 猎豹与羚羊 | 自然选择有利于羚羊种群中肌肉发达、动作敏捷的个体，也有利于猎豹种群中跑得快的个体，两个物种的进化过程宛如一场漫长的“军备竞赛” |
| 兰花与传粉蛾 | 兰花长着细长的花距，蛾类生有同样细长的吸管状口器，二者相互适应 |
| 光合生物与大气成分 | 最早的光合生物的出现使原始大气中有了氧气，为好氧生物的出现创造了前提条件 |
| 被子植物与传粉昆虫 | 被子植物的出现为传粉昆虫的形成创造了条件，传粉昆虫又成为食虫鸟类繁盛的前奏 |

**捕食者的作用**

- 捕食者所吃掉的大多是被捕食者中年老、病弱或年幼的个体，客观上起到了促进种群发展的作用。
- 美国生态学家斯坦利提出**“收割理论”**：捕食者往往捕食个体数量多的物种，这样就会避免出现一种或少数几种生物在生态系统中占绝对优势的局面，为其他物种的形成腾出空间。捕食者的存在有利于增加物种多样性。

!!! note "协同进化的结果"

    通过漫长的协同进化过程，地球上不仅出现了千姿百态的物种，丰富多彩的基因库，而且形成了多种多样的生态系统。

### 二、生物多样性

**生物多样性的三个层次**

| 层次 | 含义 |
|------|------|
| 遗传多样性（基因多样性） | 种群内和种群间基因的多样性 |
| 物种多样性 | 地球上生物种类的丰富程度 |
| 生态系统多样性 | 生态系统的类型、结构和功能的多样性 |

- 生物多样性的形成经历了漫长的进化历程，是协同进化的结果。

### 三、生物进化的历程

| 时间 | 主要事件 |
|------|----------|
| 46 亿年前 | 地球形成 |
| 30 多亿年前 | 生命的起源 |
| 35 亿年前 | 出现古细菌化石，是目前发现的最早的生物化石 |
| 35 亿～15 亿年前 | 海洋中主要是种数不多的细菌（包括蓝细菌），均为原核生物；生态系统只有生产者和分解者，属于两极生态系统 |
| 真核生物出现后 | 有性生殖出现，生物通过有性生殖实现基因重组，增强了生物变异的多样性，进化速度明显加快 |
| 5.4 亿～5.0 亿年前 | 寒武纪大爆发，海洋中大量无脊椎动物物种爆发式地迅速形成；消费者出现，生态系统结构更加复杂 |
| 约 4 亿年前 | 造山运动使海洋缩小、陆地扩大，一些海洋植物开始适应陆地生活，形成原始陆生植物（主要是蕨类植物） |
| 4 亿年前之后 | 出现原始两栖类；裸子植物和被子植物先后成为生产者中的主角；鸟类、哺乳类成为占优势的动物类群 |
| 6 600 万年前 | 恐龙在白垩纪末全部绝灭，为哺乳类的兴盛腾出了空间 |

**进化顺序**

- 生物由简单到复杂、由低等到高等、由水生到陆生。
- 生态系统的结构由只有生产者和分解者的两极生态系统，发展为包含生产者、消费者和分解者的三极生态系统。

!!! note "最早出现的生物"

    地球上的原始大气中是没有氧气的，因此最早出现的生物都是厌氧（进行无氧呼吸）的；最早的光合生物出现后，原始大气中有了氧气，为好氧生物的出现创造了前提条件。

### 四、生物进化理论在发展

以自然选择学说为核心的现代生物进化理论对自然界的生命史作出了科学的解释，但生物进化过程复杂而漫长，仍有许多争论和疑点。

| 学说或观点 | 主要内容 |
|------------|----------|
| 中性学说 | 大量的基因突变是中性的，自然选择对这些基因突变不起作用；这些基因突变经过长期积累，会导致种群间遗传物质出现较大差别。有人主张决定生物进化方向的是中性突变的逐渐积累，而不是自然选择 |
| 间断平衡观点 | 物种形成并不都是渐变的过程，而是物种长期稳定与迅速形成新种交替出现的过程 |
| 自然选择学说 | 更多学者认为，基因突变并不都是中性的，有些基因突变反映在个体的性状上，与环境相适应的程度有差异，因此不能否认自然选择的作用 |

- 以自然选择学说为核心的进化理论比其他学说的影响要广泛和深远，它仍然是以后各个方面研究的基础。
- 生物进化理论不会停滞不前，而是在不断发展。

### 五、现代生物进化理论的主要内容

| 要点 | 内容 |
|------|------|
| 适应的来源 | 适应是自然选择的结果 |
| 基本单位 | 种群是生物进化的基本单位 |
| 原材料 | 突变和基因重组提供进化的原材料 |
| 进化方向 | 自然选择导致种群基因频率的定向改变 |
| 物种形成 | 通过隔离形成新的物种，生殖隔离是新物种形成的标志 |
| 进化过程 | 生物进化的过程实际上是生物与生物、生物与无机环境协同进化的过程 |
| 多样性 | 生物多样性是协同进化的结果 |

!!! tip "保护生物多样性就是保护人类自己"

    人类也是生物进化的产物。在自然界的生存斗争中，人类凭借非凡的大脑、灵巧的双手和群体的力量，已经拥有了其他生物无可比拟的生存优势，并且对其他物种的进化产生了重要影响。包括人类在内的所有生物都是在相互依存、相互制约中生存和发展的，人类的生存和发展始终受益于生物多样性。

### 六、生物多样性形成的关键事件（拓展）

| 关键事件 | 意义 |
|----------|------|
| 生命的起源 | 原始地球的无机物在高温、紫外线、雷电等条件下形成有机小分子，进而形成生物大分子，最终形成原始生命 |
| 光合生物的出现 | 原始大气中开始有氧气，为好氧生物的出现创造条件 |
| 真核生物的出现 | 细胞结构复杂化，为有性生殖和多细胞生物的出现奠定基础 |
| 有性生殖的出现 | 通过基因重组增强变异的多样性，进化速度明显加快 |
| 寒武纪大爆发 | 海洋中大量无脊椎动物物种爆发式地迅速形成，消费者出现，生态系统结构更加复杂 |
| 植物登陆 | 一些海洋植物开始适应陆地生活，形成原始陆生植物 |
| 动物登陆 | 原始两栖类出现，随后爬行类、鸟类和哺乳类相继繁盛 |
| 恐龙绝灭 | 为哺乳类的兴盛腾出空间 |
| 人类的出现 | 人类通过劳动和智慧对生物圈产生重要影响 |

- 生物进化的总体趋势是：由简单到复杂、由低等到高等、由水生到陆生。
- 生态系统的结构由只有生产者和分解者的两极生态系统，发展为包含生产者、消费者和分解者的三极生态系统。

!!! note "最早出现的生物"

    地球上的原始大气中是没有氧气的，因此最早出现的生物都是厌氧（进行无氧呼吸）的。最早的光合生物出现后，原始大气中有了氧气，为好氧生物的出现创造了前提条件。

### 七、协同进化的类型与实例

**协同进化的概念**

- 不同物种之间、生物与无机环境之间在相互影响中不断进化和发展，这就是**协同进化**。

| 类型 | 含义 | 实例 |
|------|------|------|
| 互利共生 | 两种生物相互依存，彼此有利 | 某种兰花与专门给它传粉的蛾；豆科植物与根瘤菌 |
| 捕食与被捕食 | 捕食者与被捕食者相互选择、共同进化 | 猎豹与羚羊的“军备竞赛” |
| 寄生与宿主 | 寄生者与宿主相互适应 | 寄生虫与宿主 |
| 竞争 | 竞争物种相互影响 | 同一环境中的不同植物 |
| 生物与无机环境 | 生物改变环境，环境又影响生物 | 光合生物改变大气成分 |

**捕食者的作用**

- 捕食者所吃掉的大多是被捕食者中年老、病弱或年幼的个体，客观上起到了促进种群发展的作用。
- 美国生态学家斯坦利提出“收割理论”：捕食者往往捕食个体数量多的物种，避免出现一种或少数几种生物在生态系统中占绝对优势的局面，为其他物种的形成腾出空间。
- 因此，捕食者的存在有利于增加物种多样性。

!!! tip "协同进化的普遍性"

    - 一种植物专门由一种昆虫传粉的情形并不少见，昆虫传粉的专门化有利于植物繁衍后代，虫媒花与传粉昆虫在相互影响中协同进化。
    - 生物与无机环境之间也存在协同进化，例如光合生物释放氧气改变了原始大气成分，为好氧生物的出现创造了条件。

### 八、生物多样性的保护

**保护生物多样性的意义**

- 生物多样性包括遗传多样性、物种多样性和生态系统多样性三个层次。
- 生物多样性是协同进化的结果，是人类赖以生存和发展的基础。
- 保护生物多样性就是保护人类自己。

**保护措施**

| 措施 | 内容 | 特点 |
|------|------|------|
| 就地保护 | 建立自然保护区，保护生物及其栖息环境 | 最有效的保护措施 |
| 易地保护 | 将濒危物种迁出原地，进行特殊保护和管理 | 适用于就地保护困难的物种 |
| 建立种质库 | 保存种子、精子、卵细胞等遗传资源 | 保护遗传多样性 |
| 法律法规 | 制定相关法律，禁止乱捕滥猎、乱砍滥伐 | 提供法律保障 |
| 宣传教育 | 提高公众的保护意识 | 基础性工作 |

- 保护生物多样性并不意味着禁止开发和利用，而是要在保护的基础上合理利用，实现可持续发展。
- 人类对濒危动植物的保护，是对自然界正常自然选择的一种干预，目的是维持生态系统的稳定和生物多样性。

!!! warning "保护生物多样性的误区"

    - 保护生物多样性不是禁止利用生物资源，而是合理利用、可持续利用。
    - 保护生物多样性不仅是保护珍稀物种，也包括保护普通物种及其栖息环境。
    - 保护生物多样性需要政府、社会和公众的共同参与。

!!! note "本节小结"

    不同物种之间、生物与无机环境之间在相互影响中不断进化和发展，这就是协同进化。生物多样性包括遗传多样性、物种多样性和生态系统多样性三个层次，是协同进化的结果。现代生物进化理论以自然选择学说为核心，仍在不断发展。
