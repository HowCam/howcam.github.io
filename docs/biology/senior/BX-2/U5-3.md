# 第5章 基因突变及其他变异

## 5.3 人类遗传病

### 一、人类遗传病的概念

**人类遗传病**：通常是指由遗传物质改变而引起的人类疾病。

- 随着医疗卫生条件的改善，人类的传染性疾病大多已逐渐得到控制，而遗传性疾病的发病率和死亡率却有逐年增高的趋势。
- 我国有 $20\%\sim25\%$ 的人患有遗传病，仅唐氏综合征患者的总数就有 60 万人以上。

### 二、人类常见遗传病的类型

人类遗传病主要可以分为**单基因遗传病**、**多基因遗传病**和**染色体异常遗传病**三大类。

| 类型 | 概念 | 特点 | 实例 |
|------|------|------|------|
| 单基因遗传病 | 受一对等位基因控制的遗传病 | 种类多，目前发现 8 000 多种；遵循孟德尔遗传规律 | 显性：多指、并指、软骨发育不全；隐性：镰状细胞贫血、白化病、苯丙酮尿症 |
| 多基因遗传病 | 受两对或两对以上等位基因控制的遗传病 | 在群体中发病率比较高；常表现家族聚集现象；易受环境影响 | 原发性高血压、冠心病、哮喘、青少年型糖尿病 |
| 染色体异常遗传病 | 由染色体变异引起的遗传病（简称染色体病） | 已发现 500 多种，几乎涉及人类的每一对染色体 | 唐氏综合征（21 三体综合征）、猫叫综合征 |

**唐氏综合征**

- 又称 21 三体综合征，是一种常见的染色体病。
- 患者智力低于常人，身体发育缓慢，并表现出特殊的面容。
- 对患者进行染色体检查，可以看到患者比正常人增多了一条 21 号染色体。

!!! warning "先天性疾病与遗传病的区别"

    - 先天性疾病不一定是遗传病，例如母亲在妊娠早期受环境因素影响而导致的胎儿发育异常。
    - 家族性疾病也不一定是遗传病，例如因饮食中缺乏维生素 A 而导致的一家族多人患夜盲症。

### 三、调查人群中的遗传病

**发病率计算公式**

\[
\text{某种遗传病的发病率}=\frac{\text{某种遗传病的患者数}}{\text{某种遗传病的被调查人数}}\times100\%
\]

**调查方法**

| 调查内容 | 调查对象 | 注意事项 |
|----------|----------|----------|
| 某种遗传病的发病率 | 人群中随机抽样 | 调查群体要足够大，可在班级、年级中汇总数据 |
| 某种遗传病的遗传方式 | 患者家系 | 绘制系谱图，判断显隐性及基因所在染色体 |

- 调查时最好选取群体中发病率较高的单基因遗传病，如红绿色盲、白化病、高度近视（600 度以上）等。
- 每个小组可调查周围熟悉的 $4\sim10$ 个家庭（或家系）中遗传病的情况。

### 四、遗传病的检测和预防

**遗传咨询**

1. 医生对咨询对象进行身体检查，了解家族病史，对是否患有某种遗传病作出诊断；
2. 分析遗传病的传递方式；
3. 推算出后代的再发风险率；
4. 向咨询对象提出防治对策和建议，如进行产前诊断、终止妊娠等。

**产前诊断**

- **概念**：在胎儿出生前，医生用专门的检测手段，确定胎儿是否患有某种遗传病或先天性疾病。
- **手段**：羊水检查、B 超检查、孕妇血细胞检查以及基因检测等。

**基因检测**

- **概念**：通过检测人体细胞中的 DNA 序列，以了解人体的基因状况。人的血液、唾液、精液、毛发或人体组织等，都可以用来进行基因检测。
- **意义**：
    - 可以精确地诊断病因，帮助医生对症下药；
    - 可以预测个体患病的风险，帮助个体通过改善生存环境和生活习惯，规避或延缓疾病的发生；
    - 检测父母是否携带遗传病的致病基因，能够预测后代患这种疾病的概率。

!!! question "基因检测的利与弊"

    基因检测可以精确诊断病因、预测患病风险，但也存在争议。人们担心由于缺陷基因的检出，在就业、保险等方面受到不平等的待遇，还涉及个人隐私的保护问题。

**基因治疗**

- **概念**：用正常基因取代或修补患者细胞中有缺陷的基因，从而达到治疗疾病的目的。
- **实例**：1990 年，美国科学家实施了世界上第一例临床基因治疗，患者是一位患有重症联合免疫缺陷病的 4 岁女孩。科学家从她体内取出白细胞，转入能够合成腺苷脱氨酶（ADA）的正常基因，再将导入了正常基因的白细胞输入她体内，患者的症状得到明显改善。
- **现状**：研究已取得不少进展，但在临床上还存在稳定性和安全性等问题。

### 五、遗传病的预防措施

| 措施 | 作用 |
|------|------|
| 禁止近亲结婚 | 降低隐性遗传病的发病率 |
| 遗传咨询 | 分析传递方式，推算再发风险率，提出防治建议 |
| 产前诊断 | 在胎儿出生前确定是否患有某种遗传病或先天性疾病 |
| 新生儿疾病筛查 | 及早发现并治疗某些遗传病，降低危害 |

!!! tip "近亲结婚发病率高的原因"

    近亲结婚的双方从共同祖先那里获得同一种隐性致病基因的可能性较大，婚配后后代隐性致病基因纯合的机会大大增加，因此隐性遗传病的发病率明显升高。

### 六、遗传病概率的计算（拓展）

**单基因遗传病的计算步骤**

1. 根据系谱图判断遗传方式（常染色体显性/隐性、伴 X 显性/隐性、伴 Y）；
2. 确定相关个体的基因型（注意显性个体的基因型可能有两种）；
3. 求出配子的种类及概率；
4. 利用乘法定律和加法定律计算子代的患病概率。

**示例**

- 白化病（常染色体隐性遗传）：双亲表型正常，生了一个白化病孩子，则双亲均为 $Aa$，再生一个孩子患病的概率为 $\dfrac{1}{4}$。
- 红绿色盲（伴 X 隐性遗传）：女性携带者（$X^BX^b$）× 正常男性（$X^BY$）：
    - 子代中男孩患病的概率为 $\dfrac{1}{2}$；
    - 子代中患病男孩的概率为 $\dfrac{1}{4}$。

**两种遗传病同时考虑**

| 表述 | 计算方法 |
|------|----------|
| 只患甲病 | $P(\text{甲})\times P(\text{乙正常})$ |
| 只患乙病 | $P(\text{甲正常})\times P(\text{乙})$ |
| 患两种病 | $P(\text{甲})\times P(\text{乙})$ |
| 只患一种病 | 只患甲病 $+$ 只患乙病 |
| 完全正常 | $P(\text{甲正常})\times P(\text{乙正常})$ |
| 患病 | $1-P(\text{完全正常})$ |

!!! tip "概率计算的关键"

    - 先分别分析每一种遗传病，再按题意组合；
    - 注意区分“患病男孩”和“男孩患病”；
    - 注意题目是否给出“已知某个体表现正常”等条件，条件概率会改变分母。

### 七、基因检测与伦理问题

**基因检测**

- 基因检测是通过检测个体的基因序列，了解其是否携带致病基因或易感基因的技术。
- 应用：遗传病诊断、产前诊断、肿瘤易感性评估、个体化用药等。

**伦理与社会问题**

| 问题 | 说明 |
|------|------|
| 隐私保护 | 基因信息属于个人隐私，泄露可能对个人造成伤害 |
| 基因歧视 | 可能在学习、就业、保险等方面受到不公平对待 |
| 基因编辑 | 对人类生殖细胞进行基因编辑涉及伦理和法律问题 |
| 知情同意 | 基因检测应尊重被检测者的知情权和选择权 |

- 基因组编辑技术具有类似“手术刀”的潜力，可用于治疗基因突变导致的疾病，但技术本身存在识别准确性等问题。
- 对人类基因进行“改造”时要严格遵守法律法规，不能违反人类的伦理道德。
- 我国已颁布相关法规，对基因检测、辅助生殖和基因组编辑等技术的应用进行规范管理。

!!! note "本节小结"

    人类遗传病包括单基因遗传病、多基因遗传病和染色体异常遗传病三大类。通过遗传咨询、产前诊断和基因检测等手段，可以在一定程度上有效地预防遗传病的产生和发展。基因检测和基因治疗等现代科技是一把双刃剑，既要看到其为人类造福的一面，也要关注其可能带来的伦理和社会问题。
