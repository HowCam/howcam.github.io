# 第1章 遗传因子的发现

## 1.2 孟德尔的豌豆杂交实验（二）

### 一、两对相对性状的杂交实验

1. **两对相对性状**：豌豆的子叶颜色（黄色与绿色）和种子形状（圆粒与皱粒）。

2. **亲本选择**：纯种黄色圆粒（YYRR）× 纯种绿色皱粒（yyrr）。

3. **$F_1$结果**：全部为黄色圆粒，说明黄色对绿色为显性，圆粒对皱粒为显性。

4. **$F_1$自交（$F_2$）结果**：

    - 黄色圆粒：315粒

    - 黄色皱粒：108粒

    - 绿色圆粒：101粒

    - 绿色皱粒：32粒

    - 比例约为 **9:3:3:1**

!!! note "关键比例"

    - **9:3:3:1** 是两对相对性状杂交实验中 $F_2$ 的性状分离比

    - 每一对性状仍遵循 3:1 的分离比

!!! note "出现 9:3:3:1 的必要条件"
    1. 两对等位基因分别位于 **两对同源染色体** 上
    2. 每对等位基因的分离互不干扰（遵循分离定律）
    3. $F_1$ 为 **双杂合个体**（YyRr）
    4. **完全显性**（显性基因对隐性基因完全显性）
    5. 各种配子的成活率相同
    6. 雌雄配子随机结合
    7. 各种基因型的成活率相同

### 二、对自由组合现象的解释
   | 配子类型 | 比例 |
   |---------|------|
   | YR      | 1/4  |
   | Yr      | 1/4  |
   | yR      | 1/4  |
   | yr      | 1/4  |

   4. 雌雄配子的结合是随机的，形成 16 种组合，9 种基因型，4 种表现型。

6. **测交实验验证**：

    - $F_1$（YyRr）× 隐性纯合（必要）（yyrr）

    - 预期结果：黄色圆粒 : 黄色皱粒 : 绿色圆粒 : 绿色皱粒 = **1:1:1:1**

    - 实验结果与预期相符，验证了假说的正确性。

    - 测交实验必须有隐性纯合子，Yyrr × yyRr 无法验证自由组合定律。

!!! note "验证自由组合定律的方法"
    | 方法 | 操作 | 预期结果（双杂合自交） | 意义 |
    |------|------|----------------------|------|
    | **自交法** | $F_1$ 自交 | 9:3:3:1 | 直接验证 $F_2$ 性状分离比 |
    | **测交法** | $F_1$ × 隐性纯合子 | 1:1:1:1 | 验证配子类型及比例 |
    | **花粉鉴定法** | 观察 $F_1$ 花粉的性状 | 1:1:1:1 | 直接观察配子类型 |
    | **单倍体育种法** | 花粉离体培养 | 验证基因型种类 | 从配子角度直接验证 |

### 三、孟德尔第二定律（自由组合定律）

7. **自由组合定律（孟德尔第二定律）**：

    - 控制不同性状的遗传因子在形成配子时自由组合

    - 时间：有性生殖的生物形成配子时

    - 实质：等位基因分离，非同源染色体上的非等位基因自由组合

8. **分离定律与自由组合定律的关系**：

    - 分离定律是自由组合定律的基础

    - 在分析多对相对性状时，应逐对分析，再组合

!!! tip "解题技巧"

    求解自由组合问题的基本步骤：

    1. 先将每对性状单独分析

    2. 再将各对性状的分析结果组合（概率相乘）

### 四、孟德尔实验方法的启示

9. **孟德尔获得成功的原因**：

    1. 正确选用实验材料（豌豆）

    2. 合理运用数学统计方法（统计分析 $F_2$ 的性状分离比）

    3. 创新运用假说—演绎法

    4. 科学设计实验程序（先研究一对，再研究多对）

10. **假说—演绎法**：

    - **提出问题**：观察实验，发现问题

    - **提出假说**：解释现象，作出假设

    - **演绎推理**：根据假说，推测结果

    - **实验验证**：实施实验，验证预测

    - **得出结论**：总结规律，形成理论

### 五、知识点总结

| 定律 | 研究对象 | 本质 |
|------|---------|------|
| 分离定律 | 一对相对性状 | 等位基因分离 |
| 自由组合定律 | 两对及两对以上相对性状 | 等位基因分离，非等位基因自由组合 |
