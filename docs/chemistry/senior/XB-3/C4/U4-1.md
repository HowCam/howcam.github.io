# 第四章 生物大分子

## 第一节 糖类

### 一、糖类的概述

#### 1. 糖类的定义

**糖类**是多羟基醛或多羟基酮及其脱水缩合物，通常由碳、氢、氧三种元素组成，其组成通式一般可表示为 $\ce{C_n(H2O)_m}$。

#### 2. 糖类的分类

| 类型 | 定义 | 举例 |
|------|------|------|
| 单糖 | 不能水解的糖 | 葡萄糖、果糖、核糖 |
| 低聚糖（寡糖） | 水解后能生成 2-10 个单糖分子的糖 | 蔗糖、麦芽糖 |
| 多糖 | 水解后能生成多个单糖分子的糖 | 淀粉、纤维素、糖原 |

#### 3. 糖类的命名

| 名称 | 结构特点 | 举例 |
|------|----------|------|
| 醛糖 | 含有醛基的糖 | 葡萄糖、核糖 |
| 酮糖 | 含有酮基的糖 | 果糖 |

### 二、单糖

#### 1. 葡萄糖

**分子式**：$\ce{C6H12O6}$

**结构**：

- 含有醛基的己醛糖
- 分子式：$\ce{HOCH2-(CHOH)4-CHO}$

**物理性质**：
- 白色晶体
- 味甜
- 易溶于水
- 熔点：$146°C$

**化学性质**：

##### (1) 氧化反应

葡萄糖是还原糖，能被弱氧化剂氧化。

**银镜反应**：

$$\ce{CH2OH(CHOH)4CHO + 2[Ag(NH3)2]OH -> CH2OH(CHOH)4COONH4 + 2Ag↓ + 3NH3 + H2O}$$

**与新制 $\ce{Cu(OH)2}$ 反应**：

$$\ce{CH2OH(CHOH)4CHO + 2Cu(OH)2 -> CH2OH(CHOH)4COOH + Cu2O↓ + 2H2O}$$

**被 $\ce{KMnO4}$ 氧化**：

$$\ce{CH2OH(CHOH)4CHO ->[O] COOH(CHOH)4-CH2OH}$$

（葡萄糖酸）

##### (2) 还原反应

葡萄糖加氢还原，生成山梨醇：

$$\ce{CH2OH(CHOH)4CHO + H2 ->[Ni] CH2OH(CHOH)4CH2OH}$$

（山梨醇）

##### (3) 发酵反应

$$\ce{C6H12O6 ->[酒化酶] 2C2H5OH + 2CO2}$$

（酿酒）

##### (4) 与苯酚反应

葡萄糖与苯酚在酸性条件下发生缩合反应，生成酚醛树脂类物质。

**用途**：
- 食品工业：甜味剂
- 医药：补液、能量补充
- 工业：生产山梨醇、葡萄糖酸

#### 2. 果糖

**分子式**：$\ce{C6H12O6}$

**结构**：

- 含有酮基的己酮糖
- 分子式：$\ce{HOCH2-(CHOH)3-CO-CH2OH}$

**物理性质**：
- 白色晶体
- 味极甜（最甜的糖）
- 易溶于水

**化学性质**：

##### (1) 还原性

果糖是还原糖，能发生银镜反应。

!!! note "注意"
    果糖虽然是酮糖，但在碱性条件下可异构化为醛糖，因此也能发生银镜反应。

##### (2) 与 $\ce{Ca(OH)2}$ 反应

$$\ce{C6H12O6 + Ca(OH)2 -> C6H11O5CaOH + H2O}$$

生成的产物可溶于水，但加入 $\ce{NaCl}$ 后会沉淀。

##### (3) 发酵反应

$$\ce{C6H12O6 ->[酒化酶] 2C2H5OH + 2CO2}$$

**用途**：
- 食品工业：甜味剂（比蔗糖甜）
- 医药：能量补充

#### 3. 核糖与脱氧核糖

| 名称 | 分子式 | 结构特点 |
|------|--------|----------|
| 核糖 | $\ce{C5H10O5}$ | 戊醛糖 |
| 脱氧核糖 | $\ce{C5H10O4}$ | 戊醛糖，2-位脱氧 |

核糖和脱氧核糖是核酸的重要组成部分。

### 二、低聚糖

#### 1. 蔗糖

**分子式**：$\ce{C12H22O11}$

**结构**：

- 由一分子葡萄糖和一分子果糖脱水缩合而成
- 分子中无游离醛基

**物理性质**：
- 无色晶体
- 味甜
- 易溶于水
- 熔点：$186°C$

**化学性质**：

##### (1) 非还原性

蔗糖是非还原糖，不能发生银镜反应。

**原因**：蔗糖分子中不含游离醛基，葡萄糖和果糖的醛基已形成苷键。

##### (2) 水解反应

$$\ce{C12H22O11 + H2O ->[稀H2SO4, Δ] C6H12O6 + C6H12O6}$$

$$\ce{蔗糖 + 水 ->[稀H2SO4] 葡萄糖 + 果糖}$$

!!! note "蔗糖水解的检验"
    蔗糖水解后生成葡萄糖和果糖，两者都是还原糖，可发生银镜反应。因此，可用银镜反应检验蔗糖是否水解。

**用途**：
- 食品工业：甜味剂
- 医药：矫味剂
- 工业：生产葡萄糖、果糖

#### 2. 麦芽糖

**分子式**：$\ce{C12H22O11}$

**结构**：

- 由两分子葡萄糖脱水缩合而成
- 分子中有游离醛基

**物理性质**：
- 白色晶体
- 味甜（不如蔗糖甜）
- 易溶于水

**化学性质**：

##### (1) 还原性

麦芽糖是还原糖，能发生银镜反应。

**原因**：麦芽糖分子中含有游离醛基。

##### (2) 水解反应

$$\ce{C12H22O11 + H2O -> 2C6H12O6}$$

$$\ce{麦芽糖 + 水 -> 2葡萄糖}$$

**用途**：
- 食品工业：甜味剂
- 工业：生产葡萄糖

#### 3. 蔗糖与麦芽糖的比较

| 项目 | 蔗糖 | 麦芽糖 |
|------|------|--------|
| 分子式 | $\ce{C12H22O11}$ | $\ce{C12H22O11}$ |
| 组分 | 葡萄糖 + 果糖 | 葡萄糖 + 葡萄糖 |
| 还原性 | 非还原糖 | 还原糖 |
| 银镜反应 | 不能 | 能 |
| 水解产物 | 葡萄糖 + 果糖 | 葡萄糖 |
| 甜度 | 更甜 | 较甜 |

### 三、多糖

#### 1. 淀粉

**分子式**：$\ce{(C6H10O5)_n}$

**结构**：

- 由多个 α-葡萄糖分子脱水缩合而成
- 分为直链淀粉和支链淀粉
- 直链淀粉：线性结构，溶于热水
- 支链淀粉：支链结构，不溶于热水

**物理性质**：
- 白色粉末
- 不溶于冷水
- 支链淀粉在热水中形成糊状（糊化）

**化学性质**：

##### (1) 水解反应

淀粉在酸或酶催化下可水解：

$$\ce{(C6H10O5)_n + nH2O ->[稀H2SO4, Δ] nC6H12O6}$$

$$\ce{淀粉 + 水 -> 葡萄糖}$$

**水解过程**：

$$\ce{淀粉 ->[部分水解] 糊精 ->[继续水解] 麦芽糖 ->[完全水解] 葡萄糖}$$

##### (2) 遇碘变蓝

淀粉遇碘单质变蓝，这是淀粉的特征反应。

$$\ce{淀粉 + I2 -> 蓝色络合物}$$

!!! note "注意"
    直链淀粉遇碘变蓝紫色，支链淀粉遇碘变红紫色。

##### (3) 非还原性

淀粉是非还原糖，不能发生银镜反应。

**用途**：
- 食品工业：制糖、酿酒
- 医药：赋形剂
- 工业：生产乙醇、丙酮

#### 2. 纤维素

**分子式**：$\ce{(C6H10O5)_n}$

**结构**：

- 由多个 β-葡萄糖分子脱水缩合而成
- 线性结构
- 纤维素分子之间形成氢键，因此不溶于水

**物理性质**：
- 白色纤维状
- 不溶于水
- 不溶于一般有机溶剂

**化学性质**：

##### (1) 水解反应

纤维素在酸催化下可水解：

$$\ce{(C6H10O5)_n + nH2O ->[稀H2SO4, Δ] nC6H12O6}$$

$$\ce{纤维素 + 水 -> 葡萄糖}$$

水解比淀粉困难。

##### (2) 酯化反应

纤维素与硝酸反应，生成硝酸纤维素：

$$\ce{[C6H7O2(OH)3]n + 3nHNO3 ->[浓H2SO4] [C6H7O2(OH)2(ONO2)]n + 3nH2O}$$

（硝酸纤维素）

根据硝酸化的程度，可分为：
- 低氮量硝酸纤维素：火棉胶
- 高氮量硝酸纤维素：火药

##### (3) 非还原性

纤维素是非还原糖，不能发生银镜反应。

**用途**：
- 纺织工业：棉纤维
- 造纸工业：纸浆
- 食品工业：膳食纤维
- 工业：生产纤维素衍生物

#### 3. 淀粉和纤维素的比较

| 项目 | 淀粉 | 纤维素 |
|------|------|--------|
| 组成单元 | α-葡萄糖 | β-葡萄糖 |
| 键的类型 | α-1,4-苷键 | β-1,4-苷键 |
| 形态 | 直链和支链 | 线性 |
| 溶解性 | 直链淀粉溶于热水，支链淀粉不溶 | 不溶于水 |
| 水解难易 | 较易 | 较难 |
| 与碘反应 | 变蓝 | 不变蓝 |
| 存在 | 植物种子、根茎 | 植物细胞壁 |

---

!!! tip "学习提示"
    - 糖类的分类主要根据能否水解以及水解产物的数量。
    - 单糖和还原性低聚糖能发生银镜反应，多糖和非还原性低聚糖不能。
    - 淀粉遇碘变蓝是重要的检验方法。
    - 葡萄糖和果糖互为同分异构体。
