# 第三节 核酸

### 一、核酸的概述

#### 1. 核酸的定义

**核酸**是由核苷酸通过磷酸二酯键连接而成的生物大分子，是遗传信息的载体。

#### 2. 核酸的分类

| 类型 | 分布 | 功能 |
|------|------|------|
| 脱氧核糖核酸（DNA） | 主要存在于细胞核中 | 储存遗传信息 |
| 核糖核酸（RNA） | 主要存在于细胞质中 | 参与蛋白质合成 |

### 二、核苷酸

#### 1. 核苷酸的结构

核苷酸由三部分组成：
- **碱基**：含氮杂环化合物
- **戊糖**：核糖或脱氧核糖
- **磷酸**：磷酸分子

**通式**：

$$\ce{磷酸-核糖-碱基}$$

#### 2. 碱基

##### (1) 嘌呤碱

| 名称 | 缩写 | 结构 |
|------|------|------|
| 腺嘌呤 | A | $\ce{C5H5N5}$ |
| 鸟嘌呤 | G | $\ce{C5H5N5O}$ |

##### (2) 嘧啶碱

| 名称 | 缩写 | 结构 |
|------|------|------|
| 胞嘧啶 | C | $\ce{C4H5N3O}$ |
| 胸腺嘧啶 | T | $\ce{C5H6N2O2}$ |
| 尿嘧啶 | U | $\ce{C4H4N2O2}$ |

**DNA 中的碱基**：A、G、C、T

**RNA 中的碱基**：A、G、C、U

#### 3. 核糖与脱氧核糖

| 类型 | 结构 |
|------|------|
| 核糖 | 戊醛糖，$\ce{C5H10O5}$ |
| 脱氧核糖 | 戊醛糖，2-位脱氧，$\ce{C5H10O4}$ |

#### 4. 核苷

核苷是碱基与核糖通过糖苷键连接而成的化合物。

**命名**：腺苷、鸟苷、胞苷、尿苷、胸苷

#### 5. 核苷酸

核苷与磷酸通过酯键连接，生成核苷酸。

**命名**：腺苷酸、鸟苷酸、胞苷酸、尿苷酸、胸苷酸

### 三、DNA 的结构

#### 1. DNA 的组成

DNA 由四种脱氧核苷酸组成：
- 腺嘌呤脱氧核苷酸（dAMP）
- 鸟嘌呤脱氧核苷酸（dGMP）
- 胞嘧啶脱氧核苷酸（dCMP）
- 胸腺嘧啶脱氧核苷酸（dTMP）

#### 2. DNA 的双螺旋结构

**沃森-克里克模型**（1953年）：

- DNA 分子由两条多核苷酸链组成
- 两条链围绕同一轴心盘旋成双螺旋结构
- 碱基位于内侧，通过氢键配对（A-T，G-C）
- 磷酸-脱氧核糖骨架位于外侧

!!! note "碱基配对原则"
    腺嘌呤（A）与胸腺嘧啶（T）配对，形成两个氢键。
    鸟嘌呤（G）与胞嘧啶（C）配对，形成三个氢键。

#### 3. DNA 的特性

| 特性 | 说明 |
|------|------|
| 双螺旋结构 | 两条链互补 |
| 半保留复制 | 复制时每条链作为模板 |
| 储存信息 | 碱基序列储存遗传信息 |
| 稳定性 | 双螺旋结构使 DNA 稳定 |

### 四、RNA 的结构

#### 1. RNA 的组成

RNA 由四种核苷酸组成：
- 腺嘌呤核苷酸（AMP）
- 鸟嘌呤核苷酸（GMP）
- 胞嘧啶核苷酸（CMP）
- 尿嘧啶核苷酸（UMP）

#### 2. RNA 的类型

| 类型 | 功能 |
|------|------|
| 信使 RNA（mRNA） | 传递遗传信息 |
| 转运 RNA（tRNA） | 转运氨基酸 |
| 核糖体 RNA（rRNA） | 构成核糖体的主要成分 |

#### 3. RNA 与 DNA 的比较

| 项目 | DNA | RNA |
|------|-----|-----|
| 核苷酸 | 脱氧核苷酸 | 核苷酸 |
| 戊糖 | 脱氧核糖 | 核糖 |
| 碱基 | A、G、C、T | A、G、C、U |
| 结构 | 双螺旋 | 单链 |
| 功能 | 储存遗传信息 | 表达遗传信息 |
| 位置 | 主要在细胞核 | 主要在细胞质 |

### 五、核酸的生物功能

#### 1. DNA 的功能

- **储存遗传信息**：DNA 分子中的碱基序列编码遗传信息
- **复制**：DNA 通过半保留复制，将遗传信息传递给子代
- **转录**：DNA 将遗传信息转录为 RNA

#### 2. RNA 的功能

- **翻译**：mRNA 将遗传信息翻译为蛋白质
- **转运**：tRNA 转运氨基酸参与蛋白质合成
- **催化**：某些 RNA 具有催化功能（核酶）

### 六、核酸的性质

#### 1. 物理性质

- 核酸为白色纤维状固体
- 溶于水，不溶于有机溶剂
- DNA 的熔点高于 RNA

#### 2. 化学性质

##### (1) 水解反应

核酸在酸、碱或酶催化下可水解，生成核苷酸。

$$\ce{DNA + H2O -> 脱氧核苷酸}$$

$$\ce{RNA + H2O -> 核苷酸}$$

##### (2) 变性

核酸在高温、酸、碱等作用下，双螺旋结构被破坏，发生变性。

**特点**：
- 紫外吸收增加
- 生物活性丧失
- 可复性（可逆变性）

##### (3) 显色反应

核酸与二苯胺试剂反应，生成蓝色化合物，可用于 DNA 的定性检验。

$$\ce{DNA + 二苯胺 -> 蓝色}$$

RNA 与苔黑酚试剂反应，生成绿色化合物，可用于 RNA 的定性检验。

---

!!! tip "学习提示"
    - 核酸是生物大分子，由核苷酸组成。
    - DNA 是遗传信息的载体，RNA 参与蛋白质合成。
    - 碱基配对原则（A-T，G-C）是 DNA 复制和转录的基础。
    - 核酸的变性是可逆的，高温下变性，降温后可复性。
