# 第二节 蛋白质

### 一、氨基酸

#### 1. 氨基酸的定义

**氨基酸**是指分子中同时含有氨基（$-\ce{NH2}$）和羧基（$-\ce{COOH}$）的化合物。

#### 2. 氨基酸的结构

氨基酸的中心碳原子（α-碳）上连接四个基团：
- 氨基（$-\ce{NH2}$）
- 羧基（$-\ce{COOH}$）
- 氢原子（$-\ce{H}$）
- 侧链基团（$-\ce{R}$）

**通式**：

$$\ce{H2N-CH(R)-COOH}$$

#### 3. 氨基酸的分类

##### (1) 按氨基和羧基数目分类

| 类型 | 定义 | 举例 |
|------|------|------|
| 中性氨基酸 | 氨基和羧基数目相等 | 甘氨酸、丙氨酸 |
| 酸性氨基酸 | 羧基数目多于氨基 | 天冬氨酸、谷氨酸 |
| 碱性氨基酸 | 氨基数目多于羧基 | 赖氨酸、精氨酸 |

##### (2) 按 α-碳原子上的 R 基团分类

| 类型 | R 基团特点 | 举例 |
|------|------------|------|
| 脂肪族氨基酸 | R 为脂肪烃基 | 甘氨酸、丙氨酸 |
| 芳香族氨基酸 | R 为芳香烃基 | 苯丙氨酸、酪氨酸 |
| 含硫氨基酸 | R 含硫 | 半胱氨酸、甲硫氨酸 |
| 杂环氨基酸 | R 为杂环 | 色氨酸、组氨酸 |

#### 4. 常见氨基酸

| 名称 | 缩写 | 结构简式 |
|------|------|----------|
| 甘氨酸 | Gly | $\ce{H2N-CH2-COOH}$ |
| 丙氨酸 | Ala | $\ce{(CH3)CH(NH2)COOH}$ |
| 丝氨酸 | Ser | $\ce{HOCH2CH(NH2)COOH}$ |
| 半胱氨酸 | Cys | $\ce{HSCH2CH(NH2)COOH}$ |
| 赖氨酸 | Lys | $\ce{H2N(CH2)4CH(NH2)COOH}$ |

#### 5. 氨基酸的性质

##### (1) 两性性质

氨基酸分子中既含有酸性基团（$-\ce{COOH}$），又含有碱性基团（$-\ce{NH2}$），因此既能与酸反应，又能与碱反应。

$$\ce{H2N-CH2-COOH + HCl -> ClH3N-CH2-COOH}$$

$$\ce{H2N-CH2-COOH + NaOH -> H2N-CH2-COONa + H2O}$$

##### (2) 等电点

在特定 pH 值下，氨基酸主要以两性离子形式存在，净电荷为零，这个 pH 值称为等电点（pI）。

- 酸性氨基酸的等电点 < 7
- 碱性氨基酸的等电点 > 7
- 中性氨基酸的等电点 ≈ 6

##### (3) 显色反应

氨基酸与茚三酮反应，生成蓝紫色化合物，可用于氨基酸的定性检验。

$$\ce{氨基酸 + 茚三酮 -> 蓝紫色产物}$$

### 二、蛋白质的结构

#### 1. 蛋白质的组成

蛋白质是由 α-氨基酸通过肽键连接而成的高分子化合物。

#### 2. 肽键

一个氨基酸的氨基与另一个氨基酸的羧基脱水缩合形成的酰胺键，称为肽键（$-\ce{CO-NH-}$）。

**二肽**：由两个氨基酸通过一个肽键连接而成。

**多肽**：由多个氨基酸通过多个肽键连接而成。

#### 3. 蛋白质的结构层次

| 结构 | 定义 | 作用力 |
|------|------|--------|
| 一级结构 | 氨基酸的排列顺序 | 肽键 |
| 二级结构 | 多肽链的折叠方式 | 氢键 |
| 三级结构 | 多肽链的立体排布 | 氢键、离子键、疏水作用、二硫键 |
| 四级结构 | 亚基的缔合方式 | 氢键、离子键 |

!!! note "蛋白质结构的重要性"
    蛋白质的功能取决于其空间结构。高温、重金属盐、紫外线等可使蛋白质变性，破坏其空间结构，从而失去生理活性。

### 三、蛋白质的性质

#### 1. 两性性质

蛋白质分子中含有游离的氨基和羧基，因此既能与酸反应，又能与碱反应。

#### 2. 水解反应

蛋白质在酸、碱或酶催化下可水解，生成 α-氨基酸：

$$\ce{蛋白质 + H2O ->[酸或碱] α-氨基酸}$$

#### 3. 盐析

向蛋白质溶液中加入饱和氯化钠、硫酸钠等盐溶液，蛋白质会从溶液中析出，这种现象称为盐析。

**特点**：
- 盐析是可逆过程
- 盐析不改变蛋白质的性质
- 盐析可用于蛋白质的分离和提纯

#### 4. 变性

蛋白质在热、酸、碱、重金属盐、紫外线等作用下，其空间结构被破坏，从而失去生理活性的过程称为变性。

**变性因素**：
- 物理因素：加热、紫外线、X射线
- 化学因素：酸、碱、重金属盐、酒精

**变性特点**：
- 不可逆
- 蛋白质失去生理活性
- 蛋白质的性质发生改变（如溶解度降低）

!!! warning "重金属中毒的急救"
    误服重金属盐后，可服用大量生鸡蛋清或牛奶进行急救，其原理是蛋白质与重金属离子结合，阻止其被吸收。

#### 5. 颜色反应

##### (1) 茚三酮反应

蛋白质与茚三酮反应，生成蓝紫色化合物。

##### (2) 双缩脲反应

蛋白质与双缩脲试剂（硫酸铜的碱性溶液）反应，生成紫色络合物。

!!! note "注意"
    双缩脲反应是检验蛋白质和多肽的重要方法，但氨基酸不能发生双缩脲反应。

#### 6. 显色反应

| 试剂 | 现象 | 说明 |
|------|------|------|
| 茚三酮 | 蓝紫色 | 检验氨基酸和蛋白质 |
| 双缩脲试剂 | 紫色 | 检验蛋白质和多肽 |
| 浓硝酸 | 黄色 | 含苯环的蛋白质（如白蛋白） |

### 四、酶

#### 1. 酶的定义

**酶**是活细胞产生的具有催化作用的有机物，绝大多数酶是蛋白质。

#### 2. 酶的特性

| 特性 | 说明 |
|------|------|
| 高效性 | 酶的催化效率比无机催化剂高 $10^6$-$10^{13}$ 倍 |
| 专一性 | 一种酶只能催化一种或一类反应 |
| 温和性 | 酶在温和的条件下（常温、常压）即可催化反应 |
| 易变性 | 酶对温度、pH 等条件敏感，易变性失活 |

#### 3. 酶的催化机理

酶的作用机理是通过降低反应的活化能来加快反应速率。

**过程**：
1. 酶的活性中心与底物结合
2. 形成酶-底物复合物
3. 底物转化为产物
4. 产物释放，酶恢复原状

### 五、蛋白质的用途

| 领域 | 用途 |
|------|------|
| 食品 | 蛋白质是重要的营养物质 |
| 医药 | 白蛋白、干扰素等 |
| 工业 | 皮革、丝绸、胶水 |
| 农业 | 蛋白质饲料 |

---

!!! tip "学习提示"
    - 氨基酸是蛋白质的基本组成单位。
    - 蛋白质的性质与氨基酸的性质密切相关。
    - 蛋白质变性是重要的概念，日常生活中应注意防止蛋白质变性。
    - 酶是一类重要的蛋白质，具有高效性和专一性。
