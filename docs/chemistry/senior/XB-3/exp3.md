# 实验活动 3 糖类的性质

## 实验目的

1. 掌握糖类的主要化学性质
2. 学会鉴别还原糖与非还原糖
3. 了解淀粉与碘的反应特性
4. 探究糖类的水解反应

## 实验原理

### 1. 还原糖的检验

单糖（葡萄糖、果糖）和部分低聚糖（麦芽糖）含有游离醛基，能还原银氨溶液和新制 $\ce{Cu(OH)2}$，是还原糖。

非还原糖（蔗糖、淀粉、纤维素）不含游离醛基，不能发生银镜反应。

### 2. 淀粉与碘的反应

淀粉遇碘单质变蓝，是检验淀粉的灵敏反应。

直链淀粉遇碘变蓝紫色，支链淀粉遇碘变红紫色。

### 3. 糖类的水解

二糖和多糖在酸催化下可水解，生成单糖：

$$\ce{C12H22O11 + H2O ->[稀H2SO4, Δ] 2C6H12O6}$$

$$\ce{(C6H10O5)_n + nH2O ->[稀H2SO4, Δ] nC6H12O6}$$

水解产物（单糖）具有还原性。

## 实验步骤

### 1. 还原糖的检验

#### (1) 银镜反应

1. 取四支洁净的试管，编号。

2. 分别加入 2mL 葡萄糖溶液、果糖溶液、蔗糖溶液、麦芽糖溶液。

3. 各加入 1mL 银氨溶液，摇匀。

4. 水浴加热，观察并记录现象。

#### (2) 斐林反应

1. 取四支试管，编号。

2. 各加入 2mL 新制 $\ce{Cu(OH)2}$。

3. 分别加入 1mL 葡萄糖溶液、果糖溶液、蔗糖溶液、麦芽糖溶液。

4. 加热煮沸 2-3 分钟，观察并记录现象。

### 2. 淀粉与碘的反应

1. 取两支试管，各加入 2mL 淀粉溶液。

2. 向第一支试管滴加碘酒 2-3 滴，观察现象。

3. 向第二支试管滴加碘酒 2-3 滴，然后加热煮沸，观察现象。冷却后再观察。

### 3. 蔗糖的水解

1. 取两支试管，编号。

2. 第一支试管加入 3mL 蔗糖溶液，第二支试管加入 3mL 蔗糖溶液和 1mL 稀硫酸。

3. 将两支试管都放入沸水中加热 5 分钟。

4. 取出冷却，向两支试管各加入 $\ce{NaOH}$ 溶液中和硫酸至中性（或弱碱性）。

5. 向两支试管各加入 2mL 新制 $\ce{Cu(OH)2}$，加热煮沸，观察现象。

### 4. 淀粉的水解

1. 取三支试管，编号。

2. 各加入 3mL 淀粉溶液。

3. 第一支试管直接检验，第二支试管加入 1mL 稀硫酸后水浴加热，第三支试管加入 1mL 稀硫酸后水浴加热 15 分钟。

4. 向三支试管各加入 $\ce{NaOH}$ 溶液中和酸。

5. 向三支试管各加入 2mL 斐林试剂，加热，观察并记录现象。

## 注意事项

!!! warning "实验安全"
    1. 银氨溶液必须现配现用，久置会生成爆炸性的雷酸银。
    
    2. 加热时要使用试管夹，试管口不要对着人。
    
    3. 浓硫酸具有强腐蚀性，操作要小心。
    
    4. 实验后要用稀硝酸清洗试管，防止银镜附着。

| 糖类 | 银镜反应 | 斐林反应 |
|------|----------|----------|
| 葡萄糖 | - | - |
| 果糖 | - | - |
| 蔗糖 | - | - |
| 麦芽糖 | - | - |

### 2. 淀粉与碘的反应

| 操作 | 现象 | 结论 |
|------|------|------|
| 淀粉 + 碘酒 | - | - |
| 淀粉 + 碘酒 → 加热 | - | - |
| 加热后冷却 | - | - |

### 3. 蔗糖的水解

| 条件 | 斐林反应 | 结论 |
|------|----------|------|
| 蔗糖（未水解） | - | - |
| 蔗糖（水解后） | - | - |

### 4. 淀粉的水解

| 水解时间 | 斐林反应 | 结论 |
|----------|----------|------|
| 0 分钟 | - | - |
| 5 分钟 | - | - |
| 15 分钟 | - | - |
