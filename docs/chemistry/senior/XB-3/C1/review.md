### 重点知识梳理

#### 1. 有机化合物的分类

| 分类依据 | 类别 | 特点 |
|----------|------|------|
| 按碳骨架 | 链状化合物 | 碳原子连接成链状 |
| 按碳骨架 | 环状化合物 | 碳原子连接成环状 |
| 按官能团 | 烃 | 仅含碳、氢元素 |
| 按官能团 | 烃的衍生物 | 含有其他元素 |

#### 2. 烷烃的通式与性质

| 项目 | 内容 |
|------|------|
| 通式 | $\ce{C_nH_{2n+2}}$ |
| 碳原子间的键 | 全部为单键 |
| 化学性质 | 稳定，通常不与强酸、强碱、强氧化剂反应 |
| 主要反应 | 取代反应、氧化反应、裂化反应 |

#### 3. 同系物与同分异构体的比较

|  | 同系物 | 同分异构体 |
|  |--------|------------|
| 相同点 | 结构相似 | 分子式相同 |
| 不同点 | 分子式不同，差 $\ce{CH2}$ | 结构不同 |
| 举例 | 甲烷、乙烷、丙烷 | 正戊烷、异戊烷、新戊烷 |

#### 4. 有机化合物的研究方法

| 方法 | 原理 | 应用 |
|------|------|------|
| 蒸馏 | 沸点差异 | 分离液体混合物 |
| 重结晶 | 溶解度差异 | 提纯固体 |
| 质谱 | 质荷比 | 测定分子量 |
| 红外光谱 | 官能团吸收 | 检测官能团 |
| 核磁共振 | 氢核共振 | 确定氢原子类型和数目 |

## 典型例题

???+ success "例题1"
    
    下列有机化合物中，属于烷烃的是（　）
    
    A. $\ce{C2H4}$　B. $\ce{C2H6}$　C. $\ce{C2H2}$　D. $\ce{C6H6}$
    
    **答案**：B
    
    **解析**：烷烃的通式为 $\ce{C_nH_{2n+2}}$，饱和烃只含单键。$\ce{C2H4}$ 为烯烃，$\ce{C2H2}$ 为炔烃，$\ce{C6H6}$ 为芳香烃。

???+ success "例题2"
    
    某有机物含碳 85.7%，氢 14.3%，相对分子质量为 56。求该有机物的分子式。
    
    **答案**：$\ce{C4H8}$
    
    **解析**：
    
    原子个数比：$\ce{C : H} = 85.7/12 : 14.3/1 = 7.14 : 14.3 = 1 : 2$
    
    实验式：$\ce{CH2}$
    
    实验式量：14
    
    $n = 56 / 14 = 4$
    
    分子式：$\ce{C4H8}$

???+ success "例题3"
    
    下列化合物中，与甲烷互为同系物的是（　）
    
    A. $\ce{C2H4}$　B. $\ce{C2H6}$　C. $\ce{C3H8}$　D. $\ce{C3H6}$
    
    **答案**：C
    
    **解析**：同系物指结构相似、分子组成相差一个或若干个 $\ce{CH2}$ 的有机化合物。甲烷为烷烃，所以应选择烷烃。$\ce{C3H8}$（丙烷）与甲烷均为烷烃，结构相似，分子组成相差 2 个 $\ce{CH2}$。

## 能力提升

### 易错点分析

!!! warning "常见错误"
    
    1. **混淆同系物与同分异构体**：同系物分子式不同，同分异构体分子式相同。
    
    2. **烷烃命名错误**：选主链应选最长碳链，编号应从靠近支链一端开始。
    
    3. **取代反应理解不清**：甲烷与氯气的取代反应是逐步进行的，产物为混合物。

### 知识拓展

#### 1. 等效氢原子的判断

在核磁共振氢谱中，等效氢原子指化学环境相同的氢原子。

**等效氢的判断方法**：

- 同一碳原子上的氢原子等效
- 处于对称位置的氢原子等效
- 同一碳原子上的甲基 $\ce{-CH3}$ 中的三个氢原子等效

#### 2. 核磁共振氢谱的简单应用

峰的数目 = 氢原子的种类数

峰的面积比 = 不同类型氢原子的数目比
