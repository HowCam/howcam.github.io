# 第一章 有机化合物的结构特点与研究方法

## 第一节 有机化合物的结构特点

### 一、有机化合物的分类

有机化合物是指含碳元素的化合物（一氧化碳、二氧化碳、碳酸盐、金属碳化物等除外）。

#### 1. 按碳骨架分类

| 类型 | 特点 | 举例 |
|------|------|------|
| 链状化合物（脂肪族化合物） | 碳原子连接成链状 | 甲烷 $\ce{CH4}$、乙醇 $\ce{C2H5OH}$ |
| 环状化合物 | 碳原子连接成环状 | 苯 $\ce{C6H6}$、环己烷 |

#### 2. 按官能团分类

| 官能团 | 结构 | 化合物类别 | 举例 |
|--------|------|------------|------|
| 碳碳双键 | $>C=C<$ | 烯烃 | 乙烯 $\ce{C2H4}$ |
| 碳碳三键 | $-C≡C-$ | 炔烃 | 乙炔 $\ce{C2H2}$ |
| 羟基 | $-OH$ | 醇/酚 | 乙醇 $\ce{C2H5OH}$、苯酚 $\ce{C6H5OH}$ |
| 醛基 | $-CHO$ | 醛 | 乙醛 $\ce{CH3CHO}$ |
| 羰基 | $>C=O$ | 酮 | 丙酮 $\ce{CH3COCH3}$ |
| 羧基 | $-COOH$ | 羧酸 | 乙酸 $\ce{CH3COOH}$ |
| 酯基 | $-COOR$ | 酯 | 乙酸乙酯 $\ce{CH3COOC2H5}$ |
| 氨基 | $-NH2$ | 胺 | 甲胺 $\ce{CH3NH2}$ |

### 二、有机化合物中碳原子的成键特点

#### 1. 碳原子的成键数

碳原子有 **4** 个价电子，可以形成 **4** 个共价键。

#### 2. 碳原子的成键方式

- **碳碳单键**（$\ce{C-C}$）：$\sigma$ 键
- **碳碳双键**（$\ce{C=C}$）：1个 $\sigma$ 键 + 1个 $\pi$ 键
- **碳碳三键**（$\ce{C≡C}$）：1个 $\sigma$ 键 + 2个 $\pi$ 键

#### 3. 碳原子的成键类型

- 与其他碳原子成键
- 与氢、氧、氮、卤素等原子成键

### 三、甲烷的结构

#### 1. 甲烷的分子结构

甲烷 $\ce{CH4}$ 是最简单的有机化合物。

- **正四面体结构**：碳原子位于正四面体中心，四个氢原子位于正四面体的顶点。
- **碳氢键**：四个 $\ce{C-H}$ 键的键长、键能、键角均相等。

!!! note "键角"
    $\ce{C-H}$ 键之间的夹角为 $109.5°$。

#### 2. 甲烷的化学性质

##### (1) 氧化反应

$$\ce{CH4 + 2O2 -> CO2 + 2H2O}$$

燃烧时火焰呈淡蓝色。

##### (2) 取代反应

$$\ce{CH4 + Cl2 ->[光照] CH3Cl + HCl}$$

甲烷与氯气在光照条件下发生逐步取代反应：

$\ce{CH4 + Cl2 ->[光照] CH3Cl + HCl}$

$\ce{CH3Cl + Cl2 ->[光照] CH2Cl2 + HCl}$

$\ce{CH2Cl2 + Cl2 ->[光照] CHCl3 + HCl}$

$\ce{CHCl3 + Cl2 ->[光照] CCl4 + HCl}$

### 四、烷烃

#### 1. 烷烃的定义

**烷烃**是指饱和烃，即碳原子之间只以单键相连的链烃。

#### 2. 烷烃的结构特点

- 碳原子之间只以 **单键** 连接
- 每个碳原子的价键全部被氢原子饱和
- 通式：$\ce{C_nH_{2n+2}}$（$n \geq 1$）

#### 3. 烷烃的命名

| 碳原子数 | 名称 | 分子式 |
|----------|------|--------|
| 1 | 甲烷 | $\ce{CH4}$ |
| 2 | 乙烷 | $\ce{C2H6}$ |
| 3 | 丙烷 | $\ce{C3H8}$ |
| 4 | 丁烷 | $\ce{C4H10}$ |
| 5 | 戊烷 | $\ce{C5H12}$ |
| 6 | 己烷 | $\ce{C6H14}$ |
| 7 | 庚烷 | $\ce{C7H16}$ |
| 8 | 辛烷 | $\ce{C8H18}$ |
| 9 | 壬烷 | $\ce{C9H20}$ |
| 10 | 癸烷 | $\ce{C10H22}$ |

#### 4. 同分异构现象

!!! note "同分异构体"
    分子式相同，但结构不同的化合物互称为同分异构体。

戊烷的同分异构体：

| 名称 | 结构简式 | 碳骨架 |
|------|----------|--------|
| 正戊烷 | $\ce{CH3CH2CH2CH2CH3}$ | 直链 |
| 异戊烷 | $\ce{(CH3)2CHCH2CH3}$ | 带支链 |
| 新戊烷 | $\ce{C(CH3)4}$ | 支链最多 |

#### 5. 烷烃的化学性质

烷烃的化学性质与甲烷相似，通常较稳定，不与强酸、强碱、强氧化剂反应。

##### (1) 氧化反应

$$\ce{C_nH_{2n+2} + \frac{3n+1}{2}O2 -> nCO2 + (n+1)H2O}$$

##### (2) 取代反应

烷烃与卤素发生取代反应，生成卤代烃。

##### (3) 裂化反应

在高温下，烷烃可发生裂化反应，生成较小的分子。

### 五、烷烃的命名

#### 1. 系统命名法规则

1. **选主链**：选择最长碳链作为主链（母链）。
2. **编号**：从靠近支链的一端开始给主链碳原子编号。
3. **写名称**：支链位置-支链名称-主链名称。

#### 2. 常见取代基

| 取代基 | 名称 |
|--------|------|
| $-\ce{CH3}$ | 甲基 |
| $-\ce{C2H5}$ | 乙基 |
| $-\ce{C3H7}$ | 丙基 |
| $-\ce{(CH3)2CH-}$ | 异丙基 |

#### 3. 碳原子数在十以上的命名

| 数字 | 名称 |
|------|------|
| 十一 | 十一 |
| 十二 | 十二 |
| 十三 | 十三 |
| ... | ... |
| 二十 | 二十 |

### 六、同系物

!!! note "同系物"
    结构相似，分子组成相差一个或若干个 $\ce{CH2}$ 的有机化合物互称为同系物。

例如：甲烷、乙烷、丙烷都是烷烃的同系物。

---

!!! tip "学习提示"
    - 有机化合物的结构决定性质，学习时要注意从结构角度理解性质。
    - 烷烃的通式 $\ce{C_nH_{2n+2}}$ 适用于所有烷烃。
    - 取代反应是有机化学中的重要反应类型。
