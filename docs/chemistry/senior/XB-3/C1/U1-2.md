# 第一节 研究有机化合物的一般方法

### 一、有机化合物的分离与提纯

#### 1. 蒸馏

适用于分离提纯沸点相差较大的液体混合物。

**实验装置**：

蒸馏装置由蒸馏烧瓶、冷凝管、接收器等组成。

**操作要点**：

- 温度计水银球位于蒸馏烧瓶支管口处
- 冷凝管中冷水下进上出
- 加入沸石防止暴沸
- 先加热再开冷凝水

#### 2. 重结晶

适用于分离提纯固体有机化合物。

**操作步骤**：

1. 加热溶解
2. 趁热过滤
3. 冷却结晶
4. 过滤洗涤

#### 3. 萃取

适用于分离提纯有机化合物。

**类型**：

- **液-液萃取**：利用溶质在两种互不相溶的溶剂中的溶解度不同进行分离
- **固-液萃取**：用溶剂从固体混合物中提取所需物质

#### 4. 色谱法

利用吸附剂对不同有机化合物的吸附能力不同进行分离。

### 二、有机化合物分子式的测定

#### 1. 元素分析

##### (1) 定性分析

检测有机化合物中是否含有碳、氢、氧、氮、卤素等元素。

##### (2) 定量分析

通过燃烧法测定有机化合物中各元素的质量百分比。

**燃烧反应**：

$$\ce{C_xH_yO_z + (x + y/4 - z/2)O2 -> xCO2 + (y/2)H2O}$$

#### 2. 相对分子质量的测定

##### (1) 质谱法（MS）

通过质谱仪测定分子的质荷比（$\ce{m/z}$），确定相对分子质量。

**原理**：分子在电子轰击下形成分子离子和碎片离子，根据质荷比和相对强度进行检测。

##### (2) 蒸气密度法

根据阿伏加德罗定律测定气态物质的相对分子质量。

$$\ce{M = m \cdot RT / (PV)}$$

#### 3. 分子式的确定

已知实验式和各元素的质量分数，可推算出分子式。

**例**：某有机化合物含碳 40%、氢 6.7%、氧 53.3%，相对分子质量为 60，求分子式。

**解**：

| 元素 | 质量分数 | 原子个数比 |
|------|----------|------------|
| C | 40% | $40/12 : 6.7/1 : 53.3/16 = 3.33 : 6.7 : 3.33 = 1 : 2 : 1$ |
| H | 6.7% | - |
| O | 53.3% | - |

实验式：$\ce{CH2O}$

实验式量：$12 + 2 + 16 = 30$

相对分子质量为 60，则 $n = 60 / 30 = 2$

分子式：$\ce{C2H4O2}$（乙酸）

### 三、有机化合物结构式的测定

#### 1. 红外光谱（IR）

用于检测有机化合物中存在的官能团。

**原理**：不同官能团吸收不同波长的红外光，产生特征吸收峰。

| 官能团 | 吸收峰范围（$\ce{cm^{-1}}$） |
|--------|----------------------------|
| $\ce{-OH}$ | 3200-3600 |
| $\ce{-NH2}$ | 3300-3500 |
| $\ce{-C≡C-H}$ | 2100-2260 |
| $\ce{-C=O}$ | 1650-1750 |
| $\ce{-C=C-}$ | 1600-1680 |
| $\ce{-C-H}$（饱和） | 2850-2950 |

#### 2. 核磁共振氢谱（$\ce{^1H NMR}$）

用于检测有机化合物中氢原子的类型和数目。

**原理**：氢核在外磁场中吸收射频辐射，产生共振信号。

**谱图信息**：

- **峰的位置（δ值）**：化学位移，反映氢核所处的化学环境
- **峰的面积**：氢原子的数目比
- **峰的分裂**：相邻氢核的耦合分裂

| 化学环境 | δ值（ppm） |
|----------|------------|
| $-\ce{CH3}$ | 0.9 |
| $-\ce{CH2}-$ | 1.3 |
| $-\ce{CH<}$ | 1.5 |
| $-\ce{CH=O}$ | 9-10 |
| $-\ce{OH}$ | 1-5（可变） |
| $-\ce{C6H5-H}$ | 6.5-8.5 |

#### 3. 质谱（MS）

用于测定分子量和分子结构信息。

**质荷比**（$\ce{m/z}$）等于相对分子质量时，对应的峰为分子离子峰。

**碎片离子峰**可提供分子断裂信息。

### 四、有机物分子结构的确定步骤

1. **元素分析**：确定元素组成
2. **测定相对分子质量**：确定分子量
3. **确定实验式**：计算原子个数比
4. **确定分子式**：利用分子量确定
5. **确定结构式**：利用波谱数据确定

---

!!! tip "学习提示"
    - 有机化合物的分离提纯方法各有适用范围，要根据物质性质选择合适的方法。
    - 红外光谱、核磁共振氢谱、质谱是现代有机化学中重要的分析手段。
    - 综合利用多种波谱数据可以确定有机化合物的结构。
