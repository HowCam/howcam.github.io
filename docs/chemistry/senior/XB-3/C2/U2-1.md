# 第二章 烃

## 第一节 烷烃

### 一、烷烃的回顾

#### 1. 烷烃的结构特点

- 碳原子之间只以 **单键** 连接
- 每个碳原子的价键全部被氢原子饱和
- 通式：$\ce{C_nH_{2n+2}}$（$n \geq 1$）

#### 2. 烷烃的命名

**系统命名法规则**：

1. **选主链**：选择最长碳链作为主链（母链）。
2. **编号**：从靠近支链的一端开始给主链碳原子编号。
3. **写名称**：支链位置-支链名称-主链名称。

### 二、烷烃的物理性质

#### 1. 状态

| 碳原子数 | 状态 | 原因 |
|----------|------|------|
| 1-4 | 气态 | 分子量小，范德华力小 |
| 5-16 | 液态 | 分子量适中 |
| 17以上 | 固态 | 分子量大，范德华力大 |

#### 2. 沸点

- 随碳原子数增加，沸点逐渐升高
- 碳原子数相同的烷烃，支链越多，沸点越低
- 规律：直链 > 支链

#### 3. 密度

- 随碳原子数增加，密度逐渐增大
- 烷烃的密度均小于水

#### 4. 溶解性

- 烷烃不溶于水
- 烷烃溶于有机溶剂

### 三、烷烃的化学性质

#### 1. 氧化反应

##### (1) 燃烧反应

$$\ce{C_nH_{2n+2} + \frac{3n+1}{2}O2 -> nCO2 + (n+1)H2O}$$

!!! note "完全燃烧的条件"
    - 氧气充足：生成 $\ce{CO2}$ 和 $\ce{H2O}$
    - 氧气不充足：生成 $\ce{CO}$ 和 $\ce{H2O}$（黑烟）

##### (2) 甲烷的燃烧

$$\ce{CH4 + 2O2 -> CO2 + 2H2O}$$

燃烧时火焰呈淡蓝色，放出大量热。

#### 2. 取代反应

##### (1) 甲烷的取代反应

$$\ce{CH4 + Cl2 ->[光照] CH3Cl + HCl}$$

逐步取代：

$$\ce{CH4 + Cl2 ->[光照] CH3Cl + HCl}$$
$$\ce{CH3Cl + Cl2 ->[光照] CH2Cl2 + HCl}$$
$$\ce{CH2Cl2 + Cl2 ->[光照] CHCl3 + HCl}$$
$$\ce{CHCl3 + Cl2 ->[光照] CCl4 + HCl}$$

产物：$\ce{CH3Cl}$（一氯甲烷）、$\ce{CH2Cl2}$（二氯甲烷）、$\ce{CHCl3}$（三氯甲烷，又称氯仿）、$\ce{CCl4}$（四氯化碳）

##### (2) 其他烷烃的取代反应

烷烃与 $\ce{Cl2}$、$\ce{Br2}$ 等卤素单质发生取代反应。

#### 3. 裂化反应

在高温下，烷烃可发生裂化反应，生成较小的分子。

**热裂化**：在高温下进行

**催化裂化**：在催化剂作用下进行

**产物**：较小的烷烃、烯烃、氢气等

### 四、烷烃的应用

| 物质 | 应用 |
|------|------|
| 甲烷 | 天然气主要成分，清洁能源 |
| 乙烷 | 乙烯的工业原料 |
| 丙烷 | 燃料，焊接 |
| 丁烷 | 打火机燃料 |
| 己烷 | 有机溶剂 |
| 石蜡 | 蜡烛，蜡纸 |

---

!!! tip "学习提示"
    - 烷烃的物理性质随碳原子数增加呈规律性变化。
    - 取代反应是有机化学中的重要反应类型。
    - 完全燃烧的产物为 $\ce{CO2}$ 和 $\ce{H2O}$。
