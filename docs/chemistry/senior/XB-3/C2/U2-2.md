# 第二节 烯烃 炔烃

### 一、烯烃

#### 1. 烯烃的结构特点

**烯烃**是指含有碳碳双键（$\ce{C=C}$）的不饱和烃。

- 含有一个碳碳双键的烯烃，通式：$\ce{C_nH_{2n}}$（$n \geq 2$）
- 碳碳双键由一个 $\sigma$ 键和一个 $\pi$ 键组成
- $\pi$ 键键能较小，易断裂，因此烯烃化学性质活泼

#### 2. 常见的烯烃

| 名称 | 结构简式 | 状态 |
|------|----------|------|
| 乙烯 | $\ce{C2H4}$ | 气体 |
| 丙烯 | $\ce{C3H6}$ | 气体 |
| 丁烯 | $\ce{C4H8}$ | 气体 |
| 戊烯 | $\ce{C5H10}$ | 液体 |

#### 3. 乙烯的结构

**乙烯** $\ce{C2H4}$ 是最简单的烯烃。

**分子结构**：

- 两个碳原子均为 $\ce{sp^2}$ 杂化
- 六个原子在同一平面上
- $\ce{C=C}$ 键键长：134 pm（介于单键和叁键之间）
- $\ce{C=C}$ 键键能：615 kJ/mol
- 键角：约 $120°$

**结构式**：

$$\ce{CH2=CH2}$$

!!! note "碳碳双键的特点"
    - $\sigma$ 键：电子云轴向重叠，可旋转
    - $\pi$ 键：电子云侧面重叠，不可旋转
    - 因此含碳碳双键的化合物存在顺反异构

#### 4. 乙烯的化学性质

##### (1) 氧化反应

**燃烧反应**：

$$\ce{C2H4 + 3O2 -> 2CO2 + 2H2O}$$

火焰明亮，带黑烟。

**被高锰酸钾氧化**：

$$\ce{CH2=CH2 ->[KMnO4/H+] CO2 + H2O}$$

!!! warning "注意"
    烯烃能使高锰酸钾溶液褪色，可用于鉴别烯烃与烷烃。

##### (2) 加成反应

**与溴加成**：

$$\ce{CH2=CH2 + Br2 -> CH2Br-CH2Br}$$

（1,2-二溴乙烷，无色）

**与 $\ce{H2}$ 加成**：

$$\ce{CH2=CH2 + H2 ->[催化剂] CH3-CH3}$$

（乙烷）

**与 $\ce{HCl}$ 加成**：

$$\ce{CH2=CH2 + HCl ->[催化剂] CH3CH2Cl}$$

（氯乙烷）

**与 $\ce{H2O}$ 加成**：

$$\ce{CH2=CH2 + H2O ->[催化剂] CH3CH2OH}$$

（乙醇）

##### (3) 加聚反应

$$\ce{nCH2=CH2 ->[催化剂] -[CH2-CH2]-_n}$$

聚乙烯（PE）

#### 5. 烯烃的加成规律

- **马尔科夫尼科夫规则**（Markovnikov's Rule）：
  不对称烯烃与 $\ce{HX}$、$\ce{H2O}$ 等加成时，$\ce{H}$ 加在含 $\ce{H}$ 多的碳原子上，$\ce{X}$ 或 $\ce{OH}$ 加在含 $\ce{H}$ 少的碳原子上。

- **反马尔科夫尼科夫规则**（过氧化物效应）：
  在过氧化物存在下，与 $\ce{HBr}$ 加成时，$\ce{Br}$ 加在含 $\ce{H}$ 多的碳原子上。

### 二、炔烃

#### 1. 炔烃的结构特点

**炔烃**是指含有碳碳三键（$\ce{C≡C}$）的不饱和烃。

- 含有一个碳碳三键的炔烃，通式：$\ce{C_nH_{2n-2}}$（$n \geq 2$）
- 碳碳三键由一个 $\sigma$ 键和两个 $\pi$ 键组成
- $\pi$ 键键能较小，易断裂，因此炔烃化学性质活泼

#### 2. 常见的炔烃

| 名称 | 结构简式 | 状态 |
|------|----------|------|
| 乙炔 | $\ce{C2H2}$ | 气体 |
| 丙炔 | $\ce{C3H4}$ | 气体 |
| 丁炔 | $\ce{C4H6}$ | 气体 |
| 戊炔 | $\ce{C5H8}$ | 液体 |

#### 3. 乙炔的结构

**乙炔** $\ce{C2H2}$ 是最简单的炔烃。

**分子结构**：

- 两个碳原子均为 $\ce{sp}$ 杂化
- 四个原子在同一直线上
- $\ce{C≡C}$ 键键长：120 pm（最短）
- $\ce{C≡C}$ 键键能：839 kJ/mol
- 键角：$180°$

**结构式**：

$$\ce{HC≡CH}$$

#### 4. 乙炔的化学性质

##### (1) 氧化反应

**燃烧反应**：

$$\ce{2C2H2 + 5O2 -> 4CO2 + 2H2O}$$

火焰温度高（约 $3000℃$），可用于焊接和切割金属。

**被高锰酸钾氧化**：

$$\ce{HC≡CH ->[KMnO4/H+] CO2 + H2O}$$

##### (2) 加成反应

**与溴加成**（分步进行）：

$$\ce{HC≡CH + Br2 -> CHBr=CHBr}$$

（1,2-二溴乙烯）

$$\ce{CHBr=CHBr + Br2 -> CHBr2-CHBr2}$$

（1,1,2,2-四溴乙烷）

**与 $\ce{H2}$ 加成**（分步进行）：

$$\ce{HC≡CH + H2 ->[催化剂] CH2=CH2}$$

$$\ce{CH2=CH2 + H2 ->[催化剂] CH3-CH3}$$

**与 $\ce{HX}$ 加成**（分步进行）：

$$\ce{HC≡CH + HCl ->[催化剂] CH2=CHCl}$$

（氯乙烯）

##### (3) 加聚反应

$$\ce{nCH2=CHCl ->[催化剂] -[CH2-CHCl]-_n}$$

聚氯乙烯（PVC）

##### (4) 炔烃的特殊反应——乙炔的水化

$$\ce{HC≡CH + H2O ->[Hg^{2+}] CH3CHO}$$

乙炔在 $\ce{Hg^{2+}}$ 催化下与水加成，生成乙醛（工业制备乙醛的方法之一）。

#### 5. 炔烃的加成规律

炔烃的加成规律与烯烃类似，可分步进行。

### 三、烯烃和炔烃的对比

| 项目 | 烯烃 | 炔烃 |
|------|------|------|
| 通式 | $\ce{C_nH_{2n}}$ | $\ce{C_nH_{2n-2}}$ |
| 官能团 | $\ce{C=C}$ | $\ce{C≡C}$ |
| 化学键 | 1个 $\sigma$ + 1个 $\pi$ | 1个 $\sigma$ + 2个 $\pi$ |
| 碳原子杂化 | $\ce{sp^2}$ | $\ce{sp}$ |
| 键角 | $120°$ | $180°$ |
| 主要反应 | 加成、加聚、氧化 | 加成、加聚、氧化 |

### 四、烯烃和炔烃的命名

#### 1. 系统命名法

1. **选主链**：选择含碳碳双键或碳碳三键的最长碳链。
2. **编号**：从靠近双键或三键的一端开始编号。
3. **写名称**：双键/三键位置-主链名称。

#### 2. 常见烯烃和炔烃的命名

| 结构简式 | 系统命名 |
|----------|----------|
| $\ce{CH2=CH-CH3}$ | 丙烯 |
| $\ce{CH3-CH=CH-CH3}$ | 2-丁烯 |
| $\ce{CH≡C-CH3}$ | 丙炔 |
| $\ce{CH3-C≡CH}$ | 丙炔（另一种命名） |

---

!!! tip "学习提示"
    - 烯烃和炔烃的不饱和度决定了它们的化学性质。
    - 加成反应是烯烃和炔烃的特征反应。
    - 烯烃的顺反异构是由于碳碳双键不可旋转造成的。
