### 重点知识梳理

#### 1. 官能团的转化关系

```
烃  →  卤代烃  →  醇  →  醛  →  羧酸  →  酯  →  酰胺
   （取代）    （水解） （氧化） （氧化） （酯化） （氨解）
```

```
烯烃  ⇌  卤代烃
 （水化）  （消去）
```

```
炔烃  →  卤代烃  →  醛
（加成）   （水解）
```

#### 2. 重要反应类型

| 反应类型 | 反应物 | 产物 | 条件 |
|----------|--------|------|------|
| 取代 | 烷烃 + $\ce{X2}$ | 卤代烃 | 光照 |
| 取代 | 苯 + $\ce{X2}$ | 卤苯 | $\ce{Fe}$ 催化 |
| 取代 | 醇 + $\ce{HX}$ | 卤代烃 | 加热 |
| 消去 | 卤代烃 + $\ce{NaOH}$ | 烯烃 | 醇溶液，加热 |
| 水解 | 卤代烃 + $\ce{NaOH}$ | 醇 | 水溶液，加热 |
| 氧化 | 伯醇 | 醛/羧酸 | $\ce{Cu}$ 或 $\ce{K2Cr2O7}$ |
| 氧化 | 仲醇 | 酮 | $\ce{Cu}$ 或 $\ce{K2Cr2O7}$ |
| 氧化 | 醛 | 羧酸 | $\ce{Ag(NH3)2+}$ 或 $\ce{Cu(OH)2}$ |
| 酯化 | 羧酸 + 醇 | 酯 | 浓 $\ce{H2SO4}$，加热 |
| 水解 | 酯 + 水 | 羧酸 + 醇 | 酸或碱催化 |

#### 3. 醛和酮的鉴别

| 试剂 | 现象 | 结论 |
|------|------|------|
| 银氨溶液 | 生成银镜 | 含醛基 |
| 新制 $\ce{Cu(OH)2}$ | 生成砖红色沉淀 | 含醛基 |
| $\ce{NaHSO3}$ | 生成无色结晶 | 醛或酮 |
| 饱和 $\ce{NaHSO3}$ | 褪色 | 醛或酮 |
| $\ce{I2}$ + $\ce{NaOH}$ | 黄色沉淀 | 甲基酮 |

#### 4. 酚的鉴别

| 试剂 | 现象 | 结论 |
|------|------|------|
| 浓溴水 | 生成白色沉淀 | 苯酚 |
| $\ce{FeCl3}$ 溶液 | 显紫色 | 苯酚 |
| 饱和溴水 | 生成三溴苯酚沉淀 | 苯酚 |

## 典型例题

???+ success "例题1"
    
    下列物质中，能与银氨溶液反应的是（　）
    
    A. 乙醇　B. 乙醛　C. 丙酮　D. 乙酸
    
    **答案**：B
    
    **解析**：银氨溶液（托伦试剂）能氧化醛基，生成银镜。乙醇和乙酸不含醛基，不能反应。丙酮不含醛基，不能反应。乙醛含有醛基，能发生银镜反应。

???+ success "例题2"
    
    下列物质中，能与 $\ce{FeCl3}$ 溶液反应显紫色的是（　）
    
    A. 苯甲醇　B. 苯酚　C. 甲苯　D. 乙酸
    
    **答案**：B
    
    **解析**：苯酚与 $\ce{FeCl3}$ 溶液反应显紫色，这是酚类的特征反应。苯甲醇是醇类，不能与 $\ce{FeCl3}$ 反应显紫色。甲苯和乙酸也不能。

???+ success "例题3"
    
    以乙烯为原料合成乙酸乙酯，写出各步反应的化学方程式。
    
    **答案**：
    
    $$\ce{CH2=CH2 + H2O ->[H+] CH3CH2OH}$$
    
    $$\ce{2CH3CH2OH + O2 ->[Cu] 2CH3CHO + 2H2O}$$
    
    $$\ce{2CH3CHO + O2 ->[Co] 2CH3COOH}$$
    
    $$\ce{CH3COOH + C2H5OH <=>[浓H2SO4, Δ] CH3COOC2H5 + H2O}$$

???+ success "例题4"
    
    鉴别乙醛、苯酚、乙酸三种物质，可选用的试剂是（　）
    
    A. 银氨溶液
    
    B. $\ce{FeCl3}$ 溶液
    
    C. 碳酸钠溶液
    
    D. 以上都不行
    
    **答案**：D
    
    **解析**：需要分别检验。银氨溶液检验乙醛；$\ce{FeCl3}$ 溶液检验苯酚；碳酸钠溶液检验乙酸（产生气泡）。单一试剂不能同时鉴别三种物质。

## 能力提升

### 易错点分析

!!! warning "常见错误"
    
    1. **混淆消去反应与取代反应的条件**：卤代烃与 $\ce{NaOH}$ 的水溶液发生取代反应，与 $\ce{NaOH}$ 的醇溶液发生消去反应。
    
    2. **混淆酚与醇的反应**：苯酚与 $\ce{NaOH}$ 反应，醇不反应；苯酚与浓溴水反应，醇不反应。
    
    3. **混淆醛与酮的反应**：醛能发生银镜反应，酮不能；醛能与 $\ce{NaHSO3}$ 反应，酮也能，但反应活性不同。
    
    4. **酯化反应的方向**：羧酸提供羟基，醇提供氢原子。

### 知识拓展

#### 1. 醛酮的羟醛缩合

两个含有 $\alpha$ 氢的醛分子，在碱性条件下发生缩合反应，生成 β-羟基醛。

$$\ce{2CH3CHO ->[NaOH] CH3CH(OH)CH2CHO}$$

（3-羟基丁醛）

#### 2. 酚醛树脂的合成

苯酚与甲醛在酸或碱催化下发生缩聚反应，生成酚醛树脂。

$$\ce{nC6H5OH + nHCHO ->[-C6H3OHCH2-]_n + nH2O}$$

酚醛树脂是第一种人工合成的塑料。

#### 3. 酯的水解规律

- 酸性水解：可逆反应
- 碱性水解（皂化）：不可逆反应，水解更完全
- 酯的分子量越大，水解越困难
- 酯的取代基越复杂，水解越困难
