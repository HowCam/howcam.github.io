# 第五节 有机合成

### 一、有机合成的概述

#### 1. 有机合成的定义

**有机合成**是指利用简单易得的原料，通过一步或多步反应，制备具有特定结构和功能的有机化合物的过程。

#### 2. 有机合成的目的

- 制备自然界中稀缺但有实用价值的有机化合物
- 改进天然产物的结构，提高其性能
- 合成具有特殊功能的新材料
- 验证有机化合物的结构

#### 3. 有机合成的原则

1. **原料廉价易得**
2. **反应条件温和、操作简便**
3. **产率高、副产物少**
4. **符合绿色化学的要求**

### 二、有机合成的路线设计

#### 1. 逆合成分析法

逆合成分析法是有机合成路线设计的常用方法。

**基本思路**：从目标分子出发，反向推导，逐步找到起始原料。

**步骤**：
1. 确定目标分子
2. 识别目标分子中的关键键
3. 逆向切断该键，得到前体
4. 重复上述步骤，直到得到易得的原料

#### 2. 碳链的增长方法

##### (1) 增长一个碳原子

**方法一**：卤代烃的氰化反应

$$\ce{RBr + NaCN -> RCN + NaBr}$$

$$\ce{RCN + 2H2O -> RCOOH + NH3}$$

（腈水解为羧酸）

**方法二**：格氏试剂与 $\ce{CO2}$ 反应

$$\ce{RMgBr + CO2 -> RCOOMgBr ->[H2O] RCOOH}$$

##### (2) 增长多个碳原子

**方法**：炔烃的碳链增长

$$\ce{RC≡CH + CH3I ->[NaNH2] RC≡CCH3}$$

$$\ce{RC≡CCH3 + H2 ->[Lindlar] RC=CHCH3}$$

$$\ce{RC≡CCH3 + H2O ->[Hg^{2+}] RC(O)CH2CH3}$$

（酮）

#### 3. 官能团的转化

##### (1) 官能团的引入

| 目标官能团 | 引入方法 |
|------------|----------|
| $-\ce{OH}$ | 烯烃水化、卤代烃水解、醛酮还原 |
| $-\ce{X}$ | 烃的卤代、醇的卤代、烯烃加成 |
| $-\ce{NH2}$ | 卤代烃氨解、硝基还原 |
| $-\ce{NO2}$ | 芳香烃硝化 |
| $-\ce{COOH}$ | 伯醇氧化、醛氧化、腈水解 |
| $-\ce{CHO}$ | 伯醇氧化、烯烃臭氧化 |
| $\ce{C=O}$ | 仲醇氧化、炔烃水化 |

##### (2) 官能团的转化

| 转化 | 反应 |
|------|------|
| $-\ce{OH}$ → $-\ce{X}$ | 醇与 $\ce{HX}$ 或 $\ce{PX5}$ 反应 |
| $-\ce{X}$ → $-\ce{OH}$ | 卤代烃水解 |
| $-\ce{CH2OH}$ → $-\ce{CHO}$ | 伯醇氧化 |
| $-\ce{CHO}$ → $-\ce{CH2OH}$ | 醛还原 |
| $-\ce{CHO}$ → $-\ce{COOH}$ | 醛氧化 |
| $-\ce{COOH}$ → $-\ce{COOR}$ | 酯化反应 |
| $\ce{-CH=CH2}$ → $\ce{-CH2-CH2OH}$ | 烯烃水化 |
| $\ce{-CH=CH2}$ → $\ce{-CH2-CH2X}$ | 烯烃与 $\ce{HX}$ 加成 |

#### 4. 碳链的缩短方法

##### (1) 脱羧反应

$$\ce{RCOONa + NaOH ->[CaO, Δ] RH + Na2CO3}$$

##### (2) 氧化反应

烯烃被臭氧氧化可断裂碳链：

$$\ce{RCH=CH2 ->[O3] RCHO + HCHO}$$

##### (3) 裂化反应

长链烷烃在高温下裂化，生成较短的分子。

### 三、常见有机合成路线

#### 1. 由乙烯合成乙酸乙酯

$$\ce{CH2=CH2 ->[H2O, H+] CH3CH2OH ->[O] CH3CHO ->[O] CH3COOH}$$

$$\ce{CH3COOH + CH3CH2OH <=>[浓H2SO4, Δ] CH3COOC2H5 + H2O}$$

#### 2. 由丙烯合成丙三醇

$$\ce{CH3CH=CH2 ->[Cl2, 高温] ClCH2CH=CH2 ->[Cl2, H2O] HOCH2CHClCH2Cl}$$

$$\ce{HOCH2CHClCH2Cl ->[NaOH, 水] HOCH2CH(OH)CH2OH}$$

#### 3. 由苯合成苯甲酸

$$\ce{C6H6 ->[Br2, Fe] C6H5Br ->[Mg, 无水醚] C6H5MgBr ->[CO2] C6H5COOMgBr}$$

$$\ce{C6H5COOMgBr ->[H2O] C6H5COOH}$$

#### 4. 由甲苯合成 TNT

$$\ce{C6H5CH3 ->[浓HNO3, 浓H2SO4, Δ] C6H4(CH3)NO2}$$

$$\ce{C6H4(CH3)NO2 ->[浓HNO3, 浓H2SO4, Δ] C6H3(CH3)(NO2)2}$$

$$\ce{C6H3(CH3)(NO2)2 ->[浓HNO3, 浓H2SO4, Δ] C6H2(CH3)(NO2)3}$$

（2,4,6-三硝基甲苯，TNT）

### 四、有机合成中的重要反应

#### 1. 取代反应

| 反应 | 试剂 | 产物 |
|------|------|------|
| 烷烃卤代 | $\ce{Cl2/Br2}$，光照 | 卤代烃 |
| 苯环卤代 | $\ce{Cl2/Br2}$，$\ce{Fe}$ 或 $\ce{FeX3}$ | 卤苯 |
| 苯环硝化 | 浓 $\ce{HNO3}$，浓 $\ce{H2SO4}$ | 硝基苯 |
| 醇卤代 | $\ce{HX}$ 或 $\ce{PX5}$ | 卤代烃 |
| 卤代烃水解 | $\ce{NaOH}$，水 | 醇 |

#### 2. 加成反应

| 反应 | 试剂 | 产物 |
|------|------|------|
| 烯烃加 $\ce{H2}$ | $\ce{H2}$，催化剂 | 烷烃 |
| 烯烃加 $\ce{HX}$ | $\ce{HX}$ | 卤代烃 |
| 烯烃加 $\ce{X2}$ | $\ce{Br2/Cl2}$ | 二卤代烃 |
| 烯烃水化 | $\ce{H2O}$，$\ce{H+}$ | 醇 |
| 醛加 $\ce{H2}$ | $\ce{H2}$，$\ce{Ni}$ | 伯醇 |
| 酮加 $\ce{H2}$ | $\ce{H2}$，$\ce{Ni}$ | 仲醇 |

#### 3. 消去反应

| 反应 | 条件 | 产物 |
|------|------|------|
| 醇消去 | 浓 $\ce{H2SO4}$，$170°C$ | 烯烃 |
| 卤代烃消去 | $\ce{NaOH}$，醇，Δ | 烯烃 |

#### 4. 氧化反应

| 反应 | 试剂 | 产物 |
|------|------|------|
| 伯醇氧化 | $\ce{O2}$，$\ce{Cu}$ 或 $\ce{K2Cr2O7}$ | 醛 → 羧酸 |
| 仲醇氧化 | $\ce{O2}$，$\ce{Cu}$ 或 $\ce{K2Cr2O7}$ | 酮 |
| 烯烃氧化 | $\ce{KMnO4}$，$\ce{H2SO4}$ | 醛/酮/羧酸 |
| 醛氧化 | $\ce{Ag(NH3)2+}$ 或 $\ce{Cu(OH)2}$ | 羧酸 |

#### 5. 还原反应

| 反应 | 试剂 | 产物 |
|------|------|------|
| 醛还原 | $\ce{H2}$，$\ce{Ni}$ 或 $\ce{NaBH4}$ | 伯醇 |
| 酮还原 | $\ce{H2}$，$\ce{Ni}$ 或 $\ce{NaBH4}$ | 仲醇 |
| 硝基还原 | $\ce{Fe/HCl}$ 或 $\ce{H2/Pd}$ | 胺 |

#### 6. 缩合反应

| 反应 | 试剂 | 产物 |
|------|------|------|
| 酯化反应 | 羧酸 + 醇，浓 $\ce{H2SO4}$ | 酯 |
| 缩醛反应 | 醛 + 醇 | 缩醛 |
| 羟醛缩合 | 含 $\alpha$ 氢的醛 | β-羟基醛 |
| 酯缩合 | 酯 | β-酮酸酯 |

### 五、有机合成实例分析

#### 例题1

以乙烯为唯一有机原料（其他无机试剂任选），合成乙酸乙酯。

**合成路线**：

$$\ce{CH2=CH2 ->[H2O, H+] CH3CH2OH}$$

$$\ce{CH3CH2OH ->[O] CH3CHO ->[O] CH3COOH}$$

$$\ce{CH3COOH + CH3CH2OH <=>[浓H2SO4, Δ] CH3COOC2H5 + H2O}$$

#### 例题2

以苯为唯一有机原料（其他无机试剂任选），合成苯甲酸。

**合成路线**：

$$\ce{C6H6 ->[Br2, Fe] C6H5Br}$$

$$\ce{C6H5Br ->[Mg, 无水乙醚] C6H5MgBr}$$

$$\ce{C6H5MgBr ->[CO2] C6H5COOMgBr}$$

$$\ce{C6H5COOMgBr ->[H2O/H+] C6H5COOH}$$

#### 例题3

以乙醇为唯一有机原料（其他无机试剂任选），合成丁二酸二乙酯。

**合成路线**：

$$\ce{CH3CH2OH ->[O] CH3CHO ->[O] CH3COOH}$$

$$\ce{CH3CH2OH ->[PBr3] CH3CH2Br}$$

$$\ce{CH3CH2Br ->[NaCN] CH3CH2CN}$$

$$\ce{CH3CH2CN ->[H2O, H+] CH3CH2COOH}$$

$$\ce{CH3COOH + CH3CH2OH <=>[浓H2SO4, Δ] CH3COOC2H5}$$

$$\ce{CH3COOC2H5 ->[C2H5ONa] CH3COCH2COOC2H5}$$

$$\ce{CH3COCH2COOC2H5 ->[1. OH-] ->[2. HCl] CH3COCH2COOH}$$

$$\ce{CH3COCH2COOH ->[H2, Pd] HOOCCH2CH2COOH}$$

$$\ce{HOOCCH2CH2COOH + 2C2H5OH <=>[浓H2SO4, Δ] C2H5OOCCH2CH2COOC2H5}$$

---

!!! tip "学习提示"
    - 有机合成路线设计要灵活运用各种有机反应。
    - 逆合成分析法是设计合成路线的重要方法。
    - 碳链增长和官能团转化是有机合成的核心。
    - 选择合理的合成路线要综合考虑原料、成本、产率等因素。
