# 第二节 醇 酚

### 一、醇

#### 1. 醇的分类

##### (1) 按羟基数目分类

| 类型 | 定义 | 举例 |
|------|------|------|
| 一元醇 | 分子中含有一个羟基 | 乙醇 $\ce{C2H5OH}$ |
| 二元醇 | 分子中含有两个羟基 | 乙二醇 $\ce{HOCH2CH2OH}$ |
| 多元醇 | 分子中含有多个羟基 | 丙三醇 $\ce{HOCH2CH(OH)CH2OH}$ |

##### (2) 按羟基所连碳原子类型分类

| 类型 | 羟基位置 | 举例 |
|------|----------|------|
| 伯醇 | 羟基连接在伯碳上 | 乙醇 $\ce{CH3CH2OH}$ |
| 仲醇 | 羟基连接在仲碳上 | 异丙醇 $\ce{(CH3)2CHOH}$ |
| 叔醇 | 羟基连接在叔碳上 | 叔丁醇 $\ce{(CH3)3COH}$ |

##### (3) 按烃基是否饱和分类

| 类型 | 烃基 | 举例 |
|------|------|------|
| 饱和醇 | 饱和烃基 | 乙醇 $\ce{C2H5OH}$ |
| 不饱和醇 | 不饱和烃基 | 烯丙醇 $\ce{CH2=CH-CH2OH}$ |
| 芳香醇 | 芳香烃基 | 苯甲醇 $\ce{C6H5CH2OH}$ |

#### 2. 醇的命名

##### (1) 系统命名法

1. 选择含羟基的最长碳链作为主链
2. 从靠近羟基的一端开始编号
3. 羟基位置用数字表示
4. 写名称：羟基位置-主链名称 + "醇"

##### (2) 常见醇的命名

| 结构简式 | 系统命名 |
|----------|----------|
| $\ce{CH3OH}$ | 甲醇 |
| $\ce{CH3CH2OH}$ | 乙醇 |
| $\ce{CH3CH2CH2OH}$ | 1-丙醇 |
| $\ce{CH3CH(OH)CH3}$ | 2-丙醇 |
| $\ce{HOCH2CH2OH}$ | 乙二醇 |
| $\ce{HOCH2CH(OH)CH2OH}$ | 丙三醇（甘油） |

#### 3. 醇的物理性质

##### (1) 状态

- 碳原子数 1-3 的醇为无色液体
- 碳原子数 4-11 的醇为油状液体
- 碳原子数 12 以上的醇为固体

##### (2) 沸点

- 醇的沸点比相应烷烃高得多
- 原因是醇分子间可形成氢键
- 随碳原子数增加，沸点升高
- 支链越多，沸点越低

!!! note "氢键的影响"
    醇分子间形成氢键，需要较高温度才能破坏，因此醇的沸点比相应的醚和卤代烃高。

##### (3) 溶解性

- 甲醇、乙醇、丙醇可与水互溶
- 随着碳原子数增加，溶解度逐渐降低
- 原因是碳链越长，疏水性越强

| 醇 | 与水互溶性 |
|----|------------|
| 甲醇 | 互溶 |
| 乙醇 | 互溶 |
| 丙醇 | 互溶 |
| 丁醇 | 部分互溶 |
| 戊醇 | 微溶 |

#### 4. 醇的化学性质

##### (1) 与活泼金属反应

醇与钠、钾等活泼金属反应，生成醇盐和氢气。

$$\ce{2CH3CH2OH + 2Na -> 2CH3CH2ONa + H2↑}$$

反应活性：甲醇 > 伯醇 > 仲醇 > 叔醇

##### (2) 氧化反应

伯醇被氧化为醛，继续氧化为羧酸。

$$\ce{CH3CH2OH ->[O] CH3CHO ->[O] CH3COOH}$$

仲醇被氧化为酮。

$$\ce{(CH3)2CHOH ->[O] (CH3)2C=O}$$

叔醇不易被氧化。

**检验**：醇的催化氧化
- 伯醇：氧化后产物可与银氨溶液反应（银镜反应）
- 仲醇：氧化后产物不能与银氨溶液反应，但可使高锰酸钾褪色
- 叔醇：不能被氧化

##### (3) 消去反应

醇在浓硫酸催化下加热，发生消去反应，生成烯烃。

$$\ce{CH3CH2OH ->[浓H2SO4, 170°C] CH2=CH2 + H2O}$$

**规律**：
- 邻二醇可发生分子内脱水，生成醛或酮
- 醇的脱水反应温度高于消去反应温度

##### (4) 取代反应

醇与氢卤酸反应，羟基被卤原子取代，生成卤代烃。

$$\ce{CH3CH2OH + HBr -> CH3CH2Br + H2O}$$

反应活性：叔醇 > 仲醇 > 伯醇 > 甲醇

##### (5) 酯化反应

醇与羧酸在浓硫酸催化下发生酯化反应，生成酯。

$$\ce{CH3COOH + C2H5OH <=>[浓H2SO4, Δ] CH3COOC2H5 + H2O}$$

##### (6) 分子间脱水

两分子醇在浓硫酸催化下加热，发生分子间脱水，生成醚。

$$\ce{2CH3CH2OH ->[浓H2SO4, 140°C] CH3CH2OCH2CH3 + H2O}$$

（乙醚）

### 二、苯酚

#### 1. 苯酚的结构

**苯酚**的分子式：$\ce{C6H5OH}$

结构：苯环上连接一个羟基

$$\ce{C6H5-OH}$$

#### 2. 苯酚的物理性质

- 无色或白色晶体
- 熔点：$43°C$
- 沸点：$181.8°C$
- 有特殊气味
- 常温下微溶于水（$6.7g/100g$ 水）
- 加热时溶解度增大
- 易溶于有机溶剂

!!! warning "注意"
    苯酚有毒，对皮肤有强烈的腐蚀性。如不慎沾到皮肤上，应立即用酒精冲洗。

#### 3. 苯酚的化学性质

##### (1) 酸性

苯酚具有弱酸性，能与氢氧化钠反应，生成苯酚钠和水。

$$\ce{C6H5OH + NaOH -> C6H5ONa + H2O}$$

但苯酚的酸性比碳酸弱，不能使石蕊变色。

$$\ce{C6H5OH + Na2CO3 -> C6H5ONa + NaHCO3}$$

!!! note "苯酚酸性弱于碳酸"
    向苯酚钠溶液中通入 $\ce{CO2}$，会析出苯酚，说明苯酚酸性弱于碳酸：

$$\ce{C6H5ONa + CO2 + H2O -> C6H5OH + NaHCO3}$$

##### (2) 取代反应

苯酚与浓溴水反应，生成三溴苯酚白色沉淀。

$$\ce{C6H5OH + 3Br2 -> C6H2Br3OH↓ + 3HBr}$$

（2,4,6-三溴苯酚）

该反应非常灵敏，可用于苯酚的定性检验。

##### (3) 显色反应

苯酚与 $\ce{FeCl3}$ 溶液反应，呈现紫色，可用于检验苯酚。

$$\ce{6C6H5OH + FeCl3 -> [Fe(OC6H5)6]^{3-} + 6H+ + 3Cl-}$$

##### (4) 氧化反应

苯酚露置在空气中会被氧化，呈粉红色。

##### (5) 加成反应

苯酚在镍催化剂作用下可与 $\ce{H2}$ 加成，生成环己醇。

$$\ce{C6H5OH + 3H2 ->[Ni] C6H11OH}$$

#### 4. 苯酚的用途

| 用途 | 说明 |
|------|------|
| 消毒剂 | 苯酚稀溶液可用于消毒 |
| 合成药物 | 合成阿司匹林等药物 |
| 生产塑料 | 生产酚醛树脂 |
| 生产染料 | 生产染料和颜料 |

### 三、醇和酚的比较

| 项目 | 醇 | 苯酚 |
|------|-----|------|
| 结构 | 羟基连接在脂肪链上 | 羟基直接连接在苯环上 |
| 酸性 | 几乎不显酸性 | 弱酸性（强于碳酸） |
| 与 $\ce{Na}$ 反应 | 能 | 能 |
| 与 $\ce{NaOH}$ 反应 | 不能（伯、仲醇） | 能 |
| 与 $\ce{Na2CO3}$ 反应 | 不能 | 能 |
| 与 $\ce{FeCl3}$ 反应 | 不能 | 显紫色 |
| 与浓溴水反应 | 不能 | 生成白色沉淀 |

### 四、乙二醇和甘油

#### 1. 乙二醇

**分子式**：$\ce{C2H6O2}$

**结构**：$\ce{HOCH2-CH2OH}$

**性质**：
- 无色无臭液体
- 沸点：$197°C$
- 与水互溶
- 有甜味

**用途**：
- 汽车防冻液
- 生产聚酯纤维
- 生产溶剂

#### 2. 丙三醇（甘油）

**分子式**：$\ce{C3H8O3}$

**结构**：$\ce{HOCH2-CH(OH)-CH2OH}$

**性质**：
- 无色粘稠液体
- 沸点：$290°C$
- 与水互溶
- 有甜味
- 吸湿性强

**用途**：
- 化妆品保湿剂
- 食品甜味剂
- 生产硝化甘油（炸药）
- 医药溶剂

!!! note "检验甘油"
    甘油与 $\ce{Cu(OH)2}$ 反应，生成绛蓝色溶液（铜氨络合物），可用于检验多元醇。

$$\ce{CH2OH(CHOH)2CH2OH + Cu(OH)2 -> [Cu(CHOH)4] 深蓝色 + 2H2O}$$

---

!!! tip "学习提示"
    - 醇和酚的结构差异导致了它们性质的不同。
    - 苯酚的酸性比碳酸弱，但不能使石蕊变色。
    - 苯酚与溴水的取代反应非常灵敏，可用于检验苯酚。
    - 多元醇与 $\ce{Cu(OH)2}$ 反应可生成有颜色的络合物。
