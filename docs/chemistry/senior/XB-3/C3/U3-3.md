# 第三节 醛 酮

### 一、醛和酮的定义

#### 1. 醛

**醛**是指分子中含有醛基（$-\ce{CHO}$）的有机化合物。

**官能团**：醛基（$-\ce{CHO}$）

**通式**：$\ce{RCHO}$（$\ce{R}$ 可以是氢或烃基）

最简单的醛：甲醛 $\ce{HCHO}$

#### 2. 酮

**酮**是指分子中含有羰基（$\ce{C=O}$），且羰基连接两个烃基的有机化合物。

**官能团**：羰基（$\ce{C=O}$）

**通式**：$\ce{RCOR'}$（$\ce{R}$ 和 $\ce{R'}$ 为烃基，且不能为氢）

最简单的酮：丙酮 $\ce{CH3COCH3}$

### 二、醛和酮的分类

#### 1. 按烃基类型分类

| 类型 | 醛 | 酮 |
|------|-----|-----|
| 脂肪醛/酮 | 脂肪族醛/酮 | 脂肪族酮 |
| 芳香醛/酮 | 芳香醛（如苯甲醛） | 芳香酮（如苯乙酮） |

#### 2. 按醛基或羰基数目分类

| 类型 | 醛 | 酮 |
|------|-----|-----|
| 一元醛/酮 | 分子中含一个醛基 | 分子中含一个羰基 |
| 二元醛/酮 | 分子中含两个醛基 | 分子中含两个羰基 |

#### 3. 按烃基是否饱和分类

| 类型 | 醛 | 酮 |
|------|-----|-----|
| 饱和醛/酮 | 饱和烃基 | 饱和烃基 |
| 不饱和醛/酮 | 不饱和烃基 | 不饱和烃基 |

### 三、醛和酮的命名

#### 1. 醛的系统命名法

1. 选择含醛基的最长碳链作为主链
2. 从醛基碳开始编号（醛基碳总是1号）
3. 写名称：主链名称 + "醛"

#### 2. 酮的系统命名法

1. 选择含羰基的最长碳链作为主链
2. 从靠近羰基的一端开始编号
3. 羰基位置用数字表示
4. 写名称：羰基位置-主链名称 + "酮"

#### 3. 常见醛和酮的命名

| 结构简式 | 系统命名 |
|----------|----------|
| $\ce{HCHO}$ | 甲醛 |
| $\ce{CH3CHO}$ | 乙醛 |
| $\ce{CH3CH2CHO}$ | 丙醛 |
| $\ce{C6H5CHO}$ | 苯甲醛 |
| $\ce{CH3COCH3}$ | 丙酮 |
| $\ce{CH3COCH2CH3}$ | 丁酮 |

### 四、甲醛和乙醛

#### 1. 甲醛

**分子式**：$\ce{CH2O}$

**结构**：$\ce{HCHO}$

**物理性质**：
- 无色有刺激性气味的气体
- 沸点：$-19.5°C$
- 易溶于水（福尔马林是 37%-40% 的甲醛水溶液）
- 密度小于空气

**化学性质**：

##### (1) 氧化反应

甲醛可被氧化为甲酸：

$$\ce{HCHO ->[O] HCOOH}$$

甲醛可被银氨溶液氧化（银镜反应）：

$$\ce{HCHO + 2[Ag(NH3)2]OH -> HCOONH4 + 2Ag↓ + 3NH3 + H2O}$$

甲醛可被新制 $\ce{Cu(OH)2}$ 氧化：

$$\ce{HCHO + 2Cu(OH)2 -> HCOOH + Cu2O↓ + 2H2O}$$

##### (2) 还原反应

甲醛可被 $\ce{H2}$ 还原为甲醇：

$$\ce{HCHO + H2 ->[Ni] CH3OH}$$

##### (3) 缩聚反应

甲醛可与苯酚发生缩聚反应，生成酚醛树脂：

$$\ce{nC6H5OH + nHCHO ->[-C6H3OHCH2-]_n + nH2O}$$

**用途**：
- 防腐剂（福尔马林）
- 生产酚醛树脂
- 生产塑料
- 生产药物

#### 2. 乙醛

**分子式**：$\ce{C2H4O}$

**结构**：$\ce{CH3CHO}$

**物理性质**：
- 无色有刺激性气味的液体
- 沸点：$20.8°C$
- 易挥发
- 溶于水和有机溶剂

**化学性质**：

##### (1) 氧化反应

乙醛可被银氨溶液氧化（银镜反应）：

$$\ce{CH3CHO + 2[Ag(NH3)2]OH -> CH3COONH4 + 2Ag↓ + 3NH3 + H2O}$$

乙醛可被新制 $\ce{Cu(OH)2}$ 氧化：

$$\ce{CH3CHO + 2Cu(OH)2 -> CH3COOH + Cu2O↓ + 2H2O}$$

##### (2) 还原反应

乙醛可被 $\ce{H2}$ 还原为乙醇：

$$\ce{CH3CHO + H2 ->[Ni] CH3CH2OH}$$

### 五、丙酮

**分子式**：$\ce{C3H6O}$

**结构**：$\ce{CH3COCH3}$

**物理性质**：
- 无色有特殊气味的液体
- 沸点：$56.5°C$
- 易挥发
- 与水互溶
- 是常用的有机溶剂

**化学性质**：

##### (1) 加成反应

丙酮可与 $\ce{H2}$ 加成，生成 2-丙醇：

$$\ce{CH3COCH3 + H2 ->[Ni] (CH3)2CHOH}$$

丙酮可与氢氰酸加成，生成羟基腈：

$$\ce{CH3COCH3 + HCN -> CH3C(OH)(CN)CH3}$$

##### (2) 还原反应

丙酮可被还原为异丙醇：

$$\ce{CH3COCH3 + H2 ->[Ni] (CH3)2CHOH}$$

##### (3) 检验

丙酮不能发生银镜反应，可与乙醛区分。

丙酮可使溴水褪色（与 $\ce{Br2}$ 发生加成反应）。

### 六、醛和酮的化学性质

#### 1. 醛的化学性质

##### (1) 加成反应

醛可与 $\ce{H2}$、$\ce{HCN}$ 等发生加成反应。

$$\ce{RCHO + H2 ->[Ni] RCH2OH}$$

$$\ce{RCHO + HCN -> RCH(OH)CN}$$

##### (2) 氧化反应

**银镜反应**：

$$\ce{RCHO + 2[Ag(NH3)2]OH -> RCOONH4 + 2Ag↓ + 3NH3 + H2O}$$

**与新制 $\ce{Cu(OH)2}$ 反应**：

$$\ce{RCHO + 2Cu(OH)2 -> RCOOH + Cu2O↓ + 2H2O}$$

!!! note "注意"
    醛能被弱氧化剂氧化，说明醛的还原性较强。酮不能发生银镜反应，可用于区分醛和酮。

##### (3) 催化氧化

伯醛氧化为羧酸：

$$\ce{RCHO ->[O] RCOOH}$$

##### (4) 缩合反应

醛可与醇发生缩合反应，生成缩醛。

$$\ce{RCHO + 2R'OH -> RCH(OR')2 + H2O}$$

#### 2. 酮的化学性质

##### (1) 加成反应

酮可与 $\ce{H2}$、$\ce{HCN}$ 等发生加成反应，但比醛困难。

$$\ce{RCOR' + H2 ->[Ni] RCH(OH)R'}$$

##### (2) 不对称加成

与 $\ce{HCN}$ 加成时，$\ce{CN-}$ 倾向于加在空间位阻较小的碳原子上。

##### (3) 还原反应

酮可被还原为仲醇。

$$\ce{RCOR' + H2 ->[Ni] RCH(OH)R'}$$

#### 3. 醛和酮的对比

| 项目 | 醛 | 酮 |
|------|-----|-----|
| 官能团 | $-\ce{CHO}$ | $\ce{C=O}$（连接两个烃基） |
| 通式 | $\ce{RCHO}$ | $\ce{RCOR'}$ |
| 银镜反应 | 能 | 不能 |
| 与 $\ce{Cu(OH)2}$ 反应 | 生成砖红色 $\ce{Cu2O}$ | 不能 |
| 加成反应 | 容易 | 较难 |
| 还原产物 | 伯醇 | 仲醇 |

### 七、醛和酮的检验

#### 1. 银镜反应

银氨溶液（托伦试剂）与醛反应，生成银镜。

**操作**：在洁净试管中加入 1mL 银氨溶液，滴入 2-3 滴乙醛溶液，水浴加热。

**现象**：试管内壁附着一层光亮的银镜。

#### 2. 斐林反应

新制 $\ce{Cu(OH)2}$ 与脂肪醛反应，生成砖红色 $\ce{Cu2O}$ 沉淀。

**操作**：在试管中加入 2mL 斐林试剂甲（$\ce{CuSO4}$ 溶液）和 2mL 斐林试剂乙（酒石酸钾钠氢氧化钠溶液），滴入 5-6 滴乙醛溶液，加热。

**现象**：生成砖红色沉淀。

!!! note "注意"
    斐林试剂是 $\ce{Cu^{2+}}$ 与酒石酸钾钠在碱性条件下形成的深蓝色溶液。芳香醛（如苯甲醛）不能发生斐林反应。

#### 3. 与 $\ce{NaHSO3}$ 反应

醛和酮均可与 $\ce{NaHSO3}$ 反应，生成无色结晶。

$$\ce{RCHO + NaHSO3 -> RCH(OH)SO3Na}$$

该反应可用于醛和酮的分离与提纯。

---

!!! tip "学习提示"
    - 醛和酮都含有羰基（$\ce{C=O}$），但醛的羰基连接氢，酮的羰基连接两个烃基。
    - 醛的还原性比酮强，可发生银镜反应，酮不能。
    - 银镜反应和斐林反应是检验醛的重要方法。
    - 甲醛是唯一能使蛋白质变性的醛，常用于消毒和防腐。
