# 第四节 羧酸 羧酸衍生物

### 一、羧酸

#### 1. 羧酸的定义

**羧酸**是指分子中含有羧基（$-\ce{COOH}$）的有机化合物。

**官能团**：羧基（$-\ce{COOH}$）

**通式**：$\ce{RCOOH}$（$\ce{R}$ 可以是氢或烃基）

#### 2. 羧酸的分类

##### (1) 按羧基数目分类

| 类型 | 定义 | 举例 |
|------|------|------|
| 一元羧酸 | 分子中含有一个羧基 | 乙酸 $\ce{CH3COOH}$ |
| 二元羧酸 | 分子中含有两个羧基 | 乙二酸（草酸）$\ce{HOOC-COOH}$ |
| 多元羧酸 | 分子中含有多个羧基 | 柠檬酸 |

##### (2) 按烃基类型分类

| 类型 | 定义 | 举例 |
|------|------|------|
| 脂肪羧酸 | 羧基连接在脂肪烃基上 | 乙酸 $\ce{CH3COOH}$ |
| 芳香羧酸 | 羧基连接在芳香烃基上 | 苯甲酸 $\ce{C6H5COOH}$ |

##### (3) 按烃基是否饱和分类

| 类型 | 定义 | 举例 |
|------|------|------|
| 饱和羧酸 | 饱和烃基 | 乙酸 $\ce{CH3COOH}$ |
| 不饱和羧酸 | 不饱和烃基 | 丙烯酸 $\ce{CH2=CHCOOH}$ |

#### 3. 羧酸的命名

##### (1) 系统命名法

1. 选择含羧基的最长碳链作为主链
2. 从羧基碳开始编号（羧基碳总是1号）
3. 写名称：主链名称 + "酸"

##### (2) 常见羧酸的命名

| 结构简式 | 系统命名 |
|----------|----------|
| $\ce{HCOOH}$ | 甲酸 |
| $\ce{CH3COOH}$ | 乙酸 |
| $\ce{CH3CH2COOH}$ | 丙酸 |
| $\ce{(CH3)2CHCOOH}$ | 2-甲基丙酸（异丁酸） |
| $\ce{C6H5COOH}$ | 苯甲酸 |
| $\ce{HOOC-COOH}$ | 乙二酸（草酸） |
| $\ce{HOOC-CH2-COOH}$ | 丙二酸 |

#### 4. 乙酸

**分子式**：$\ce{C2H4O2}$

**结构**：$\ce{CH3COOH}$

**物理性质**：
- 无色有刺激性气味的液体
- 沸点：$117.9°C$
- 熔点：$16.6°C$（低于熔点为冰状固体，称冰醋酸）
- 易溶于水和有机溶剂

**化学性质**：

##### (1) 酸性

乙酸是一元弱酸，电离度约 1.3%，酸性比碳酸强。

$$\ce{CH3COOH <=> CH3COO- + H+}$$

能电离出 $\ce{H+}$，因此具有酸的通性：

- 与指示剂反应：使石蕊变红
- 与碱反应：$\ce{CH3COOH + NaOH -> CH3COONa + H2O}$
- 与盐反应：$\ce{2CH3COOH + Na2CO3 -> 2CH3COONa + CO2↑ + H2O}$
- 与活泼金属反应：$\ce{2CH3COOH + Zn -> (CH3COO)2Zn + H2↑}$

##### (2) 酯化反应

乙酸与醇在浓硫酸催化下发生酯化反应，生成酯。

$$\ce{CH3COOH + C2H5OH <=>[浓H2SO4, Δ] CH3COOC2H5 + H2O}$$

!!! note "酯化反应的机理"
    酯化反应是可逆反应，浓硫酸起催化和吸水作用。反应时，羧酸提供羟基，醇提供氢原子。

##### (3) 取代反应

乙酸可与 $\ce{PCl5}$、$\ce{PCl3}$、$\ce{SOCl2}$ 等反应，生成酰卤。

$$\ce{CH3COOH + PCl5 -> CH3COCl + POCl3 + HCl}$$

### 二、羧酸的物理性质

#### 1. 状态

- 碳原子数 1-3 的低级羧酸为有刺激性气味的液体
- 碳原子数 4-9 的中级羧酸为有腐败气味的油状液体
- 碳原子数 10 以上的羧酸为无味的蜡状固体

#### 2. 沸点

- 羧酸的沸点比相应醇高
- 原因是羧酸分子间可形成两个氢键（更强的二聚体）
- 随碳原子数增加，沸点升高

#### 3. 溶解性

- 低碳数的羧酸可与水互溶
- 随着碳原子数增加，溶解度逐渐降低
- 原因是羧基是亲水基团，但碳链是疏水基团

| 羧酸 | 溶解性 |
|------|--------|
| 甲酸 | 互溶 |
| 乙酸 | 互溶 |
| 丙酸 | 互溶 |
| 丁酸 | 微溶 |
| 戊酸 | 微溶 |

#### 4. 酸性比较

| 羧酸 | 电离常数（$Ka$） | 相对酸性 |
|------|------------------|----------|
| 甲酸 | $1.8 \times 10^{-4}$ | 最强 |
| 乙酸 | $1.8 \times 10^{-5}$ | 强 |
| 丙酸 | $1.3 \times 10^{-5}$ | 中 |
| 草酸 | $5.9 \times 10^{-2}$（第一步） | 最强（二元酸）|

### 三、羧酸的化学性质

#### 1. 酸性

羧酸具有酸性，能与碱反应。

$$\ce{RCOOH + NaOH -> RCOONa + H2O}$$

羧酸的酸性比碳酸强，但比盐酸、硫酸等强酸弱。

$$\ce{2RCOOH + Na2CO3 -> 2RCOONa + CO2↑ + H2O}$$

#### 2. 酯化反应

羧酸与醇在浓硫酸催化下发生酯化反应。

$$\ce{RCOOH + R'OH <=>[浓H2SO4, Δ] RCOOR' + H2O}$$

#### 3. 脱羧反应

羧酸盐在加热条件下可脱去羧基，生成烃。

$$\ce{RCOONa + NaOH ->[CaO, Δ] RH + Na2CO3}$$

（只适用于无 $\alpha$ 氢的羧酸，如苯甲酸）

#### 4. α-氢的取代反应

含有 $\alpha$ 氢的羧酸可发生卤代反应。

$$\ce{CH3COOH + Cl2 ->[P] CH2ClCOOH + HCl}$$

（α-氯乙酸）

### 四、羧酸衍生物

#### 1. 酯

##### (1) 酯的结构

**酯**是羧酸与醇脱水缩合的产物，含有酯基（$-\ce{COOR}$）。

**通式**：$\ce{RCOOR'}$

##### (2) 酯的命名

命名方法：某酸某酯

| 结构简式 | 系统命名 |
|----------|----------|
| $\ce{HCOOCH3}$ | 甲酸甲酯 |
| $\ce{CH3COOCH3}$ | 乙酸甲酯 |
| $\ce{CH3COOC2H5}$ | 乙酸乙酯 |
| $\ce{C6H5COOCH3}$ | 苯甲酸甲酯 |

##### (3) 酯的性质

**物理性质**：
- 多为无色有果香味的液体
- 密度小于水
- 难溶于水，溶于有机溶剂
- 低级酯沸点较低

**化学性质**：

**水解反应**：

酸性水解：

$$\ce{CH3COOC2H5 + H2O <=>[稀H2SO4, Δ] CH3COOH + C2H5OH}$$

碱性水解（皂化反应）：

$$\ce{CH3COOC2H5 + NaOH -> CH3COONa + C2H5OH}$$

!!! note "酯的水解"
    酯在酸性条件下水解是可逆反应，在碱性条件下水解是不可逆反应。碱性条件下，生成的羧酸与碱反应生成盐，使平衡正向移动，水解更完全。

#### 2. 酰胺

##### (1) 酰胺的结构

酰胺是羧酸与氨或胺脱水缩合的产物，含有酰胺基（$-\ce{CONH2}$）。

**通式**：$\ce{RCONH2}$

##### (2) 酰胺的命名

命名方法：某酰胺

| 结构简式 | 系统命名 |
|----------|----------|
| $\ce{HCONH2}$ | 甲酰胺 |
| $\ce{CH3CONH2}$ | 乙酰胺 |
| $\ce{C6H5CONH2}$ | 苯甲酰胺 |

##### (3) 酰胺的性质

**物理性质**：
- 甲酰胺、乙酰胺为白色晶体
- 苯甲酰胺为斜方晶体
- 低级酰胺可溶于水

**化学性质**：

**水解反应**：

$$\ce{RCONH2 + H2O -> RCOOH + NH3}$$

（酸性或碱性条件下更易水解）

#### 3. 酰卤

##### (1) 酰卤的结构

酰卤是羧酸中的羟基被卤素取代的产物，含有酰卤基（$-\ce{COX}$）。

**通式**：$\ce{RCOX}$（$\ce{X}$ = $\ce{Cl}$、$\ce{Br}$、$\ce{I}$）

##### (2) 常见酰卤

| 名称 | 结构 | 说明 |
|------|------|------|
| 乙酰氯 | $\ce{CH3COCl}$ | 无色液体，易水解 |
| 苯甲酰氯 | $\ce{C6H5COCl}$ | 无色液体，易水解 |

##### (3) 酰卤的性质

**化学性质**：

**水解反应**：

$$\ce{CH3COCl + H2O -> CH3COOH + HCl}$$

酰卤非常活泼，易与水、醇、氨反应。

**醇解反应**：

$$\ce{CH3COCl + C2H5OH -> CH3COOC2H5 + HCl}$$

**氨解反应**：

$$\ce{CH3COCl + NH3 -> CH3CONH2 + HCl}$$

#### 4. 酸酐

##### (1) 酸酐的结构

酸酐是两个羧酸分子脱去一分子水形成的化合物。

**通式**：$\ce{RCOOCOR'}$

##### (2) 常见酸酐

| 名称 | 结构 | 说明 |
|------|------|------|
| 乙酸酐 | $\ce{(CH3CO)2O}$ | 无色有刺激性的液体 |
| 邻苯二甲酸酐 | $\ce{C6H4(CO)2O}$ | 白色固体 |

##### (3) 酸酐的性质

**化学性质**：

**水解反应**：

$$\ce{(CH3CO)2O + H2O -> 2CH3COOH}$$

**醇解反应**：

$$\ce{(CH3CO)2O + C2H5OH -> CH3COOC2H5 + CH3COOH}$$

### 五、羧酸及其衍生物的相互转化

```
羧酸 <-> 酯 <-> 酰胺
   ↑         ↑       ↑
   |         |       |
酰卤 <-> 酸酐
```

**反应关系**：

- 羧酸 → 酯：酯化反应
- 酯 → 羧酸：水解反应
- 羧酸 → 酰胺：氨解反应
- 羧酸 → 酰卤：与 $\ce{PCl5}$ 反应
- 酰卤 → 酸酐：与羧酸钠反应
- 酸酐 → 酯：醇解反应

---

!!! tip "学习提示"
    - 羧酸具有酸性，能与碱、碳酸盐、金属反应。
    - 酯化反应是可逆反应，浓硫酸起催化和吸水作用。
    - 酯的碱性水解比酸性水解更完全。
    - 羧酸衍生物的活泼性：酰卤 > 酸酐 > 酯 > 酰胺。
