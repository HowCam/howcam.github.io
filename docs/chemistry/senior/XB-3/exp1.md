# 实验活动 1 乙酸乙酯的制备与性质

## 实验目的

1. 掌握乙酸乙酯的制备方法
2. 了解酯化反应的原理和特点
3. 学会用分液漏斗分离互不相溶的液体混合物
4. 探究乙酸乙酯的性质

## 实验原理

### 酯化反应

乙酸与乙醇在浓硫酸催化下发生酯化反应，生成乙酸乙酯和水：

$$\ce{CH3COOH + C2H5OH <=>[浓H2SO4, Δ] CH3COOC2H5 + H2O}$$

!!! note "酯化反应的特点"
    - 反应是可逆的
    - 浓硫酸起催化和吸水作用
    - 反应需要加热
    - 乙酸提供羟基，乙醇提供氢原子

### 乙酸乙酯的性质

- 无色有果香味的液体
- 密度小于水
- 难溶于水
- 可燃烧

## 实验用品

### 仪器

- 圆底烧瓶（100mL）
- 冷凝管
- 铁架台
- 酒精灯
- 分液漏斗
- 锥形瓶
- 导管
- 温度计

### 试剂

- 冰醋酸（无水乙酸）
- 乙醇（95%）
- 浓硫酸
- 饱和碳酸钠溶液
- 饱和食盐水
- 无水硫酸钠

## 实验步骤

### 1. 乙酸乙酯的制备

1. **组装装置**：按右图组装实验装置，检查装置气密性。

2. **混合反应物**：在干燥的圆底烧瓶中加入 6mL 乙醇，缓慢加入 4mL 浓硫酸，边加边振荡，冷却。

3. **加入乙酸**：再加入 6mL 冰醋酸，摇匀。

4. **加热反应**：
   - 先用小火加热，观察有无蒸汽产生
   - 正常后大火加热，使反应物保持沸腾约 5 分钟

5. **收集产物**：
   - 产物经冷凝管冷凝后流入锥形瓶
   - 观察锥形瓶中液体的分层现象

### 2. 分离与提纯

1. **饱和碳酸钠洗涤**：
   - 将锥形瓶中的混合物倒入分液漏斗
   - 加入 15mL 饱和碳酸钠溶液
   - 振荡，静置分层
   - 分液，下层从下口放出，上层从上口倒出

2. **饱和食盐水洗涤**：
   - 将上层液体放入另一分液漏斗
   - 加入 10mL 饱和食盐水
   - 振荡，静置，分液

3. **干燥**：
   - 将有机层（上层）放入干燥的锥形瓶
   - 加入适量无水硫酸钠，塞紧塞子，振荡
   - 放置约 15 分钟

4. **蒸馏**：
   - 将干燥后的有机层倒入蒸馏烧瓶
   - 加热蒸馏，收集 73-78°C 的馏分

### 3. 乙酸乙酯的性质探究

1. **观察外观**：观察乙酸乙酯的颜色、状态、气味

2. **溶解性实验**：
   - 取两支试管，各加入 2mL 水
   - 向第一支试管加入 1mL 乙酸乙酯，振荡，观察
   - 向第二支试管加入 1mL 乙酸乙酯和几滴紫色石蕊试液，振荡，观察

3. **燃烧实验**：
   - 取少量乙酸乙酯于蒸发皿中
   - 点燃，观察燃烧现象

## 注意事项

!!! warning "实验安全"
    1. 浓硫酸具有强腐蚀性，稀释时一定要将浓硫酸缓慢加入乙醇中，边加边振荡，切勿将乙醇加入浓硫酸中。
    
    2. 加热时要使用石棉网，防止暴沸。
    
    3. 反应混合物易溅出，加热时试管口不要对着人。
    
    4. 乙酸乙酯易燃，燃烧实验要注意安全。

## 实验现象与结论

| 实验 | 现象 | 结论 |
|------|------|------|
| 碳酸钠洗涤 | 有气泡产生，液体分层 | 乙酸乙酯中混有乙酸和乙醇 |
| 水溶解实验 | 乙酸乙酯浮在水面，下层呈紫色 | 乙酸乙酯密度小于水，不溶于水 |
| 石蕊试液实验 | 下层石蕊试液呈紫色 | 乙酸乙酯不显酸性 |
| 燃烧实验 | 火焰明亮，有黑烟 | 乙酸乙酯易燃，含碳量较高 |
