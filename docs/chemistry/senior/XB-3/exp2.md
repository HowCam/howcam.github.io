# 实验活动 2 有机化合物中常见官能团的检验

## 实验目的

1. 掌握常见有机化合物官能团的检验方法
2. 学会利用特征反应鉴别不同类型的有机化合物
3. 巩固有机化合物的性质知识

## 实验原理

### 1. 醛基的检验

#### (1) 银镜反应

醛基能被银氨溶液（托伦试剂）氧化，生成银镜：

$$\ce{RCHO + 2[Ag(NH3)2]OH -> RCOONH4 + 2Ag↓ + 3NH3 + H2O}$$

#### (2) 斐林反应

醛基能被新制氢氧化铜氧化，生成砖红色氧化亚铜沉淀：

$$\ce{RCHO + 2Cu(OH)2 -> RCOOH + Cu2O↓ + 2H2O}$$

### 2. 羧基的检验

羧基具有酸性，能与碳酸盐反应生成二氧化碳气体：

$$\ce{2RCOOH + Na2CO3 -> 2RCOONa + CO2↑ + H2O}$$

### 3. 酚羟基的检验

#### (1) 与溴水反应

苯酚与浓溴水反应，生成白色三溴苯酚沉淀：

$$\ce{C6H5OH + 3Br2 -> C6H2Br3OH↓ + 3HBr}$$

#### (2) 与 $\ce{FeCl3}$ 反应

苯酚与 $\ce{FeCl3}$ 溶液反应，显紫色：

$$\ce{6C6H5OH + FeCl3 -> [Fe(OC6H5)6]^{3-} + 6H+ + 3Cl-}$$

### 4. 碳碳双键的检验

含有碳碳双键的有机化合物能使溴水或高锰酸钾溶液褪色：

$$\ce{RCH=CH2 + Br2 -> RCHBr-CH2Br}$$

$$\ce{3CH2=CH2 + 2KMnO4 + 4H2O -> 3HOCH2-CH2OH + 2MnO2 + 2KOH}$$

### 5. 淀粉的检验

淀粉遇碘单质变蓝：

$$\ce{淀粉 + I2 -> 蓝色络合物}$$

### 6. 蛋白质的检验

#### (1) 颜色反应

- 蛋白质与茚三酮反应，生成蓝紫色化合物
- 蛋白质与浓硝酸反应，生成黄色沉淀（含苯环的蛋白质）

#### (2) 双缩脲反应

蛋白质与双缩脲试剂反应，生成紫色络合物。

## 实验步骤

### 1. 醛基的检验

#### (1) 银镜反应

1. 洁净试管：取一支洁净的试管，用热的 $\ce{NaOH}$ 溶液洗涤，再用蒸馏水洗净。

2. 加试剂：加入 2mL 银氨溶液，滴入 3-4 滴乙醛溶液。

3. 水浴加热：将试管放在热水浴中加热，观察现象。

4. 清洗：实验后立即加入稀硝酸洗涤，清除附着的银镜。

#### (2) 斐林反应

1. 取两支试管，各加入 2mL 新制 $\ce{Cu(OH)2}$。

2. 分别加入 5-6 滴乙醛溶液和葡萄糖溶液。

3. 加热煮沸，观察现象。

### 2. 羧基的检验

1. 取两支试管，各加入 2mL 乙酸溶液。

2. 分别加入 1mL 饱和 $\ce{Na2CO3}$ 溶液。

3. 观察现象。

### 3. 酚羟基的检验

#### (1) 与溴水反应

1. 取一支试管，加入 2mL 苯酚溶液。

2. 滴加浓溴水 2-3 滴，观察现象。

#### (2) 与 $\ce{FeCl3}$ 反应

1. 取两支试管，分别加入 2mL 苯酚溶液和乙醇。

2. 各滴加 2-3 滴 $\ce{FeCl3}$ 溶液。

3. 观察现象。

### 4. 碳碳双键的检验

1. 取两支试管，各加入 2mL 溴水。

2. 分别加入 1mL 植物油和乙醇。

3. 振荡，观察现象。

### 5. 淀粉的检验

1. 取两支试管，各加入 2mL 淀粉溶液。

2. 向第一支试管滴加碘酒 2-3 滴。

3. 向第二支试管滴加碘酒 2-3 滴，然后加热煮沸，再冷却观察。

### 6. 蛋白质的检验

#### (1) 颜色反应

1. 取两支试管，各加入 2mL 鸡蛋清溶液。

2. 向第一支试管滴加茚三酮溶液 2-3 滴，加热，观察。

3. 向第二支试管滴加浓硝酸 1mL，观察。

#### (2) 双缩脲反应

1. 取一支试管，加入 2mL 鸡蛋清溶液。

2. 加入 1mL $\ce{NaOH}$ 溶液和 2-3 滴 $\ce{CuSO4}$ 溶液。

3. 振荡，观察现象。

## 注意事项

!!! warning "实验安全"
    1. 银氨溶液必须现用现配，久置会生成易爆炸的雷酸银。
    
    2. 实验后应立即用稀硝酸清洗试管，防止银镜附着在试管壁上。
    
    3. 苯酚有腐蚀性，溅到皮肤上应立即用酒精冲洗。
    
    4. 浓硝酸有强腐蚀性，操作要小心。
