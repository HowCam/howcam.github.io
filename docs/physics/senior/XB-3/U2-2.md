# U2-2 液体

## 液体

### 液体的微观结构

液体的微观结构特点：

- 分子排列紧密度接近固体（分子间距约 $10^{-10}$ m）
- 分子不是在固定位置附近振动，而是在液体中移动
- 分子振动范围比固体大，可以移动
- 分子间存在相互作用力，但比固体弱

!!! note "液体与固体的区别"
    - 固体分子排列有序，液体分子排列无序
    - 固体分子在固定位置附近振动，液体分子可以移动
    - 固体有固定形状，液体无固定形状（但有确定体积）

### 液体的表面性质

#### 表面张力

液面上任意一条线两侧的液体相互作用力垂直于该线、与液面相切、大小与线长成正比，这就是**表面张力**。

!!! note "表面张力的定义"
    表面张力是液体表面层由于分子引力不均衡而产生的沿表面切线方向使液面收缩的力。

表面张力的公式：

$$\gamma = \frac{F}{L}$$

其中 $F$ 为表面张力，$L$ 为液面周线的长度，$\gamma$ 为表面张力系数，单位 $\text{N/m}$。

!!! note "表面张力的作用"
    表面张力使液面收缩至最小面积。例如，荷叶上的露珠呈球形，是因为体积一定时球形面积最小。

!!! tip "表面张力系数的影响因素"
    - 与液体的性质有关（密度越大，表面张力系数越大）
    - 与温度有关：温度越高，表面张力系数越小
    - 与杂质有关：加入杂质可能改变表面张力

#### 浸润和不浸润

- **浸润**：液体附着在固体表面的现象（如水浸润玻璃）
- **不浸润**：液体不附着在固体表面的现象（如水银不浸润玻璃）

!!! note "浸润的原因"
    当液体和固体分子间引力大于液体分子间引力时，液体浸润固体。

#### 毛细现象

浸润液体在细管中上升、不浸润液体在细管中下降的现象叫做**毛细现象**。

!!! note "毛细现象的产生"
    毛细现象的产生与表面张力和浸润都有关系。浸润液体在细管中上升时，表面张力沿管壁向上拉拽液体。

!!! example "毛细现象举例"
    - 植物茎内的导管输送水分
    - 毛巾吸汗
    - 砖块吸水
    - 灯芯吸油

### 液晶

**液晶**是一种介于液体和晶体之间的物质状态。它既具有液体的流动性，又具有晶体的光学各向异性。

!!! note "液晶的特性"
    - 具有液体的流动性（可以流动）
    - 具有晶体的光学各向异性（对光有双折射现象）
    - 对温度变化敏感
    - 对电磁场变化敏感

!!! example "液晶的应用"
    - 电子显示（计算器、电子手表、手机屏幕、电视机）
    - 温度计（利用液晶颜色随温度变化的特性）
    - 生物膜结构模拟

        解答：√

    2. 判断：水浸润玻璃，水银不浸润玻璃。（    ）
    
        解答：√

    3. 简述浸润和毛细现象的关系。
    
        解答：浸润是液体附着在固体表面的现象。毛细现象是浸润液体在细管中上升（或不浸润液体下降）的现象。毛细现象的产生需要浸润液体和细管两个条件。

    4. 为什么荷叶上的露珠呈球形？
    
        解答：由于表面张力的作用，液面总是收缩至最小面积。在体积一定时，球形的表面积最小，因此露珠呈球形。

    5. 液晶有哪些主要特性？有哪些应用？
    
        解答：液晶特性：流动性、光学各向异性、对温度和电磁场敏感。应用：电子显示器件、温度计等。
