# U2-5 气体的等容变化和等压变化

## 气体的等容变化和等压变化

### 气体状态参量

描述气体状态的物理量叫做**状态参量**。

| 参量 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 体积 | $V$ | $\text{m}^3$ | 气体分子所到达的空间体积 |
| 压强 | $p$ | $\text{Pa}$（帕斯卡） | 气体作用在容器壁单位面积上的力 |
| 温度 | $T$ | $\text{K}$（热力学温度） | 分子平均动能的标志 |

!!! note "气体压强的微观解释"
    气体压强是大量气体分子无规则运动撞击容器壁产生的。压强大小取决于分子密度（单位体积内分子数）和分子的平均动能。

### 气体的等容变化

**等容变化**：一定质量的气体，体积保持不变。

查理定律（等容变化定律）：

$$\frac{p_1}{T_1} = \frac{p_2}{T_2}$$

或

$$\frac{p}{T} = C \quad \text{（恒量）}$$

!!! note "查理定律"
    法国物理学家查理通过实验发现：一定质量的气体在体积不变时，压强与热力学温度成正比。

### 气体的等压变化

**等压变化**：一定质量的气体，压强保持不变。

盖-吕萨克定律（等压变化定律）：

$$\frac{V_1}{T_1} = \frac{V_2}{T_2}$$

或

$$\frac{V}{T} = C \quad \text{（恒量）}$$

!!! note "盖-吕萨克定律"
    法国化学家盖-吕萨克通过实验发现：一定质量的气体在压强不变时，体积与热力学温度成正比。

### 理想气体状态方程

**理想气体**是一种理想化模型：
- 分子本身大小忽略不计
- 分子间作用力忽略不计
- 分子与器壁碰撞为完全弹性碰撞

!!! note "理想气体状态方程"
    $$\frac{p_1V_1}{T_1} = \frac{p_2V_2}{T_2} = C \quad \text{（恒量）}$$
    
    或
    
    $$pV = nRT$$
    
    其中 $R = 8.31 \text{ J/(mol·K)}$ 为气体常数，$n$ 为物质的量。

### 道尔顿分压定律

在混合气体中，每种气体对容器壁产生的压强叫做**分压**。

!!! note "道尔顿分压定律"
    混合气体的总压强等于各组分气体的分压强之和：
    
    $$p = p_1 + p_2 + p_3 + \cdots$$

!!! tip "分压的计算"
    对于理想气体，分压可按各自单独存在时的压强计算：
    $$p_i = n_iRT/V$$

???+ question "自我评价"

    1. 判断：气体等容变化时，压强与热力学温度成正比。（    ）
    
        解答：√

    2. 判断：气体等压变化时，体积与摄氏温度成正比。（    ）
    
        解答：×。气体等压变化时，体积与热力学温度成正比。

    3. 计算：某理想气体，压强 $p_1 = 1.0 \times 10^5 \text{ Pa}$，体积 $V_1 = 2.0 \text{ L}$，温度 $T_1 = 300 \text{ K}$。等压膨胀至体积 $V_2 = 3.0 \text{ L}$，求温度 $T_2$。
    
        解答：由等压过程 $\frac{V_1}{T_1} = \frac{V_2}{T_2}$ 得：
        $$T_2 = \frac{V_2}{V_1} \times T_1 = \frac{3.0}{2.0} \times 300 = 450 \text{ K}$$

    4. 计算：某容器中装有理想气体，测得压强为 $p = 2.0 \times 10^5 \text{ Pa}$，体积为 $V = 5.0 \text{ L}$，温度为 $T = 300 \text{ K}$。求气体的物质的量 $n$。
    
        解答：由 $pV = nRT$ 得：
        $$n = \frac{pV}{RT} = \frac{2.0 \times 10^5 \times 5.0 \times 10^{-3}}{8.31 \times 300} \approx 0.40 \text{ mol}$$

    5. 解释为什么气体压强与容器形状无关。
    
        解答：气体压强是由大量气体分子频繁撞击容器壁产生的。从微观角度看，压强大小只取决于单位体积内分子数（分子密度）和分子的平均动能，与容器的形状无关。
