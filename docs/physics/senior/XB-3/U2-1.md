# U2-1 固体和固体材料

## 固体和固体材料

### 晶体和非晶体

固体分为**晶体**和**非晶体**两大类。

| 特征 | 晶体 | 非晶体 |
|------|------|--------|
| 外观 | 具有规则的几何形状 | 没有规则的几何形状 |
| 物理性质 | 具有各向异性 | 具有各向同性 |
| 熔点 | 有确定的熔点 | 没有确定的熔点 |

!!! note "晶体的分类"
    晶体分为**单晶体**和**多晶体**：
    - **单晶体**：由一个晶粒组成，具有规则外形（如食盐晶体、冰）
    - **多晶体**：由多个晶粒组成，没有规则外形（如金属），但仍具有确定的熔点

!!! example "常见的晶体"
    - **单晶体**：食盐、云母、冰、金刚石、单晶硅
    - **多晶体**：铁、铜、铝等金属，多数岩石

!!! example "常见的非晶体"
    - 玻璃、松香、沥青、橡胶

### 晶体的微观结构

晶体的宏观性质由其微观结构决定：

- 分子、原子或离子按一定规律排列形成**空间点阵**（晶格）
- 粒子在平衡位置附近做微小的振动
- 不同方向上粒子排列规律不同 → 各向异性

!!! note "各向异性的微观解释"
    晶体在不同方向上粒子排列规律不同，因此沿不同方向的光学性质、力学性质、电学性质等也不同。例如，云母片沿不同方向撕开的难度不同。

### 固体材料

常见的固体材料可分为：

#### 金属材料

- **特点**：具有良好的导电性、导热性和延展性
- **应用**：建筑、机械、导线等

#### 无机非金属材料

- **陶瓷**：硬度高、耐高温、绝缘性好
- **玻璃**：透明、硬而脆
- **水泥**：建筑材料

#### 高分子材料

- **塑料**：轻便、成本低
- **橡胶**：弹性好
- **纤维**：强度高、质轻

???+ question "自我评价"

    1. 判断：晶体都具有规则的几何外形。（    ）
    
        解答：×。多晶体没有规则的几何外形，单晶体才具有规则的几何外形。

    2. 判断：晶体具有各向异性，非晶体具有各向同性。（    ）
    
        解答：√

    3. 为什么金属晶体没有规则的几何外形，但仍然属于晶体？
    
        解答：金属是多晶体，由大量晶粒无规则排列组成。虽然整体没有规则外形，但每个晶粒内部原子排列有序，具有确定的熔点，属于晶体。

    4. 解释晶体为什么具有确定的熔点。
    
        解答：晶体的微观结构是空间点阵，粒子在固定位置附近振动。当温度升高到熔点时，粒子获得足够能量克服相互作用力，打破有序排列，开始熔化。在熔化过程中温度不变，直到完全熔化。
