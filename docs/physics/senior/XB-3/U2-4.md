# U2-4 实验：探究气体等温变化的规律

## 实验：探究气体等温变化的规律

### 实验目的

探究气体在温度不变的条件下，压强与体积的关系。

### 实验原理

保持气体温度不变，改变气体体积，测量对应的压强，探究 $p$ 与 $V$ 的关系。

### 实验装置

实验装置包括：
- **注射器**：改变气体体积
- **压强传感器**：测量气体压强
- **温度传感器**：监测气体温度（保持不变）
- **数据采集器**：记录数据

### 实验步骤

1. **检查装置气密性**：将注射器活塞推至最大刻度，用橡皮帽封住出气口，检验是否漏气

2. **调节温度**：将装置放入温水浴中，调节温度至室温并保持稳定

3. **测量初始状态**：记录初始体积 $V_1$ 和对应压强 $p_1$

4. **改变体积**：逐渐向下拉活塞，每次改变一定体积

5. **记录数据**：待气体稳定后，记录各组 $(p, V)$ 数据

6. **数据分析**：绘制 $p-V$ 图像和 $p-\frac{1}{V}$ 图像

### 数据记录与处理

| 实验次数 | 体积 $V$ (mL) | 压强 $p$ (×$10^5$ Pa) | $\frac{1}{V}$ (mL$^{-1}$) |
|----------|---------------|----------------------|--------------------------|
| 1 | 20 | $p_1$ | $1/V_1$ |
| 2 | 25 | $p_2$ | $1/V_2$ |
| 3 | 30 | $p_3$ | $1/V_3$ |
| ... | ... | ... | ... |

### 实验结论

实验表明：**温度不变时，一定质量气体的压强与体积成反比**

$$pV = C \quad \text{（恒量）}$$

或

$$p_1V_1 = p_2V_2$$

这就是**玻意耳定律**（Boyle's Law）。

!!! note "玻意耳定律"
    英国化学家玻意耳于1662年通过实验发现：当气体的温度保持不变时，气体的压强与体积的乘积是一个常数。

### 注意事项

- 实验中应保持温度不变（等温条件）
- 注射器活塞应润滑良好，减少摩擦
- 读取数据时应等待气体稳定后再记录
- 实验数据应多次测量取平均值

???+ question "思考题"

    1. 为什么实验中要保持温度不变？
    
        解答：玻意耳定律的条件是温度不变。如果温度变化，气体分子的平均动能会改变，影响实验结果。

    2. 如果实验中发现 $pV$ 不为常数，可能的原因有哪些？
    
        解答：（1）温度不稳定；（2）气体泄漏；（3）活塞摩擦力影响体积读数；（4）压强传感器或注射器刻度不准确。

    3. 绘制 $p-\frac{1}{V}$ 图像可以得到什么信息？
    
        解答：如果 $pV = C$ 成立，则 $p = C \cdot \frac{1}{V}$，图像为过原点的直线，直线斜率即为常数 $C$。通过图像是否为直线可以判断是否符合玻意耳定律。
