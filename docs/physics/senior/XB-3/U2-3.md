# U2-3 温度和温标

## 温度和温标

### 温度

温度是表示物体冷热程度的物理量。从分子动理论的观点看：

!!! note "温度的本质"
    **温度是物体分子平均动能的标志。** 温度越高，分子平均动能越大，分子热运动越剧烈。

### 温标

温标是温度的标定方法。常用的温标有：

| 温标 | 零点设定 | 单位 | 每度大小 |
|------|----------|------|----------|
| 摄氏温标 | 纯冰水混合物的温度为0℃ | ℃ | 与热力学温标相同 |
| 热力学温标 | -273.15℃为零点 | K（开尔文） | 国际单位制基本单位 |
| 华氏温标 | 氯化铵和冰水混合物的温度为0°F | ℉ | 与摄氏温标不同 |

### 热力学温标

**热力学温标**是国际单位制（SI）中表示温度的基本单位。

热力学温标与摄氏温标的关系：

$$T = t + 273.15 \text{ K}$$

其中 $T$ 为热力学温度，$t$ 为摄氏温度。

!!! note "绝对零度"
    热力学温标的零度（绝对零度，0 K）是宇宙中温度的下限。一切分子热运动停止的温度，但实际上任何实际气体在到达绝对零度前就已液化或固化。

!!! tip "常用温度换算"
    - 水的沸点：$100^\circ\text{C} = 373.15 \text{ K}$
    - 冰的熔点：$0^\circ\text{C} = 273.15 \text{ K}$
    - 人体正常体温：约 $36.5^\circ\text{C} = 309.65 \text{ K}$

### 温标建立的原则

建立温标需要考虑三个要素：

1. **选择测温物质**：如汞、酒精、气体等
2. **选择测温属性**：如体积、压强、电阻等
3. **固定点**：选择标准温度点（如水的沸点、冰的熔点）

!!! note "理想气体温标"
    理想气体温标利用气体压强或体积随温度变化的线性关系定义温度，与气体种类无关，是一种科学的温标。

### 热力学第一定律

温度、压强、体积是描述气体状态的三个基本参量，它们之间的关系由**理想气体状态方程**决定。

    2. 计算：将 $27^\circ\text{C}$ 转换为热力学温度。

    4. 为什么热力学温标是国际单位制的基本单位？
    
        解答：热力学温标的零点定义在绝对零度（-273.15℃），不依赖于任何具体物质的性质，是一种理论上最严格的温标。热力学温度在物理学中应用广泛，特别是在热力学计算中。

    5. 简述建立温标需要考虑的三个要素。
    
        解答：（1）选择测温物质（如汞、酒精）；（2）选择测温属性（如体积、压强）；（3）固定标准温度点（如水的沸点、冰的熔点）。
