# 导数

## 基本初等函数导数公式

### 基础公式

| 函数 $f(x)$ | 导数 $f'(x)$ | 备注 |
|:----------:|:-----------:|:----:|
| $C$（常数）| $0$ | |
| $x^n$ | $nx^{n-1}$ | $n\in\mathbb{R}$ |
| $\sin x$ | $\cos x$ | |
| $\cos x$ | $-\sin x$ | |
| $e^x$ | $e^x$ | |
| $a^x$ | $a^x\ln a$ | $a>0,\ a\neq1$ |
| $\ln x$ | $\dfrac{1}{x}$ | $x>0$ |
| $\log_a x$ | $\dfrac{1}{x\ln a}$ | $a>0,\ a\neq1$ |

### 扩展公式

| 函数 | 导数 | 备注 |
|:----:|:----:|:----:|
| $\tan x$ | $\dfrac{1}{\cos^2 x}$ | $=1+\tan^2 x$ |
| $\cot x$ | $-\dfrac{1}{\sin^2 x}$ | $=-(1+\cot^2 x)$ |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^2}}$ | |
| $\arccos x$ | $-\dfrac{1}{\sqrt{1-x^2}}$ | |
| $\arctan x$ | $\dfrac{1}{1+x^2}$ | |
| $\ln\vert x\vert$ | $\dfrac{1}{x}$ | $x\neq0$ 统一形式 |

!!! note "易错点"
    $(\ln\vert x\vert)' = \dfrac{1}{x}$ 对 $x<0$ 也成立。

## 导数的运算法则

### 四则运算

设 $u=u(x)$，$v=v(x)$ 均可导：

- **加法** $(u\pm v)' = u' \pm v'$
- **乘法** $(uv)' = u'v + uv'$
- **数乘** $(Cu)' = Cu'$
- **除法** $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$，$v\neq0$

!!! warning "注意"
    $(uv)' \neq u'v'$，乘法法则不要漏项。

### 复合函数求导（链式法则）

**核心**：从外到内，逐层求导，依次相乘。

$$y = f[g(x)] \quad \Longrightarrow \quad y' = f'[g(x)] \cdot g'(x)$$

**步骤**：
1. 识别外层函数 $f$，内层函数 $g$
2. 分别求导
3. 内外导数相乘

**例**：$y = e^{\sin(3x)}$

| 层次 | 函数 | 导数 |
|:----:|:----:|:-----|
| 外层 | $e^{u}$ | $e^{u}$ |
| 中层 | $\sin(3x)$ | $\cos(3x)\cdot 3$ |
| 内层 | $3x$ | $3$ |

$$y' = e^{\sin(3x)}\cdot\cos(3x)\cdot 3$$

### 隐函数求导

若方程 $F(x,y)=0$ 确定了 $y$ 是 $x$ 的函数：

1. 两边对 $x$ 求导（**把 $y$ 当作 $x$ 的函数**）
2. 解出 $y'$（视 $y'$ 为未知数）

## 导数与单调性

### 核心定理

设 $f(x)$ 在区间 $I$ 上可导：

- $f'(x) > 0 \Longleftrightarrow f(x)$ 在 $I$ 上**单调递增**
- $f'(x) < 0 \Longleftrightarrow f(x)$ 在 $I$ 上**单调递减**
- $f'(x)=0$ 是极值点的**必要条件**，非充分条件

!!! note "反例"
    $f(x)=x^3$，$f'(0)=0$，但 $x=0$ 不是极值点（单调递增）。

### 分析流程

```
求定义域 → 求导 f'(x) → 解 f'(x)=0 → 划分区间 → 判断符号 → 得出结论
```

### 含参单调性讨论

根据参数取值范围讨论：

1. $f'(x) > 0$ **恒成立** → 整个区间递增
2. $f'(x) < 0$ **恒成立** → 整个区间递减
3. 混合符号 → 先解 $f'(x)=0$，再判断各区间符号

## 极值与最值

### 极值判断

**第一充分条件**（最常用）：

| 左侧 $f'(x)$ | 右侧 $f'(x)$ | 结论 |
|:-----------:|:-----------:|:----:|
| $>0$ | $<0$ | **极大值点** |
| $<0$ | $>0$ | **极小值点** |
| 同号 | 同号 | 不是极值点 |

**第二充分条件**：

$$f'(x_0)=0 \text{ 且 } f''(x_0)\neq0 \Rightarrow \begin{cases} f''(x_0)<0 &\Rightarrow \text{ 极大值} \\ f''(x_0)>0 &\Rightarrow \text{ 极小值} \end{cases}$$

!!! warning "注意"
    $f''(x_0)=0$ 时第二充分条件失效，需返回第一充分条件判断。

### 最值

闭区间 $[a,b]$ 上的连续函数必取最大、最小值。

```
求 f'(x)=0 的根 → 算端点值 f(a), f(b) → 比较大小 → 得出最值
```

## 三次函数专题

三次函数 $f(x)=ax^3+bx^2+cx+d\ (a\neq0)$。

### 导数特征

$$f'(x) = 3ax^2+2bx+c$$

$f'(x)=0$ 最多两实根，对应函数最多两个极值点。

### 常见结论

- **一个极值点**：$\Delta \leqslant 0$ 时，$f(x)$ 在 $\mathbb{R}$ 上单调
- **两个极值点**：$\Delta > 0$ 时，$f(x)$ 先增后减再增（或反过来）
- **极值点横坐标之和**：$-\dfrac{2b}{3a}$
- **对称性**：关于拐点 $\left(-\dfrac{b}{3a},\ f\left(-\dfrac{b}{3a}\right)\right)$ 中心对称

## 导数的几何意义——切线方程

### 基本公式

曲线 $y=f(x)$ 在点 $P(x_0,\ f(x_0))$ 处：

- **切线斜率**：$k = f'(x_0)$
- **法线斜率**：$k_{\text{法}} = -\dfrac{1}{f'(x_0)}$（$f'(x_0)\neq0$ 时）

### 方程

- **切线**：$y - f(x_0) = f'(x_0)(x - x_0)$
- **法线**：$y - f(x_0) = -\dfrac{1}{f'(x_0)}(x - x_0)$

### 过某点的切线

设切点为 $(t,\ f(t))$，列方程后代入已知点坐标，解出 $t$。

!!! warning "注意"
    曲线外一点未必有切线，需检验解的合理性。

## 方程有解问题

### 研究思路

将方程 $f(x)=0$ 有解问题转化为函数 $y=f(x)$ 与 $x$ 轴的交点问题。

**核心工具**：

| 工具 | 作用 |
|:----:|:-----|
| 单调性 | 若 $f(x)$ 严格单调，则 $f(x)=0$ 至多一解 |
| 连续性 | $f(a)\cdot f(b)<0$ 时，$(a,b)$ 内必有一解 |
| 极值 | 结合最值判断交点个数 |

### 常见题型

| 题型 | 处理方法 |
|:-----|:---------|
| 讨论方程解的个数 | 结合极值点、端点值分析 $f(x)$ 图像 |
| 已知有解求参数范围 | 转化为 $f(x)$ 的值域与 $0$ 的关系 |
| 证明唯一解 | 单调性 + 介值定理 |

## 恒成立问题

### 核心思路

**不等式恒成立 $\Longleftrightarrow$ 求最值**

$$f(x) \geqslant 0\ \forall x\in I \quad \Longleftrightarrow \quad \min_{x\in I} f(x) \geqslant 0$$

$$f(x) > g(x)\ \forall x\in I \quad \Longleftrightarrow \quad \min_{x\in I}[f(x)-g(x)] > 0$$

### 参数分离

将参数 $\lambda$ 单独分离到一边：

$$f(x,\ \lambda) \geqslant 0 \quad \Longleftrightarrow \quad \lambda \geqslant G(x) \text{ 或 } \lambda \leqslant G(x)$$

然后求 $G(x)$ 的最值，得到 $\lambda$ 的范围。

## 零点问题

### 零点存在定理

若 $f(x)$ 在 $[a,b]$ 上**连续**，且 $f(a)\cdot f(b)<0$，则 $\exists\ x_0\in(a,b)$ 使 $f(x_0)=0$。

### 研究方法

```
零点个数 → 单调性 + 极值点符号 + 端点值
零点位置 → 逐步缩小区间
零点个数与参数 → 极值点随参数变化
```

### 极值点偏移问题

**核心解法**：构造**差函数**

$$F(x) = f(x) - f(x_0 + x_1 - x)$$

分析 $F(x)$ 的单调性，得到 $x_1+x_2$ 的关系。

## 常用解题方法

### 分离变量

将参数与变量分开，分别置于不等式两侧。

**适用场景**：参数是一次或可分离时。

### 同构

**本质**：多个代数式具有**相同的结构特征**，可构造同一个函数统一处理。

| 形式 | 同构函数 |
|:-----|:---------|
| $xe^x$ 类 | $F(x)=xe^x$ |
| $\dfrac{e^x}{x}$ 类 | $F(x)=\dfrac{e^x}{x}$ |
| $x\ln x$ 类 | $F(x)=x\ln x$ |
| $\dfrac{\ln x}{x}$ 类 | $F(x)=\dfrac{\ln x}{x}$ |

### 端点效应

在含参不等式证明中，**端点值**往往决定最值点或极值点的位置。

## 解题步骤模板

面对任何一道导数题，按以下流程走：

1. **写定义域**（容易被忽略！）
2. **求导** $f'(x)$
3. **解方程** $f'(x)=0$（分析判别式）
4. **列表格**（临界点 + 符号判断）
5. **得结论**（单调性、极值、最值）
6. **回代原问题**（切线、零点、不等式证明）

!!! tip "压轴题技巧"
    - 恒成立问题优先考虑**分离变量**
    - 复杂不等式优先**移项构造新函数**
    - 同构结构出现时，构造**统一函数**
    - 多变量问题用**主元法**（固定其他，只变一个）
    - 极值点偏移用**差函数**技巧
