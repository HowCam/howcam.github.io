    第1章 遗传因子的发现¶

    1.2 孟德尔的豌豆杂交实验（二）¶

    一、两对相对性状的杂交实验¶

    1. 两对相对性状：豌豆的子叶颜色（黄色与绿色）和种子形状（圆粒与皱粒）。

    2. 亲本选择：纯种黄色圆粒（YYRR）× 纯种绿色皱粒（yyrr）。

    3. \(F_1\)结果：全部为黄色圆粒，说明黄色对绿色为显性，圆粒对皱粒为显性。

    4. \(F_1\)自交（\(F_2\)）结果：

      • 黄色圆粒：315粒

      • 黄色皱粒：108粒

      • 绿色圆粒：101粒

      • 绿色皱粒：32粒

      • 比例约为 9:3:3:1

    关键比例

    • 9:3:3:1 是两对相对性状杂交实验中 \(F_2\) 的性状分离比

    • 每一对性状仍遵循 3:1 的分离比

    出现 9:3:3:1 的必要条件

    1. 两对等位基因分别位于 两对同源染色体 上
    2. 每对等位基因的分离互不干扰（遵循分离定律）
    3. \(F_1\) 为 双杂合个体（YyRr）
    4. 完全显性（显性基因对隐性基因完全显性）
    5. 各种配子的成活率相同
    6. 雌雄配子随机结合
    7. 各种基因型的成活率相同

    二、对自由组合现象的解释¶

    1. 假说内容：\(F_1\) 在形成配子时，每对遗传因子彼此分离，不同对的遗传因子可以自由组合。

    2. \(F_1\) 产生的配子：YyRr 产生 YR、Yr、yR、yr 四种配子，比例为 \(1:1:1:1\)。

      配子类型 比例
      YR 1/4
      Yr 1/4
      yR 1/4
      yr 1/4

    3. 配子的结合：雌雄配子的结合是随机的。

    4. 子代结果：形成 16 种组合，9 种基因型，4 种表现型，表现型比例为 \(9:3:3:1\)。

    5. 遗传图解：\(F_1\)（YyRr）自交，\(F_2\) 中黄色圆粒 : 黄色皱粒 : 绿色圆粒 : 绿色皱粒 \(=9:3:3:1\)。

    6. 测交实验验证：

      • \(F_1\)（YyRr）× 隐性纯合（必要）（yyrr）

      • 预期结果：黄色圆粒 : 黄色皱粒 : 绿色圆粒 : 绿色皱粒 = 1:1:1:1

      • 实验结果与预期相符，验证了假说的正确性。

      • 测交实验必须有隐性纯合子，Yyrr × yyRr 无法验证自由组合定律。

    验证自由组合定律的方法

    方法 操作 预期结果（双杂合自交） 意义
    自交法 \(F_1\) 自交 9:3:3:1 直接验证 \(F_2\) 性状分离比
    测交法 \(F_1\) × 隐性纯合子 1:1:1:1 验证配子类型及比例
    花粉鉴定法 观察 \(F_1\) 花粉的性状 1:1:1:1 直接观察配子类型
    单倍体育种法 花粉离体培养 验证基因型种类 从配子角度直接验证

    三、孟德尔第二定律（自由组合定律）¶

    1. 自由组合定律（孟德尔第二定律）：

      • 控制不同性状的遗传因子在形成配子时自由组合

      • 时间：有性生殖的生物形成配子时

      • 实质：等位基因分离，非同源染色体上的非等位基因自由组合

    2. 分离定律与自由组合定律的关系：

      • 分离定律是自由组合定律的基础

      • 在分析多对相对性状时，应逐对分析，再组合

    解题技巧

    求解自由组合问题的基本步骤：

    1. 先将每对性状单独分析

    2. 再将各对性状的分析结果组合（概率相乘）

    四、孟德尔实验方法的启示¶

    1. 孟德尔获得成功的原因：

      1. 正确选用实验材料（豌豆）

      2. 合理运用数学统计方法（统计分析 \(F_2\) 的性状分离比）

      3. 创新运用假说—演绎法

      4. 科学设计实验程序（先研究一对，再研究多对）

    2. 假说—演绎法：

      • 提出问题：观察实验，发现问题

      • 提出假说：解释现象，作出假设

      • 演绎推理：根据假说，推测结果

      • 实验验证：实施实验，验证预测

      • 得出结论：总结规律，形成理论

    五、知识点总结¶

    定律 研究对象 本质
    分离定律 一对相对性状 等位基因分离
    自由组合定律 两对及两对以上相对性状 等位基因分离，非等位基因自由组合

    六、\(9:3:3:1\) 的变式¶

    两对等位基因独立遗传时，\(F_2\) 的表现型比例可能出现多种变式，其本质仍是 \(9:3:3:1\) 的不同组合：

    变式比例 合并方式 常见原因
    \(9:7\) \(9:(3+3+1)\) 两对基因互补，同时含两种显性基因时才表现显性性状
    \(9:6:1\) \(9:(3+3):1\) 两种显性基因单独作用效果相同，同时存在时效果叠加
    \(15:1\) \((9+3+3):1\) 只要含有显性基因就表现显性性状（重复作用）
    \(9:3:4\) \(9:3:(3+1)\) 一对隐性基因对另一对基因起上位作用
    \(13:3\) \((9+3+1):3\) 一对显性基因抑制另一对基因的表达
    \(12:3:1\) \((9+3):3:1\) 显性上位作用

    变式题的判断依据

    只要题目说明两对等位基因独立遗传（位于非同源染色体上），无论表现型比例如何变化，都遵循自由组合定律。解题时可先将 \(F_2\) 比例拆分，还原为 \(9:3:3:1\) 的基本组合。

    七、多对相对性状的遗传¶

    若 \(n\) 对等位基因独立遗传，且每对基因都表现为完全显性：

    项目 数量
    \(F_1\) 产生的配子种类 \(2^{n}\)
    雌雄配子的组合方式 \(4^{n}\)
    \(F_2\) 的基因型种类 \(3^{n}\)
    \(F_2\) 的表现型种类 \(2^{n}\)
    \(F_2\) 的表现型比例 \((3:1)^{n}\)
    • 例如，AaBbCc × AaBbCc，\(F_1\) 产生 \(2^{3}=8\) 种配子，\(F_2\) 有 \(3^{3}=27\) 种基因型、\(2^{3}=8\) 种表现型，表现型比例为 \((3:1)^{3}=27:9:9:9:3:3:3:1\)。
    • 计算时遵循“先分后合”的原则：先逐对分析，再相乘组合。

    八、自由组合定律的适用范围¶

    • 适用于真核生物的有性生殖过程；
    • 适用于控制不同性状的等位基因位于非同源染色体上的情况；
    • 若两对等位基因位于同一对同源染色体上，则不遵循自由组合定律，而表现为连锁与互换；
    • 不适用于原核生物、病毒和细胞质遗传。

    九、孟德尔遗传规律的应用¶

    杂交育种

    • 小麦的抗倒伏（D）对易倒伏（d）为显性，易染条锈病（T）对抗条锈病（t）为显性。
    • 现有抗倒伏但易染条锈病的品种（DDTT）和易倒伏但抗条锈病的品种（ddtt）。
    • 将两者杂交，\(F_2\) 中会出现既抗倒伏又抗条锈病的新类型（DDtt、Ddtt），经过选择和培育，可获得纯种 DDtt。

    医学实践

    • 白化病由隐性基因（a）控制。若患者的双亲表型正常，则双亲一定都是杂合子（Aa），其后代患病概率为 \(\dfrac{1}{4}\)。
    • 根据分离定律和自由组合定律，可以对遗传病在后代中的患病概率作出科学推断，为遗传咨询提供依据。

    概率计算示例

    • AaBb × AaBb 的后代中，基因型为 AABB 的概率为 \(\dfrac{1}{4}\times\dfrac{1}{4}=\dfrac{1}{16}\)；
    • 表现型为双显性的概率为 \(\dfrac{3}{4}\times\dfrac{3}{4}=\dfrac{9}{16}\)。
