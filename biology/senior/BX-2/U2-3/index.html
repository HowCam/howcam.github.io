    第2章 基因和染色体的关系¶

    2.3 伴性遗传¶

    一、伴性遗传的概念¶

    • 人类的红绿色盲、抗维生素 D 佝偻病的遗传表现与果蝇眼睛颜色的遗传非常相似。
    • 决定这些性状的基因位于性染色体上，在遗传上总是和性别相关联，这种现象叫作伴性遗传。

    二、人类红绿色盲¶

    发现

    • 1792 年，英国人道尔顿发现自己和弟弟对一些颜色识别不清，这是一种色盲现象。他发表了论文《有关色觉的离奇事实——附观察记录》，成为第一个发现色盲的人。

    基因位置与显隐性

    • 红绿色盲是一种常见的人类遗传病，患者由于色觉障碍，不能像正常人一样区分红色和绿色。
    • 人类的 X 染色体和 Y 染色体在大小、携带的基因种类和数量上都有差别：X 染色体携带着许多个基因，Y 染色体只有 X 染色体大小的 \(\dfrac{1}{5}\) 左右，携带的基因比较少。
    • 因此，许多位于 X 染色体上的基因，在 Y 染色体上没有相应的等位基因。
    • 红绿色盲基因位于 X 染色体上，属于伴 X 染色体隐性遗传。

    基因型和表型

    项目 女性 男性
    基因型 \(X^BX^B\)、\(X^BX^b\)、\(X^bX^b\) \(X^BY\)、\(X^bY\)
    表型 正常、正常（携带者）、色盲 正常、色盲

    四种婚配情况

    婚配方式 子代情况
    正常女性（\(X^BX^B\)）× 色盲男性（\(X^bY\)） 儿子色觉都正常（\(X^BY\)）；女儿都表现正常，但都是携带者（\(X^BX^b\)）
    女性携带者（\(X^BX^b\)）× 正常男性（\(X^BY\)） 儿子 \(\dfrac{1}{2}\) 正常、\(\dfrac{1}{2}\) 色盲；女儿都不是色盲，但 \(\dfrac{1}{2}\) 是携带者
    女性携带者（\(X^BX^b\)）× 色盲男性（\(X^bY\)） 儿子和女儿各有 \(\dfrac{1}{2}\) 的概率为红绿色盲
    女性色盲（\(X^bX^b\)）× 正常男性（\(X^BY\)） 儿子均为色盲（\(X^bY\)）；女儿均为携带者（\(X^BX^b\)）

    遗传特点

    • 患者中男性远多于女性；
    • 男性患者的致病基因只能从母亲那里传来，以后只能传给女儿（交叉遗传）；
    • 女性的两条 X 染色体上同时含有色盲基因时才患病，因此女性患者的父亲和儿子一定都是患者。

    交叉遗传

    红绿色盲基因随着 X 染色体在亲子代间传递，表现为“外公 → 母亲 → 外孙”的交叉遗传特点。

    三、抗维生素 D 佝偻病¶

    • 抗维生素 D 佝偻病是一种伴 X 染色体显性遗传病，受显性基因（D）控制。
    • 患者常表现出 O 形腿、骨骼发育畸形、生长发育缓慢等症状。
    项目 女性 男性
    基因型 \(X^DX^D\)、\(X^DX^d\)、\(X^dX^d\) \(X^DY\)、\(X^dY\)
    表型 患者（较重）、患者（较轻）、正常 患者、正常

    遗传特点

    • 患者中女性多于男性，但部分女性患者病症较轻；
    • 男性患者的致病基因只能传给女儿，因此男性患者与正常女性婚配的后代中，女性都是患者，男性都正常。

    四、伴性遗传理论在实践中的应用¶

    医学上的应用

    • 根据伴性遗传的规律，可以推算后代的患病概率，从而指导优生。
    • 例如，抗维生素 D 佝偻病的男性患者与正常女性结婚，通过对后代的患病情况进行分析，可以从医学角度对他们的生育提出建议。

    育种上的应用——芦花鸡

    • 鸡的性别决定方式与人类、果蝇不同：雌性个体的两条性染色体是异型的（ZW），雄性个体的两条性染色体是同型的（ZZ）。
    • 芦花鸡羽毛上的黑白相间横斑条纹由位于 Z 染色体上的显性基因 B 决定；当它的等位基因 b 纯合时，鸡表现为非芦花。
    • 用芦花雌鸡（\(Z^BW\)）与非芦花雄鸡（\(Z^bZ^b\)）交配，\(F_1\) 中雄鸡都是芦花鸡（\(Z^BZ^b\)），雌鸡都是非芦花鸡（\(Z^bW\)）。
    • 这样，对早期的雏鸡就可以根据羽毛的特征把雌性和雄性区分开，从而做到多养母鸡，多得鸡蛋。

    伴性遗传的普遍性

    伴性遗传在生物界普遍存在。人的红绿色盲、抗维生素 D 佝偻病、血友病，果蝇的红眼和白眼，芦花鸡羽毛的横斑条纹，以及雌雄异株植物（如杨、柳）中某些性状的遗传，都是伴性遗传。

    五、性别决定¶

    类型 特点 实例
    XY 型 雌性为 XX，雄性为 XY 人、果蝇、哺乳动物、多数雌雄异株植物
    ZW 型 雌性为 ZW，雄性为 ZZ 鸟类、鳞翅目昆虫（蛾、蝶）
    染色体数目决定 雄蜂由未受精的卵细胞发育而来，染色体数目为 \(n\)；雌蜂为 \(2n\) 蜜蜂
    • 性染色体上的基因并不都决定性别，如红绿色盲基因；但性染色体上基因控制的性状在遗传上总是与性别相关联。

    六、遗传方式的判断方法¶

    判断显隐性

    • 无中生有为隐性：双亲正常，子代出现患者，则该病为隐性遗传病。
    • 有中生无为显性：双亲患病，子代出现正常个体，则该病为显性遗传病。

    判断基因位于常染色体还是 X 染色体

    类型 判断依据
    隐性遗传 隐性看女病：女性患者的父亲或儿子正常，则一定不是伴 X 隐性遗传，而是常染色体隐性遗传
    显性遗传 显性看男病：男性患者的母亲或女儿正常，则一定不是伴 X 显性遗传，而是常染色体显性遗传
    伴 Y 遗传 患者全为男性，且父传子、子传孙，则基因位于 Y 染色体上

    两种遗传病概率的计算

    1. 分别分析每一种遗传病的遗传方式，求出各自患病或正常的概率；
    2. 利用乘法定律和加法定律进行组合计算；
    3. 注意区分“患病男孩”与“男孩患病”的概率。

    常见易错点

    • 位于性染色体上的基因，其遗传遵循孟德尔遗传规律，只是表现出伴性遗传的特点。
    • 伴 X 隐性遗传病中，女性患者的父亲和儿子一定患病；伴 X 显性遗传病中，男性患者的母亲和女儿一定患病。
    • 性别比例接近 \(1:1\) 的原因是含 X 的精子与含 Y 的精子数量相等，且与卵细胞结合的机会均等。

    七、其他伴性遗传实例¶

    实例 遗传方式 特点
    人类血友病 伴 X 染色体隐性遗传 患者中男性远多于女性；女性患者的父亲和儿子一定患病
    人类红绿色盲 伴 X 染色体隐性遗传 交叉遗传；男性患者的致病基因来自母亲，传给女儿
    抗维生素 D 佝偻病 伴 X 染色体显性遗传 患者中女性多于男性；男性患者的母亲和女儿一定患病
    外耳道多毛症 伴 Y 染色体遗传 患者全为男性，父传子、子传孙
    果蝇红眼与白眼 伴 X 染色体遗传 白眼性状在雄性中更易表现
    芦花鸡羽毛横斑 伴 Z 染色体显性遗传 可根据羽毛特征在雏鸡阶段辨别雌雄
    • 伴性遗传在生物界普遍存在，人的红绿色盲、抗维生素 D 佝偻病、血友病，果蝇的红眼和白眼，芦花鸡羽毛的横斑条纹，以及雌雄异株植物（如杨、柳）中某些性状的遗传，都是伴性遗传。

    八、伴性遗传的概率计算（拓展）¶

    伴 X 隐性遗传

    • 设致病基因为 \(b\)，正常基因为 \(B\)。在人群中，男性只有一条 X 染色体，其基因型为 \(X^BY\) 或 \(X^bY\)。
    • 若致病基因 \(b\) 的频率为 \(q\)，则：
      • 男性发病率 \(=q\)；
      • 女性发病率 \(=q^2\)（基因型 \(X^bX^b\)）；
      • 女性携带者频率 \(=2q(1-q)\)。
    • 因此，伴 X 隐性遗传病在男性中的发病率远高于女性。

    “患病男孩”与“男孩患病”

    表述 含义 计算
    患病男孩 子代中既是男孩又患病的概率 先求患病概率，再乘 \(\dfrac{1}{2}\)
    男孩患病 已知子代是男孩，求其患病概率 在男孩范围内求患病概率，不再乘 \(\dfrac{1}{2}\)
    • 例如，女性携带者（\(X^BX^b\)）× 正常男性（\(X^BY\)）：
      • 子代中男孩患病的概率为 \(\dfrac{1}{2}\)；
      • 子代中患病男孩的概率为 \(\dfrac{1}{4}\)。

    两种遗传病同时考虑

    1. 分别判断每种遗传病的遗传方式；
    2. 分别求出每种遗传病的患病概率和正常概率；
    3. 用乘法定律和加法定律组合计算，注意“只患一种病”“患两种病”“完全正常”等不同表述。

    九、系谱图分析的特殊情形¶

    判断遗传方式的口诀

    • 无中生有为隐性：双亲正常，子代出现患者，则该病为隐性遗传病。
    • 有中生无为显性：双亲患病，子代出现正常个体，则该病为显性遗传病。
    • 隐性遗传看女病：女性患者的父亲或儿子正常，则一定不是伴 X 隐性遗传，而是常染色体隐性遗传。
    • 显性遗传看男病：男性患者的母亲或女儿正常，则一定不是伴 X 显性遗传，而是常染色体显性遗传。
    • 伴 Y 遗传：患者全为男性，且父传子、子传孙。

    几种特殊情形

    情形 结论
    女性患者的父亲和儿子都患病 可能是伴 X 隐性遗传，也可能是常染色体隐性遗传
    男性患者的母亲和女儿都患病 可能是伴 X 显性遗传，也可能是常染色体显性遗传
    患者全为男性，且代代相传 最可能为伴 Y 遗传
    母亲患病，子代全患病；父亲患病，子代不一定患病 可能为细胞质遗传（母系遗传）
    系谱中男女患病比例接近 \(1:1\)，且与性别无关 常染色体遗传

    系谱图分析的易错点

    • 不能仅凭“患者男性多于女性”就断定是伴 X 隐性遗传，还需结合系谱中亲子代的表现型。
    • 伴 X 隐性遗传病中，女性患者的父亲和儿子一定患病；若出现反例，即可排除伴 X 隐性遗传。
    • 伴 X 显性遗传病中，男性患者的母亲和女儿一定患病；若出现反例，即可排除伴 X 显性遗传。
    • 系谱图中若某种遗传病在家族中连续传递，且患者较多，应考虑显性遗传的可能。

    十、伴性遗传与常染色体遗传的比较¶

    比较项目 常染色体遗传 伴 X 染色体遗传 伴 Y 染色体遗传
    基因位置 常染色体 X 染色体 Y 染色体
    与性别的关系 与性别无关 与性别相关联 只有男性患病
    正反交结果 相同 不同 —

    十一、本节小结¶

    伴性遗传是指位于性染色体上的基因控制的性状在遗传上总是与性别相关联的现象。红绿色盲是伴 X 隐性遗传病，患者中男性远多于女性；抗维生素 D 佝偻病是伴 X 显性遗传病，患者中女性多于男性。伴性遗传理论可用于指导优生和育种。
